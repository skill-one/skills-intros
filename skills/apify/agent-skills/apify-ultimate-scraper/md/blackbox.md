# apify-ultimate-scraper (`apify/agent-skills/apify-ultimate-scraper`)

## blackbox

**function**: 你给我一个平台链接或一句话需求, 我把网上公开的相关数据抓下来, 整理成你能直接用的表格或报告 (覆盖 Instagram、TikTok、YouTube、LinkedIn、X、Google 地图/搜索/趋势、Reddit、Yelp、Airbnb 等 15+ 平台)。

- input: 一个 TikTok 或 Instagram 博主的主页链接, output: TA 近期发布内容的数据表 (CSV/Excel): 点赞数、评论数、发布时间、热门内容排名
- input: 一句话需求, 如「帮我找 Berlin 的咖啡店名单和联系方式」, output: 一份获客名单文件: 店名、地址、电话、评分、网站, 可直接导入表格软件
- input: 一家竞品店铺或酒店的链接 (Yelp / Airbnb / 点评类网站), output: 全部顾客评论的整理文件, 含评分分布和高频关键词, 供口碑分析
- input: 一个关键词, 如「露营装备」, output: 该词在 Google 上的搜索热度趋势和相关上升关键词数据
- input: 一个 YouTube 频道链接, output: 频道视频表现报表: 播放量、互动率、表现最好/最差的视频清单
