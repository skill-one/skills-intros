# angular-new-app (`angular/skills/angular-new-app`)

## blackbox

**function**: 帮你从零生成一个可以直接运行的 Angular 网页应用项目, 并按需往里面添加页面、组件等功能代码。

- input: 「帮我建一个叫 shop-admin 的网页应用, 要有页面跳转和好看的样式」, output: 一个完整可运行的 Angular 项目文件夹, 启动后浏览器里能看到带导航的页面
- input: 「给应用加一个登录页和一个商品列表页」, output: 项目里新增这两个页面的代码文件, 并已接入应用, 直接就能访问
- input: 「检查一下代码有没有报错, 有的话修掉」, output: 一次完整的构建结果; 报错已修复, 项目恢复可以正常运行
