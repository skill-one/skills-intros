# image-edit (`prime-skills/runcomfy-agent-skills/image-edit`)

## blackbox

**function**: 帮你改图片:给一张(或一批)图和一句改动要求,交回改好的成品图,没说的部分保持原样。

- input: 一张人像照的网址 + 一句话:「背景换成雨夜霓虹街道,人别动」→, output: 背景已换成霓虹街、人物长相姿势衣着不变的新图片文件 🌃
- input: 一批商品图的网址 + 「把右下角水印统一换成 AURA,其他不动」, output: 整批尺寸、风格一致的成品图,像同一个摄影师一次拍完的 📦
- input: 一张英文海报 + 「标题改成日文『今日のおすすめ』,位置和字体粗细不变」, output: 只换了文字、版式原样的日文版海报 🗾
- input: 一张照片 + 一张涂黑了「电线」区域的标注图 + 「把电线去掉」, output: 电线被抹掉、天空和屋顶完好如初的干净照片 ☁️
