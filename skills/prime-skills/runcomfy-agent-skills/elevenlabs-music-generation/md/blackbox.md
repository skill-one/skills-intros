# elevenlabs-music-generation (`prime-skills/runcomfy-agent-skills/elevenlabs-music-generation`)

## blackbox

**function**: 你用一段文字描述想要的曲风和歌词,我直接生成一段可下载的真实音频文件——带人声的完整歌曲或纯音乐背景乐都可以,长度 5 秒到 5 分钟自定。

- input: 「写一首 60 秒的轻快独立流行歌,女声主唱,副歌唱 'We rise, we strike, we never fade out'」, output: 一个 60 秒的 MP3 歌曲文件,带前奏、主歌、副歌的真实人声演唱
- input: 「来 90 秒 lo-fi 学习背景音乐,不要人声」, output: 一个 90 秒的纯器乐音频文件,暖钢琴加慵懒鼓点,适合循环播放
- input: 「做一个 5 秒的明快品牌 jingle,片头用」, output: 一个 5 秒的短音效音频文件,可直接放进视频或播客开头
