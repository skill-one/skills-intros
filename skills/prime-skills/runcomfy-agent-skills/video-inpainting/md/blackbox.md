# video-inpainting (`prime-skills/runcomfy-agent-skills/video-inpainting`)

## blackbox

**function**: 我帮您"抹除"视频里的东西: 让一段视频里 unwanted 的人物、水印、电线等消失或被替换, 画面其他部分保持原样, 且整个过程在所有帧之间自然连贯。

- input: 一个视频文件链接 + 一句话: "去掉右下角的水印, 其他画面别动" → 输出, output: 一段新的视频文件: 水印消失了, 那块区域被干净的背景补上, 全片每一帧都如此
- input: 一个视频链接 + 一句话: "把画面里走过的路人去掉, 背景补齐" → 输出, output: 一段新视频: 那个人从头到尾都不见了, 他走过的地方被周围环境自然填补, 看不出剪辑痕迹
- input: 一个视频链接 + 一句话: "把天空换成日落, 别的部分保持不变" → 输出, output: 一段新视频: 天空变成日落效果, 且云和光线随原有画面动态变化, 其余内容原封不动
