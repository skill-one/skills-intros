# flux-2-klein (`prime-skills/runcomfy-agent-skills/flux-2-klein`)

## blackbox

**function**: 把文字描述变成图片 — 说得越具体, 图越准; 还能参考你给的样图来改图或统一风格, 出图速度极快, 适合边看边改。

- input: 一段图片描述, 如「一只蜂鸟悬停啜饮粉色木槿花, 微距摄影, 清晨光线」→, output: 一张按描述生成的图片文件 (常见 1024×1024, 也能出 16:9 宽幅海报图)
- input: 产品描述, 如「哑光陶瓷马克杯放在旧木桌上, 柔和窗光, 浅景深」→, output: 可直接用于电商页面的产品照片, 构图和布光按描述执行
- input: 1~4 张参考图 + 一句修改要求, 如「参考图的产品和桌面保持不变, 瓶身标签换成蓝底白字 AURA」→, output: 一张沿用参考图构图光影、但按你要求改动了局部的图片
- input: 反复调整的短描述, 如「更暗一点」「背景换成雪山」→, output: 几乎即时返回的新草图, 适合现场连续试十几版找感觉, 定稿后再出精修版
