# flux-kontext (`prime-skills/runcomfy-agent-skills/flux-kontext`)

## blackbox

**function**: 给我一张图片和一句修改要求(如「加把伞」「换个背景」「改个标签文字」),我还你一张只改了指定之处、其余原样保留的新图片。

- input: 一张人物照片 + 「保持脸和姿势不变,让她手里多一把橙色雨伞」, output: 一张新图片文件:还是原来那个人,只是手里多了把橙色雨伞,其他像素级不变
- input: 一张饮料瓶产品照 + 「只把标签上的 ALPHA 字样换成 AURA」, output: 一张新图片文件:瓶身、桌面、光影完全没变,仅标签文字被替换
- input: 一张街景照片 + 「保持前景建筑不变,把天空换成黄昏色调」, output: 一张新图片文件:构图和前景不变,只有天空变成黄昏色
