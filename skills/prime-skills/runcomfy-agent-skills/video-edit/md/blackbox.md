# video-edit (`prime-skills/runcomfy-agent-skills/video-edit`)

## blackbox

**function**: 把你的视频按一句话要求改出新版本:换背景、换衣服、换配色、或让角色照着参考视频做动作,人物长相和动作保持不变,直接交付改好的视频文件。

- input: 一段 10 秒口播视频链接 + 一句话「背景换成现代办公室,人别变」, output: 新的 MP4 视频:背景已换,人物的脸、口型、动作、原声都原样保留
- input: 一张角色图片 + 一段舞蹈参考视频, output: 新的 MP4 视频:图片里那个角色跳出了参考视频中的同款舞蹈动作(最长 30 秒)
- input: 一段人物走路的视频链接 + 「把衣服换成商务正装」, output: 新的 MP4 视频:衣着已换成正装,脸和动作不变,720p 清晰度
- input: 一段手持产品的视频链接 + 一张新包装设计图, output: 新的 MP4 视频:手里的产品换成了图上的新包装,镜头移动和手部动作不变
