# nano-banana-2 (`prime-skills/runcomfy-agent-skills/nano-banana-2`)

## blackbox

**function**: 把你描述的画面变成一张真实的图片文件，图上的文字也画得准，适合做海报、封面、商品图和批量出方案。

- input: 一段画面描述, 如: "雨夜东京霓虹灯下的电影感人像特写", output: 一张生成好的 PNG 图片文件, 可直接下载使用
- input: 描述 + 指定图上文字, 如: "极简商品卡, 黑色马克杯, 标题写 Brewed Quietly, 16:9", output: 一张 16:9 商品图, 图中标题文字清晰、排版如你所写
- input: 一句创意 + "先出4张竖版草稿给我挑", output: 4 张竖版 (9:16) 图片变体, 挑中后可再以高清尺寸重出同款
