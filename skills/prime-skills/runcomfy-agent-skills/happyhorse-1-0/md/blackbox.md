# happyhorse-1-0 (`prime-skills/runcomfy-agent-skills/happyhorse-1-0`)

## blackbox

**function**: 把一段文字描述变成一段带同步声音的高清短视频 (最长 15 秒), 人物长相和穿着可以跨镜头保持一致。

- input: 一段场景描述: 「Wide shot. 穿橙红色宇航服的宇航员在月球平原上滑雪, 远处地平线上悬着地球」, output: 一个 16:9、1080p 的视频文件 (默认约 5 秒), 可直接下载播放
- input: 带规格的要求: 「竖屏 9:16、8 秒、无水印: 咖啡师拉花, 蒸汽在晨光里升起, 咖啡馆环境音」, output: 一个适合发抖音/朋友圈的竖版视频文件, 时长约 8 秒, 画面自带咖啡机蒸汽声和环境音
- input: 两段分镜描述, 指定同一人物: 「镜头1: 红色大衣蓝围巾的女人走进雨夜小巷; 镜头2: 同一人在拉面店屋檐下抖伞」, output: 一个两镜头衔接的视频文件, 人物长相和穿着前后一致, 带雨声、室内人声等音效
