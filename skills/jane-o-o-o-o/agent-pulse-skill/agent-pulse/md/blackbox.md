# agent-pulse (`jane-o-o-o-o/agent-pulse-skill/agent-pulse`)

## blackbox

**function**: 帮你盘点电脑上各种 AI 编程助手的使用情况:用了多少、花了多少钱、哪个模型划算、会不会超预算。

- input: 「我这周用 AI 助手花了多少钱?」, output: 一张费用统计:总额、按工具和模型分类的花费、最贵的几个会话排行
- input: 「Claude Code 最近 24 小时都干了什么?」, output: 会话清单:每段工作的时间、时长、工作量摘要,一眼看出哪些时段最活跃
- input: 「帮我出一份本周使用周报」, output: 一份排好版的 Markdown 或网页格式报告文件,含用量、费用和省钱建议
