# here-now (`heredotnow/skill/here-now`)

## blackbox

**function**: 把你的网页或文件变成一个能直接打开的网址, 一键分享给任何人。

- input: 一个网页文件夹 (里面有 index.html), output: 一个公开网址, 例如 https://bright-canvas-a7k2.here.now/, 别人打开就能看到你的网页
- input: 一个 PDF、图片或视频文件, output: 一个分享链接, 打开后有现成的预览页面, 无需对方装任何软件
- input: 一句话: "这个网站只想让同事看", output: 同一个网址, 但变成仅限指定邮箱 / 输入密码才能访问
- input: 一批私人文件 (笔记、资料), output: 存入你的私人网盘, 没有公开链接, 只有你自己 (和你授权的人) 能取用
