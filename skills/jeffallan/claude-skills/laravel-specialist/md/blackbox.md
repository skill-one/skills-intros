# laravel-specialist (`jeffallan/claude-skills/laravel-specialist`)

## blackbox

**function**: 你用一句话描述想做的网站后端功能, 我直接给你能运行、带测试的 Laravel (一种流行的 PHP 网站开发框架) 代码。

- input: 「做一个博客系统: 文章能发草稿、能发布, 每篇文章有多条评论」, output: 一整套可直接运行的代码: 数据库建表脚本、文章/评论的数据模型、增删改查接口 (API, 供 App 或网页调用的数据通道), 附带自动化测试
- input: 「给我的接口加上注册登录, 只有登录用户能看自己的数据」, output: 登录注册接口代码 + 访问权限控制代码, 并附测试文件——运行测试即可看到每条规则通过/失败
- input: 「用户提交订单后要发短信通知, 但不能让用户在页面上干等」, output: 后台任务代码: 提交接口瞬间返回, 短信在后台自动发出, 发送失败会自动重试并留下失败记录
