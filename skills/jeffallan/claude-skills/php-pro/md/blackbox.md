# php-pro (`jeffallan/claude-skills/php-pro`)

## blackbox

**function**: 把你嘴里的需求变成一份能直接放进项目、写好测试的 PHP 后端代码 (接口、数据表、修复 Bug 都行)。

- input: 一句需求: 「帮我写一个用户注册接口, 密码要加密存」, output: 一套完整代码文件: 注册接口 + 密码加密存储 + 数据校验 + 配套自动化测试, 外加几句话说明怎么接入你的项目
- input: 一个十来年的老 PHP 文件 (老写法, 一堆警告), output: 功能不变、用现代 PHP 写法重写的同款文件: 更安全、报错更少、以后好维护
- input: 一段报错信息或「这个接口偶尔 500」的出 Bug 代码, output: 修正后的代码 + 一句话点破原因 (如: 没校验输入导致数据库报错)
