# summarize (`openclaw/openclaw/summarize`)

## blackbox

**function**: 丢给我一个链接或文件，我帮你把里面的内容提炼成摘要，或把音视频整理成文字稿。📄

- input: 一个 YouTube 视频链接, output: 这条视频讲了什么的一段摘要；如果想要逐字内容，也能拿到完整的文字稿（可直接复制）
- input: 一篇网上文章的网址（比如新闻报道、博客）, output: 这篇长文的核心要点总结，长度可按需选：一句话梗概 / 短摘要 / 详版
- input: 一个本地 PDF 或文档的文件路径（比如 50 页的报告）, output: 这份文件的重点摘要，帮你不用通读全文也能抓住关键信息
