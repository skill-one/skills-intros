# interface-design (`dammyjay93/interface-design/interface-design`)

## blackbox

**function**: 你描述想要的产品界面 (后台、仪表盘、管理面板、设置页等), 我交给你设计成品级的界面代码, 让它看起来像顶级设计团队做出来的, 而不是模板货。

- input: 一句需求, 如「帮我做一个团队任务管理后台的界面」, output: 可直接打开使用的完整界面代码, 配色、字体、布局、间距都已完成设计, 像 Linear / Stripe 那样的成品观感
- input: 现有后台页面的代码文件或截图, 加一句「看起来太普通了」, output: 重新设计后的界面代码, 附逐条修改说明: 哪里改了、为什么这么改 (层次、重点、留白)
- input: 一个具体组件需求, 如「设计一张数据指标卡片」, output: 该组件的成品代码, 包含默认、悬停、空数据、报错等完整状态的视觉效果
