# argent-create-flow (`software-mansion/argent/argent-create-flow`)

## blackbox

**function**: 把你在 iPhone 上一段重复性的操作路径 (如每天签到、固定测试步骤) 变成可一键重放的自动化流程: 你先走一遍, 之后机器照着自动跑, 并给你每一步「通过/失败」的核对报告。

- input: 一句话描述重复操作, 如「每天打开 App, 进签到页, 点签到」, output: 一个 .yaml 流程文件 + 一条重放命令 + 重放结果报告 (标明每一步是否通过)
- input: 你在手机上手动演示一遍操作路径 (我边看边录制, 含关键画面是否出现的核对), output: 已保存的流程文件, 之后一条命令即可自动重放同样路径, 无需人再动手
- input: 一个重放失败的 .yaml 流程文件, output: 修复后的流程文件 + 一次完整重放的验证结果 (指明哪里曾断开、现在如何通过)
