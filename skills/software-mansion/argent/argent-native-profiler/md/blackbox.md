# argent-native-profiler (`software-mansion/argent/argent-native-profiler`)

## blackbox

**function**: 给你的手机 App (iOS / Android) 做性能体检:找出发热卡顿、界面冻结、内存泄漏的元凶函数,给你一份按严重程度排序的诊断报告。

- input: 一台运行着你 App 的 iOS 模拟器 (你像平时一样点一点、划一划), output: 一份性能报告:列出最耗 CPU 的函数、每次界面卡死发生的时刻和持续时长、疑似内存泄漏的对象,按严重程度标红/黄排序
- input: 一台 Android 设备上正在运行的 App, output: 同类报告:额外标注每次卡顿的具体原因 (如主线程被哪个函数卡住、垃圾回收是否拖慢了界面),以及内存是否在持续增长的提示
- input: 一句追问, 如「那个卡顿到底是谁引起的?」, output: 针对该问题的深挖答案:完整的调用链,指明是哪个函数、哪段代码阻塞了主线程;修完后再跑一遍同样操作,还能给你修复前后的对比,如实告诉你指标是变好了、变差了还是没变化
