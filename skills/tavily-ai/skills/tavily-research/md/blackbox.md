# tavily-research (`tavily-ai/skills/tavily-research`)

## blackbox

**function**: 把你给的一个研究问题, 变成一份多方来源交叉验证、每条结论都标注出处的深度调研报告 (约 30 秒~2 分钟出稿)。

- input: 「帮我对比一下 Cursor、Copilot、Claude Code 这几个 AI 编程工具哪个更适合小团队」, output: 一份结构化报告: 各工具定位对比表、价格与能力差异、适用场景建议, 每个结论后面都跟着可点开的来源编号
- input: 「2025 年金融科技行业有什么趋势?」, output: 一份市场分析报告: 趋势梳理、关键玩家动态、数据支撑, 全文标注信息来源, 可保存为本地文件
- input: 「量子计算最近有哪些真正的突破?」, output: 一篇带引用的综述: 合并多个网站的说法, 区分哪些是厂商宣传、哪些有实测数据, 附原文链接供你核查
