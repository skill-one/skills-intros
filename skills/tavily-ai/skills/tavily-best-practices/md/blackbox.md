# tavily-best-practices (`tavily-ai/skills/tavily-best-practices`)

## blackbox

**function**: 给你的程序或问题接上实时互联网——搜网页、抓网页正文、做联网深度调研, 交付能直接运行的代码或现成的结果。

- input: 一句需求: 「帮我给 Python 程序加联网搜索, 传入关键词返回结果」, output: 可直接运行的代码, 传入任意关键词即返回带标题、链接、摘要的网页搜索结果
- input: 一个或一组网址, 如某篇新闻或文档的链接, output: 这些页面的正文文本内容, 可直接存成文件或交给后续程序使用
- input: 一个整站地址, 如某个文档站首页, output: 该网站全部相关页面的链接清单, 或整站正文内容一次抓完
- input: 一句研究问题, 如「分析某产品在中小企业的竞争格局」, output: 一份综合了多个网页信息来源、带出处的调研报告
