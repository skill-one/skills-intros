# ai-elements (`vercel/ai-elements/ai-elements`)

## blackbox

**function**: 给正在做网站或应用的人写好一套现成的「AI 聊天界面」前端代码——对话气泡、消息输入框、发送按钮、加载动画这些都有，拿来放进项目就能用、也能按需改。

- input: 一句话需求，如「我想给我的网页加一个 AI 客服聊天窗口」, output: 一段可以直接放进项目里运行的聊天界面代码，含对话气泡、输入框和发送按钮
- input: 一条改动要求，如「用户消息靠右、AI 回复靠左，回复要有打字机效果，去掉气泡圆角」, output: 按你的要求修改好的聊天界面代码，替换原文件后刷新页面即可看到效果
- input: 一个问题反馈，如「装好组件后界面没有样式 / 报错说找不到模块」, output: 问题原因的说明，以及改好后的代码或配置片段
