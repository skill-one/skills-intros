# dbs-chatroom-austrian (`dontbesilent2025/dbskill/dbs-chatroom-austrian`)

## whitebox

- 接收话题：用户带问题进来（未带则由主持人打招呼收集话题）
- 并行派发：同一工具调用块中同时启动哈耶克、米塞斯两个 Agent（sonnet 模型），各自带角色化 prompt 独立生成回复
- 展示回复：以「💬 角色：」格式原样呈现两份回复
- 判官总结：Claude 主持人做质量把关 + 补盲区 + 给收获，以「🎯 Claude：」输出（≤200字）
- 循环或退出：询问继续；继续则把历史上下文拼进新 prompt 回到派发步，输入「结束」终止

- 双 Agent 并行编排：依赖 Agent tool + Claude sonnet 模型；两角色的差异全部编码在 prompt 里（思考框架、诚实规则、语气、200字上限），Agent 本身无独立状态
- 多轮上下文管理：保留最近 3 轮完整对话，更早轮次压缩为「之前讨论了 N 轮，话题包括：…」摘要；追问时将旧结论拼接进新 prompt 实现连续性
- 判官后处理：主持人不新增观点流，而是校验 Agent 输出（是否套公式、有无真交锋），补盲区并给可执行建议；回复语言跟随用户（中/英）
