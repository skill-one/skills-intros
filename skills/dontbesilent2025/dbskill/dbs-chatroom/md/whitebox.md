# dbs-chatroom (`dontbesilent2025/dbskill/dbs-chatroom`)

## whitebox

- 检测输入模式：用户已点名专家则直接进入第 3 步；未点名则按理论筛选规则推荐 3~5 位专家，停住等用户确认
- 每位专家一个独立 Agent，用 Agent tool 并行调用；每个 prompt 按该专家动态生成（3 条核心思维方法 + 统一诚实规则 + 说话风格 + 约 200 字约束）
- 汇总各 Agent 返回内容，按 💬 前缀格式统一输出专家发言
- Claude 以判官身份总结：讨论质量（有无真洞察/交锋）、补盲区、2~3 条可执行建议
- 保持聊天室活动状态：用户后续输入作为新焦点，复用原班人马与上一轮判官总结开启新一轮；直到用户明确说「结束聊天室」或输入 /dbs 才退出

- 理论先行的人选筛选：先拆话题为缺失的判断变量，候选理论须过 5 条筛选（命题清楚、经时间检验、可独立验证、覆盖独立变量、一手材料足够）+ 5 问推荐前自检；主动推荐时默认排除 KOL、情绪价值型、靠声量出名的人物，用户点名者不受此限
- 多 Agent 并行架构：依赖外部 Agent tool（每个专家一个独立 Agent 并行调用）；prompt 由模板动态拼装——思考方式、诚实规则（不确定就承认、可质疑话题前提）、说话风格、200 字左右，保证输出有实质内容
- 状态延续与退出协议：新一轮讨论时将上一轮的人物、发言摘要、判官总结和用户新问题注入各专家 prompt，使其回应/质疑/修正上一轮结论；只有明确「结束聊天室」「退出聊天室」或 /dbs 两个信号才终止，回到主 Agent
