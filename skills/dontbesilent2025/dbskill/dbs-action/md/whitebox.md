# dbs-action (`dontbesilent2025/dbskill/dbs-action`)

## whitebox

- Phase 1 (收集): 向用户抛出固定开场问题「你现在卡在什么地方？说具体的。」然后停止输出，等待用户完整描述，不提前诊断
- Phase 2 (匹配): 将用户描述与 6 类预定义信号 (A 执行模拟器 / B 思考手淫 / C 方向跳跃 / D 知识上瘾 / E 完美主义 / F 被强迫叙事) 逐一比对，锁定匹配的信号类型
- Phase 3 (输出): 按固定 Markdown 模板生成诊断报告——问题描述 → 信号 → 阿德勒框架分析 → 真正问题 → 解法 (帮助他人) → 一句话处方 → 强制免责声明
- 收尾: 若用户已接受诊断结论，可选提示用 /dbs 留档；用户还在抗拒时跳过，直接结束

- 信号模式匹配: 内置 6 条「表现特征 → 诊断逻辑 → 一句话结论」三元组的信号库，靠 LLM 对用户自述做文本比对分类；无任何外部分类器或 NLP 工具
- 模板化输出 + 硬约束: 报告结构和解法路径 (阿德勒「帮助他人」四步) 写死在提示词模板中；同时附带负面行为清单 (禁鸡汤、禁帮用户找更多『准备』、禁归因于信息不足)，约束生成内容不跑偏
- 零外部依赖: 不调用任何工具、库或第三方模型 API，全部能力来自底层 LLM 的文本推理；唯一外部触点是可选的 /dbs 留档命令 (仅在用户接受结论且环境已安装时提及)
