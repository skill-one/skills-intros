# dbs-action (`dontbesilent2025/dbskill/dbs-action`)

## blackbox

**function**: 你说出你卡住的事，它诊断出你迟迟不行动背后的真实心理原因，并给出一句直接的处方——不灌鸡汤。

- input: 「我知道该开始做小红书账号，但三个月了一直没动手」, output: 一份诊断报告：指出这是用「再准备准备」替代行动的心理机制，附一句一针见血的处方
- input: 「我买了七八门课、存了上百篇教程，感觉自己还没准备好创业」, output: 一份诊断报告：识别为「知识上瘾」——买课买的是『正在进步』的安慰，并给出打破循环的具体做法
- input: 「我已经换了 4 个项目方向，每个都做不满两周就放弃了」, output: 一份诊断报告：指出不是没找到对的方向，而是在逃避任何一个方向上的深入，附下一步的启动建议
