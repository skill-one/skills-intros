# dbs-good-question (`dontbesilent2025/dbskill/dbs-good-question`)

## whitebox

- 识别输入类型：判定用户给的是模糊问题、现象、材料、自动化请求还是混合输入。
- 五项检查打分：按对象 / 目标 / 冲突 / 约束 / 反馈逐项 0-2 分，总分映射为清晰度低 / 中 / 高。
- 判断 Agent 可解性：按边界、变量、反馈、可检验、行动、规律 6 个维度，输出 A-D 自动化档位。
- 改写成问题说明书：钉住现象与冲突，补齐约束与反馈入口；信息不足只出半成品说明书，未知项写「未知」。
- 生成候选解释并批评：最多 3 个候选，按 hard to vary / 可检验性 / 行动指向筛出最强解释，收尾只给一个最小下一步。

- 阈值-分级门控：总分 0-4 松问题（只追问）、5-7 中等+有断点（给 1-2 个低置信候选解释）、8-10 好问题（进入完整候选解释与批评）；分数决定下游流程，不达标不硬凑解释。
- 格式路由：按用户意图切 5 套 Markdown 输出模板（默认 / 严格审计 / 可解性判断 / 说明书 / 候选解释），默认隐藏评分表、输出限 5 小节以内。
- 无外部依赖：全程纯 LLM 文本推理，不调用任何外部工具、库或模型 API；唯一输入源是用户提供的材料。
