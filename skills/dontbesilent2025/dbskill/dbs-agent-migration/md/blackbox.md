# dbs-agent-migration (`dontbesilent2025/dbskill/dbs-agent-migration`)

## blackbox

**function**: 把你乱糟糟的 AI 助手配置（各种平台的规则文件和技能散落各处）整理成一套多端通用、改一处就全局生效的整洁工作台。

- input: 你的项目文件夹路径（里面规则文件和技能文件摆放混乱）, output: 一份体检报告：告诉你哪些做对了、真正缺什么、平台兼容情况，以及建议先改哪一层
- input: 散落在项目各处的技能笔记文件（比如写清了步骤和触发方式的 .md 文档）, output: 一份收编清单：哪些文件值得升级为正式技能、哪些只是普通文档不建议收、以及收编后放在哪里
- input: 一句需求，比如「我想让 Claude、Codex、Grok 都能调用同一套技能」, output: 多端接入文件（每个平台各一份入口文件，统一命名），交付前附带逐项核对结果，之后你只需改源文件即可同步所有平台
