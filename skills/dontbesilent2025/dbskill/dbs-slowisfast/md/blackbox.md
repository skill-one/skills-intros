# dbs-slowisfast (`dontbesilent2025/dbskill/dbs-slowisfast`)

## blackbox

**function**: 诊断你正在用的做事方法，找出哪些环节「贪快」会反噬、哪些地方值得慢做，给你一份带具体慢方法建议的报告。

- input: 「我用 AI 批量总结竞品内容来选题」, output: 一份诊断报告：摩擦/资产/复利三项检测结果 + 2-3 个慢方法替代方案（如手动逐条拆解对标文稿）+ 明确指出哪些环节该继续保持快
- input: 「我想做自媒体，每条内容都要从头憋，感觉在消耗自己」, output: 判断你现在是消耗战还是复利模式 + 一个具体的慢方法建议（如先手动建素材库，让每条内容比上一条更容易）
- input: 「AI 一键就能生成，还有必要手动整理吗？」, output: 一句直白的回答：AI 给你结构，理解得自己走一遍；并帮你划清哪一步值得手动、哪一步该交给工具
