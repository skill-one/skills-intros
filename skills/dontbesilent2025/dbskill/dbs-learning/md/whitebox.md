# dbs-learning (`dontbesilent2025/dbskill/dbs-learning`)

## whitebox

- 确认课题与存放目录：用户指定目录 > 项目目录（当前目录/学习课题/{课题名}/）> 系统目录兜底 ~/Documents/dbskill-learning/{课题名}/
- 新课题且在项目目录时：轻量检索项目（只读索引与根目录文档，跳过 .git/.env/密钥等敏感文件），汇总知识基础证据后问用户选「按项目来 / 从零开始 / 指定材料」
- 初始化课题：创建 00-学习计划.md、assets/ 和 01.md，文章用固定结构（要解决的问题→正文→小结→下一篇预告→学习反馈区）
- 后续每篇：读学习计划 → 找序号最大的文章 → 只提取其「学习反馈」区里用户新增的文字 → 按反馈信号查梯度表，定下一篇的主题、深度和角度
- 用同一固定模板生成 {n+1}.md，回写学习计划和 INDEX.md，进入下一轮循环

- 状态全靠本地 Markdown 文件持久化（学习计划记录进度/反馈摘要/下一步；文章序号 = 目录内最大序号 + 1，不跳号），不依赖任何外部工具、库或模型 API
- 反馈提取器：模板行（「你可以写：」「1. 哪里看懂了？」等提示问题）一律过滤，只认用户在提示行下方新增的文字；无真实反馈时先反问，用户强推才继续并标注「基于当前可见上下文生成」
- 梯度调节表驱动自适应：没懂→降抽象补例子、没意思→换角度、求应用→加案例、掌握→提概念密度、具体提问→优先回应；另设证据分级（用户亲写 > AI 草稿 > 第三方材料）决定学习起点
