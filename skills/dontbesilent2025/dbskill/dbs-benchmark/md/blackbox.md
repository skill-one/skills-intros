# dbs-benchmark (`dontbesilent2025/dbskill/dbs-benchmark`)

## blackbox

**function**: 帮你找到值得模仿的赚钱对标，拆解它是怎么赚钱的，并给你一张照着做的核对清单——不聊兴趣和理想，只聊利润。

- input: "我在小红书卖手工饰品，月赚 8000，帮我找个对标", output: 一份对标分析：筛出的候选对标 + 他的赚钱链条（怎么获客、怎么让人付钱、怎么交付、怎么复购）+ 你照着做的 3 步路径
- input: 报一个你看中的业务或账号（如「某某卖课账号」「社区团购团长」）, output: 一张五重过滤打分表：他赚钱吗、你能看懂吗、你能模仿吗……每项 ✅/❌，最后一句话结论：能干就干，不能干换下一个
- input: "我已经锁定对标了，接下来该怎么做？", output: 一张逐项对比表：产品价格、内容频率、封面风格、成交话术、投流方式……你和他不一致的地方全部标出，每处要么改成一致，要么必须说出理由
