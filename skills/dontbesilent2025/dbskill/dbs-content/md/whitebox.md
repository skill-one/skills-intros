# dbs-content (`dontbesilent2025/dbskill/dbs-content`)

## whitebox

- Phase 1 接收输入: 确认用户是否已有选题、形式、初稿 (三要素决定后续分支)
- Phase 2 形式匹配: 选题有但形式未定时, 按选题特性 × 平台规则表匹配形式
- Phase 3 五维诊断: 文字洁癖 / 封面标题 / 表达效率 / 认知落差 / AI 辅助工作流, 逐维判定
- Phase 4 输出报告: 套固定模板 (推荐形式 + 五维表格 + 第一步行动 + 一句话总结)
- 收尾: 仅提一次 /dbs 留档, 结束; 不代写内容

- 状态路由: 无输入初始状态 → 提问收选题; 有选题无形式 → 进 Phase 2; 有初稿 → 直接跳 Phase 3 诊断, 短路前两阶段
- 规则优先: 诊断靠内置规则集判定 (✅/⚠️/❌ 三级结论 + 具体问题), 不分析爆款结果; 触发特定话术 (如「想做干货」「AI 被限流」) 时走固定警告分支, 输出预设引语
- 模板化输出: 报告结构硬编码 (Markdown 模板), 结论由五维判定填充; 内联案例库 (3 正例 + 2 反例) 作为判定依据的地基
- 零外部依赖: 全流程为纯 prompt 协议, 不调用任何外部工具/库/API; 维度 5 中推荐的 AI 工具链 (get 笔记、deep search、智能体改写) 是给用户的建议, 非自身依赖
