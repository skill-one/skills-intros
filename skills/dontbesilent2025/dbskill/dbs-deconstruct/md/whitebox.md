# dbs-deconstruct (`dontbesilent2025/dbskill/dbs-deconstruct`)

## whitebox

- 接收概念：询问用户「你想拆解哪个概念？或者哪句话让你困惑？」
- 维特根斯坦式审查：分析该词在不同场景中的使用差异 → 追溯原始语境做概念还原 → 伪概念检测（去掉这个词还能否用大白话说清楚）
- 奥派校准：若涉及商业/经济，用主观价值论、行动先于理论、反理性建构主义、价格信号四项检验
- 输出报告：按固定 Markdown 模板（你以为它是什么 / 使用场景表 / 概念还原 / 大白话 / Question 还是 Problem / 一句话总结）
- 可选深化：用户要求深度拆解或概念特别复杂时，追加 7 张表本体论分析（对象/事态/复合事态/关系/规则/形式/定义）

- 无任何外部依赖：不调用工具、库或 API，全部分析由底层 LLM 的语言推理完成，方法论（维特根斯坦语言哲学 + 奥派经济学）以 prompt 形式内嵌
- 核心解析逻辑是三段审查：使用场景分析（同一词在不同人嘴里含义是否一致）→ 概念还原（原始语境、核心属性、商业迁移中的扭曲）→ 伪概念检测（删词测试：用大白话能说清则词是包装，说不清则词掩盖理解空白）
- 输出强制收敛：Question vs Problem 区分（答案能否为文本形式）决定结论定性；报告用固定模板结构化输出，最终必须以大白话收尾，禁止用新概念解释旧概念
