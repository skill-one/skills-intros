# dbs-content-system (`dontbesilent2025/dbskill/dbs-content-system`)

## blackbox

**function**: 把你本地堆积的大量旧文稿、推文、课程稿，整理成一个能长期生长、随时取用的内容库——以后不用凭记忆翻旧稿，写新内容直接从库里调。

- input: 一个装满旧文章、推文、课程稿的本地文件夹路径 + 想放在哪里, output: 一套可以直接打开浏览的内容库：每篇原文都登记了来源，内容被拆成「问题 / 观点 / 案例 / 方法」等独立卡片文件，另附主题分类图和重复内容清单
- input: 「我有 3 年公众号文章和一堆零散笔记，想系统整理」+ 文件夹位置, output: 先给一份盘点结论：素材量够不够、哪些该纳入哪些该排除；够格就直接开工，交付建好的系统 + 首批抽出的内容卡片和 2~3 张主题地图
- input: 一个已经建好的内容库, output: 从现有卡片重组出的新选题稿（可以直接照着写的发布骨架），以及更新后的主题地图和系统现状总览
