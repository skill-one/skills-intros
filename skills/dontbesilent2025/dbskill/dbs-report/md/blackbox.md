# dbs-report (`dontbesilent2025/dbskill/dbs-report`)

## blackbox

**function**: 把你之前多次保存的商业诊断记录，合并成一份带日期、可直接发给别人的 Markdown 诊断报告。

- input: 输入「出报告」或命令 /dbs-report, output: 一份 Markdown 诊断报告文件 + 一行回执（文件路径、合并了几份存档、覆盖哪段时间）。报告里包含：历次主诉的演变、已确认的结论、被否决的方向、还没解决的问题、建议的下一步、全部存档索引
- input: 输入「给合伙人整理一份，只看这个月之后的」或 /dbs-report --since 2026-04-01, output: 一份只合并指定日期之后存档的诊断报告，同样拿到文件路径和合并数量回执
- input: 在没有存档、或只存过 1 次的项目里输入「出报告」, output: 不生成文件，直接提示「还没有可汇总的存档」或「只有 1 份存档不需要合并」，并告诉你可以怎么开始
