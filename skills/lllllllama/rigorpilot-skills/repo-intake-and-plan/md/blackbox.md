# repo-intake-and-plan (`lllllllama/rigorpilot-skills/repo-intake-and-plan`)

## blackbox

**function**: 把一个深度学习代码仓库「只看不跑」地审一遍, 交给你一份最小复现计划: 该跑哪条命令、还缺什么、哪里有坑——不装环境、不下载文件、不执行任何代码。

- input: 一个本地代码文件夹路径 (含 README 的深度学习项目), output: 一份扫描报告: 目录结构一览 + 文档里写明的全部命令清单, 并标注每条命令属于「跑模型 / 测效果 / 训练」哪一类
- input: GitHub 仓库链接 + 一句提示「我只想先跑推理看看效果」, output: 一份最小复现计划: 推荐从哪条文档命令开始, 跑通它还缺什么 (模型权重? 数据? 没写的参数?), 以及文档没交代清楚的疑点列表
- input: 一个文档残缺、命令疑似过期的仓库路径, output: 一份风险清单: 哪些命令文档里写了但可能跑不通、哪些关键信息缺失, 以及动手前应先确认的问题列表
