# analyze-project (`lllllllama/rigorpilot-skills/analyze-project`)

## blackbox

**function**: 给它一个深度学习研究项目的代码仓库 (本地路径或 GitHub 链接), 它通读后给你一份人话版的「仓库解读报告」: 模型结构、训练/推理从哪里启动、配置文件如何关联、哪些代码实现可疑——全程只读, 不改动你的任何代码。

- input: 一个深度学习论文的开源仓库 (本地路径或 GitHub URL), output: 一份解读报告: 这套代码实现了什么模型、训练入口在哪个文件、推理怎么跑、各配置文件之间是什么关系
- input: 「我想改成自己的数据集, 该动哪里?」这样的具体问题, output: 指到具体文件和位置的白话说明, 告诉你哪里是合理的插入点、要注意什么 (只告诉你, 不替你改)
- input: 「帮我查查这个仓库的实现有没有坑」, output: 一份可疑点清单, 每条标注为什么可疑、建议去哪里验证; 只标记为「疑点」, 不武断定为 bug
