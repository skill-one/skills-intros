# expo-api-routes (`expo/skills/expo-api-routes`)

## blackbox

**function**: 帮你的 App 或网站编写、修复和上线「接口」——让手机/网页端安全地从服务器取数据、存数据,而不暴露密钥。

- input: 一句话需求:「做一个接口,在服务器端调用 AI,别把 API 密钥打包进手机 App」, output: 一个可直接放进项目的接口代码:接收用户提问 → 密钥只留在服务器 → 返回 AI 回复
- input: 已有的接口代码 + 问题:「网页端调用时报跨域错误」「数据库查询总是失败」, output: 修好的代码,并说明改了哪里:如补上跨域许可、换用云端数据库连接
- input: 「把我的接口发布上线,并配好生产环境的密钥」, output: 几条部署命令 + 配置步骤;发布完成后得到一个可供 App/网页实际调用的线上接口地址
- input: 「我需要接收支付平台的付款回调通知」, output: 一个能接收并校验回调的接口代码,收到通知后可更新订单状态、返回正确应答
