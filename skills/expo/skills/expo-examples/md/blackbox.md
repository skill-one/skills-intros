# expo-examples (`expo/skills/expo-examples`)

## blackbox

**function**: 你想在 Expo 应用里接入第三方服务 (支付、登录、地图、AI、数据库等), 我按 Expo 官方最新示例帮你把代码和配置搞定。

- input: 我的 Expo 项目想接入 Stripe 支付 (给出项目路径), output: 改好的项目: 支付相关依赖、配置和代码已写进现有文件, 你原来的代码一点不动, 装好依赖就能跑
- input: 一个库名, 如 "Supabase" / "OpenAI" / "地图" / "动画", output: Expo 官方对应的示例代码和接入写法 (关键文件 + 需要装的包、要开的配置), 供你对照抄用
- input: "从 with-maps 这个示例帮我新建一个项目", output: 一个可直接运行的新 Expo 项目文件夹, 地图功能已配好
