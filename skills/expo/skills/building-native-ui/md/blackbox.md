# building-native-ui (`expo/skills/building-native-ui`)

## blackbox

**function**: 为你的手机 App 写出「像系统自带应用一样好看好手感」的界面屏幕代码, 直接可运行。

- input: 一句需求描述, 如「做一个设置页: 深色模式开关、通知音量滑杆、账号信息卡片」, output: 一个可直接放进项目运行的屏幕代码文件 (如 settings.tsx), 在手机上是原生 iOS/Android 质感的设置页
- input: 一个已有的屏幕代码文件, 存在问题如: 深色模式下刺眼、小屏手机上内容被裁切, output: 改好的代码: 颜色自动跟随系统深浅色, 顶部底部留白正确, 各种屏幕尺寸都不破版
- input: 一条效果需求, 如「首页顶部加毛玻璃栏, 列表卡片带入场动画」, output: 更新后的首页代码, 顶部模糊栏 + 流畅的卡片进场动画, 直接可用
