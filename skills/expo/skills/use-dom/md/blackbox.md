# use-dom (`expo/skills/use-dom`)

## blackbox

**function**: 我能把"网页技术写的界面"（如图表、代码高亮、富文本编辑器）直接装进你的手机 App 里用，同一份代码在 App 和网站上都能正常显示，不用为手机端重写一遍。

- input: 一个 Expo 手机应用项目 + 一句话需求：「用网页图表库 recharts 给我的 App 加个数据折线图」, output: 改好的代码文件；运行后 App（iPhone/安卓）界面里正常显示图表，网页端打开也直接能用
- input: 一个现有的 React 网页组件文件（例如一个代码高亮器、一个 Markdown 编辑器）, output: 这个组件可以在手机 App 里原样使用，代码一行不用改
- input: 一条需求：「网页内容的按钮要能触发手机的能力，比如点了弹出系统提示框、把数据存进手机本地」, output: 接通了网页和手机：点击页面里的按钮会弹出原生系统弹窗/完成本地保存，网页侧能拿到操作结果
