# expo-router (`expo/skills/expo-router`)

## blackbox

**function**: 给手机 App 添加页面和页面之间的跳转——新页面、底部标签栏、返回、弹出窗、搜索栏等, 交付可直接放进项目运行的代码。

- input: 一句需求: "给我的 App 加一个设置页面, 能从首页点进去", output: 设置页代码文件 + 首页代码, 点一下就能打开设置页, 左上角自带返回
- input: 一个商品列表页代码 + 要求: "点击商品进入详情页", output: 改好的列表代码: 点击进入详情, 长按还能弹出预览和"分享/删除"菜单
- input: 一句需求: "加一个底部标签栏, 首页 + 搜索, 再给搜索页配个搜索框", output: 带原生底部标签栏的布局代码 + 带搜索框的搜索页代码, 深色模式自动适配
