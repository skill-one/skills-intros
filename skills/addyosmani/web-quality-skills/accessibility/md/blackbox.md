# accessibility (`addyosmani/web-quality-skills/accessibility`)

## blackbox

**function**: 给网站做无障碍体检: 找出视障、听障、色弱、只用键盘等用户会遇到的使用障碍, 并把代码修到达标。

- input: 一个网址, 如「帮我看看 https://example.com 对残障用户友好吗」, output: 一份体检报告: 评分 + 按严重程度排序的问题清单, 如「第 3 张图片没有文字说明, 读屏软件(把屏幕内容念出来的工具)会直接跳过它」, 每条附修复建议
- input: 一个网页的 HTML/CSS 代码文件, output: 改好的代码文件: 图片补上了文字说明、图标按钮补上了名字、表单补上了标签、文字颜色对比度调到达标, 页面外观和功能不变
- input: 「我的弹窗把键盘用户困在里面出不去了」, output: 问题原因 + 修复后的代码: 键盘按 Tab 能正常进出弹窗, 关闭后光标回到原来的位置, 不再卡死
- input: 「我们要符合 WCAG AA 标准(很多地区法规要求的无障碍等级), 能达标吗?」, output: 逐条对照的达标清单: 哪些已通过、哪些不达标、每条差距具体怎么改、改完优先级如何
