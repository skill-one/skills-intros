# best-practices (`addyosmani/web-quality-skills/best-practices`)

## blackbox

**function**: 给你的网站或前端代码做一次「体检」: 找出安全隐患、过时写法和兼容性问题, 并直接给出修好的代码。

- input: 一个已上线的网站网址 (URL), output: 一份按严重程度排序的体检报告: 指出如「页面部分资源没走 HTTPS 加密」「源代码地图暴露在外」等问题, 每条附修复建议
- input: 一个前端项目的文件夹路径, output: 问题清单 + 修改后的代码文件: 例如把会卡住页面的过时写法换成现代写法, 补上缺失的手机端适配声明, 修完可直接替换原文件
- input: 一段报错的网页代码 + 「帮我看看哪里不对」, output: 修好的代码片段 + 一句话原因说明, 例如「按钮嵌套写法不合法导致点击异常」
