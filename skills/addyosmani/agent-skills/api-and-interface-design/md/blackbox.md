# api-and-interface-design (`addyosmani/agent-skills/api-and-interface-design`)

## blackbox

**function**: 帮你设计软件之间的「接口」——即双方事先约定好"传什么、返什么、出错怎么办"的那份契约,让前后端、不同系统、不同团队能顺畅对接,且接口稳定、不容易被用错。

- input: 一句功能需求,如「我们要做个待办清单,小程序前端要连后台」, output: 一份接口约定文档:有哪几个接口、每个接口收什么参数、返什么数据、出错时返什么,每个都带具体示例
- input: 现有接口的定义代码或文档(如一段 OpenAPI 文件、TypeScript 接口定义), output: 一份评审报告:逐条指出容易误用、前后不一致、日后会坑人的设计问题,并给出具体改法
- input: 一个具体担忧,如「支付接口怎么防止网络重试导致用户被重复扣款?」, output: 一套防重复方案:如何标识同一笔请求、重复请求到达时怎么响应、异常时如何兜底,可直接照着实现
