# interview-me (`addyosmani/agent-skills/interview-me`)

## blackbox

**function**: 在你动手做任何事之前, 通过一次一个问题的追问, 挖出你「真正想要的东西」, 最后交给你一份双方确认过的意图说明。

- input: 一句模糊需求, 如「帮我做个数据看板」, output: 几轮一问一答后, 一份确认过的需求清单: 你真正要的结果、给谁用、为什么是现在、怎样算成功、明确不做什么——确认无误后才能开工
- input: 「interview me」/「在开工前拷问我的想法」这类指令, output: 一次只有一个问题, 且每个问题都附带我的猜测让你纠正——比如「是要给团队看, 还是你自己记实验用? 我猜是团队」
- input: 一段听起来很对但全是漂亮话的想法, 如「我想做个可扩展、现代的应用」, output: 被点破的真实意图, 如「如果不用向任何人证明, 你其实想要什么?」——最终产出一句能直接开工的话, 而不是一堆时髦词
