# context-engineering (`addyosmani/agent-skills/context-engineering`)

## blackbox

**function**: 帮你的 AI 编程助手"开小灶"——把项目规则、相关文件和任务要求整理成它该看的资料, 让它写出的代码符合你的规范, 少瞎编、少跑偏。

- input: 一个新项目的说明 (技术栈、常用命令、你希望的代码风格), output: 一份项目规则文件 (如 CLAUDE.md), 放进项目根目录后, AI 每次都会照着你的规范写代码
- input: 一段抱怨: "AI 写的代码总不按我们的命名和风格, 还会调用根本不存在的函数", output: 一份诊断与补救: 指出 AI 缺了哪些背景资料, 并直接产出该补上的规则文件和参考示例
- input: 一项具体开发任务 + 几个相关文件路径, output: 一份只含必要信息的任务简报 (相关文件、可参考的现成写法、硬性约束), 粘贴给 AI 即可开工, 不会被无关内容带偏
