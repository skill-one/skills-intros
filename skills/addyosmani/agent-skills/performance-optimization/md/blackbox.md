# performance-optimization (`addyosmani/agent-skills/performance-optimization`)

## blackbox

**function**: 诊断你的网站或应用「慢在哪」, 并直接改代码让它变快, 用改前改后的实测数据证明真的变快了。

- input: 一个加载很慢的网页 URL + 一句描述, 如「首页要 5 秒才显示出来」, output: 一份诊断报告: 指出最拖速度的具体问题 (如首页大图没压缩、代码包太肥), 附上改好的代码和改前/改后的加载时间对比
- input: 响应很慢的后端接口代码文件, 并说明症状, 如「这个接口要 3 秒才返回」, output: 定位到瓶颈 (比如循环里一条条查数据库), 返回修改后的代码, 并附优化前后的响应时间数据
- input: 一条执行很慢的 SQL 查询语句, output: 查询分析结果 + 需要新建索引的具体语句, 以及加索引前后的执行耗时对比; 如果加索引没用, 会直接告诉你原因
