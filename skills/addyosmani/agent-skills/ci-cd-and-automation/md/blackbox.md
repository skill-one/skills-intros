# ci-cd-and-automation (`addyosmani/agent-skills/ci-cd-and-automation`)

## blackbox

**function**: 给你的项目装上"自动质检 + 自动发布"流水线：每次代码提交自动跑检查，不合格的进不了正式版本，合格的能安全上线，出问题能一键退回。

- input: 告诉我你的项目仓库在哪、用什么语言写的（如：GitHub 上的一个 Node.js 网站项目）, output: 一份可直接使用的自动化检查配置：此后每次有人改代码，系统自动运行代码规范检查、测试、构建打包，任何一项不过关就禁止合并上线
- input: 一句需求：「我希望代码合并后自动发布到网站」, output: 一套自动发布流程：改动先自动发布到一个预览版网站供你点开验收，确认没问题再上正式版；上线后出问题可指定旧版本一键回退
- input: 粘贴一段流水线失败的报错信息, output: 问题定位与修复方案：指出是哪一步、什么原因挂掉的，以及怎么改才能让流水线重新通过
