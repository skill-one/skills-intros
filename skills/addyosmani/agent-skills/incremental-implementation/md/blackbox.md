# incremental-implementation (`addyosmani/agent-skills/incremental-implementation`)

## blackbox

**function**: 把大功能的代码改动拆成多个小步完成, 每一步做完项目都能正常运行、测试通过并单独保存一份进度, 出问题随时退回上一步, 不会出现写了一大堆代码才发现全错了的情况。

- input: 一个代码仓库 + 一句话需求, 如「给订单页加一个取消订单按钮」, output: 功能可用的代码, 分成几次独立提交 (先数据库、再接口、最后按钮), 每次提交后项目都能构建、测试全过
- input: 一份开发计划里的某个任务条目, 如「任务3: 新增搜索接口」, output: 只完成该任务的代码变更, 附每步验证结果 (构建通过 ✓ 测试通过 ✓), 不夹带「顺手改」的其他无关文件
- input: 一个高风险的大改动, 如「把支付功能从旧接口整体迁到新接口」, output: 先只做最没把握的那一小段并当场验证可行, 通过后再逐步补全; 全部完成之前新功能对用户隐藏, 不会上线半成品
