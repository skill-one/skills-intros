# idea-refine (`addyosmani/agent-skills/idea-refine`)

## blackbox

**function**: 把一个模糊的想法打磨成一份能直接开工的方案——通过来回对话帮你把想法说清楚、想周全、砍到最小。

- input: 一句模糊的想法, 如「我想做个帮人坚持喝水的App」, output: 先问你 3-5 个关键问题 (给谁用、怎样算成功等), 然后给出 5-8 个思路明显不同的方向供你挑选
- input: 你选中的方向 + 补充的想法, output: 一份 markdown 方案文档 (可存为文件), 含: 问题定义、推荐方向及理由、待验证的关键假设、最小可行版本 (MVP) 范围、「不做清单」
- input: 「帮我压力测试这个创业计划」+ 你的现有方案, output: 一份直白评估: 指出你没验证过的隐藏假设、最可能翻车的点、有人会愿意为此付钱还是只是锦上添花, 以及每个假设怎么低成本验证
