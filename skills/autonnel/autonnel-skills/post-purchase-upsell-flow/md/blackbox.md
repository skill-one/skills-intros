# post-purchase-upsell-flow (`autonnel/autonnel-skills/post-purchase-upsell-flow`)

## blackbox

**function**: 帮电商卖家在顾客付完款之后多赚一笔:设计"一键加购"的追售页面(追加卖什么、定多少价、页面写什么、上线后看哪些数),让每单平均收入变高,同时不伤害原本的下单转化。

- input: 一段业务描述,如:「我卖 ¥199 的瑜伽垫,广告费不便宜,想提高每单收入」, output: 一套付款后追售方案:追加卖什么商品、定多少价、链条怎么排(接受后下一步卖什么、拒绝后降级卖什么、在哪一步停),照着就能落地
- input: 现有感谢页的内容,如:「目前只显示一行'感谢您的订单'」, output: 改好的追售页文案:点中缺口的标题、3-5 行贴合刚买商品的卖点、一个『一键加购 ¥X』按钮、一句诚实不纠缠的拒绝链接
- input: 上线后的数据,如:「追售页被看了 500 次,128 人购买;追售订单退款率 12%,比普通订单高」, output: 一份判断:接受率是否健康、退款升高是offer还是文案在误导、下一步只允许改哪一个变量,避免瞎测下结论
