# self-hosted-funnel-launch (`autonnel/autonnel-skills/self-hosted-funnel-launch`)

## blackbox

**function**: 把一个销售漏斗 (落地页 → 收银台 → 加购 → 感谢页) 从零搭建、部署到你自己的服务器上并正式上线，之后还能替你改页面、看订单数据。

- input: 你的域名或服务器权限 + 一句「帮我把卖课的漏斗部署到自己的服务器上」, output: 一个已经上线、可以登录管理的后台网址，页面能正常打开访问
- input: 一段产品描述，如「卖 ¥299 线上课程，付款后推荐加购 ¥199 私教服务」，及支付账号（如 Stripe / PayPal）, output: 一条完整跑通的销售流程：落地页、收银台、一键加购、感谢页，外加可直接放进广告的推广链接
- input: 已上线漏斗的访问地址和 API 密钥 + 指令，如「把头图换掉、价格改成 ¥199，再看下昨天的订单」, output: 改好并重新发布的页面，以及一份订单、转化数据的小报告
