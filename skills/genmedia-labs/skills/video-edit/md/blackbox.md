# video-edit (`genmedia-labs/skills/video-edit`)

## blackbox

**function**: 你给我一段现成的视频加一句修改要求（或一张参考图），我还你一段改好的新视频——换背景、换服装、换色调、换包装、或让图里的人做出参考视频里的动作，都不用你自己碰剪辑软件。

- input: 一段 10 秒内的口播视频链接 + 一句话「把背景换成现代办公室，人、口型、声音都别动」, output: 一个新视频文件：背景已换成办公室，人脸、口型和原声保持不变
- input: 一张人物照片 + 一段别人跳舞的视频链接, output: 一个新视频：照片里这个人在跳同款舞蹈，长得还是他/她自己
- input: 一段手持产品的视频链接 + 一张新包装设计图, output: 一个新视频：手里的产品包装换成了新设计，镜头运动和手部动作原样保留
- input: 一段人物视频链接 + 一句话「把衣服换成商务西装 / 把光线调成黄昏金色」, output: 一个新视频：只有衣着或光线变了，人物长相和动作和原片一致
