# seedance-2-5-image-to-video (`genmedia-labs/skills/seedance-2-5-image-to-video`)

## blackbox

**function**: 把一张静态照片变成一段 4~30 秒的高清动态视频,画面里的人和物会动起来,并可同步生成说话声、环境音和配乐。

- input: 一张咖啡馆人像照片的 URL + 指令:"她抬头看向镜头,温柔地说今天的新豆子到了", output: 一段 8 秒的 MP4 视频:照片里的人开口说出这句台词,背景带咖啡厅的环境杂音
- input: 一张产品瓶子的照片 URL + 指令:"瓶子缓缓旋转,镜头慢慢推近,15 秒,不要声音", output: 一段 15 秒的静音 MP4:瓶身、标签、光影和照片里完全一致,只添加了旋转运镜和光线变化
- input: 一张海边风景照的 URL + 指令:"云缓慢飘动,海浪轻拍岸边", output: 一段 5 秒的动态 MP4:静止的风景活了过来,同步带上海浪和风声
