# pexo-agent (`pexoai/pexo-skills/pexo-agent`)

## blackbox

**function**: 把一句话描述、图片、网页链接、脚本或音频,变成一条可直接发布的成品视频(自动配乐、字幕、多镜头剪辑),你不需要懂任何视频制作。

- input: 一句中文描述,如「给我的咖啡店做一条 15 秒的竖屏短视频,适合发抖音」→, output: 一条 15 秒 9:16 成品视频文件 + 下载链接,已带配乐、字幕和转场,可直接发布
- input: 一张产品照片,如 shoes.jpg,加一句「用这张图做个产品广告」→, output: 以这张照片为主角的产品广告视频,自动完成分镜、运镜和背景配乐
- input: 一个商品页面的 https 链接,如「根据这个页面做推广视频」→, output: 基于该页面内容生成的推广视频,通常是多镜头、带旁白的完整短片
