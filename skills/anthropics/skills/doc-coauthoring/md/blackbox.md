# doc-coauthoring (`anthropics/skills/doc-coauthoring`)

## blackbox

**function**: 陪你从零到一合写正式文档（决策文档、提案、技术方案等）：你说想法和背景，我帮你整理成结构完整、读者能看懂并能落地的成稿。

- input: 一句话需求，如「我要写一份把数据库从 MySQL 迁到 Postgres 的决策文档，说服老板批预算」, output: 一份可直接发给老板的决策文档：背景、方案对比、建议、风险都写清楚，并经过反复修改到你满意
- input: 一堆零散素材：聊天记录截图、会议纪要、零碎吐槽、半成品草稿，不用整理直接全部粘贴, output: 一份条理清晰的提案/方案文档——我通过追问把信息缺口补齐后成稿
- input: 一份你已经写好的技术方案或 PRD, output: 一份「模拟读者测试」报告：指出新读者会卡住、误解或觉得没说清的地方，并给出修改后的终稿
