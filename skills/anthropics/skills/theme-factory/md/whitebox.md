# theme-factory (`anthropics/skills/theme-factory`)

## whitebox

- 先原样展示 theme-showcase.pdf, 让用户预览 10 套预设主题 (只读, 不做任何修改)
- 询问用户选哪套主题, 并等待明确选择确认后才继续
- 从 themes/ 目录读取所选主题的规格文件 (色板 + 字体配对)
- 将配色与字体一致地套用到整个 artifact, 校验对比度与可读性
- 若 10 套预设都不合适, 转入定制: 按用户描述生成新主题, 先展示供确认, 再按上述流程应用

- 主题即规格文件: 每套主题在 themes/ 目录下定义为一组 hex 色码 + 标题/正文两套配对字体, 应用时逐页逐元素统一替换, 保持主题视觉识别一致
- 展示与修改分离: theme-showcase.pdf 是静态预览物料, 流程中只展示不改动; 修改动作只发生在用户 artifact 上
- 门控与降级: 主题选择设有显式确认门槛 (未确认不执行); 预设不满足时用基础描述现场合成自定义主题 (命名同风格, 同样先确认后应用)
- 依赖面: 仅依赖 skill 自带的 theme-showcase.pdf 与 themes/ 目录; SKILL.md 未声明任何外部库或模型 API, 不额外引入
