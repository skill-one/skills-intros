# webapp-testing (`anthropics/skills/webapp-testing`)

## blackbox

**function**: 像一个真实用户一样在浏览器里打开并操作你的网页应用, 帮你验证功能是否正常, 最后交给你截图和一份"哪里好用、哪里出问题"的报告。

- input: 一个本地网页项目的文件夹 + 启动命令 (如 npm run dev), 以及一句需求: "测一下注册登录流程", output: 一份测试结论: 注册、登录各步骤是否成功, 失败时附上报错截图和原因分析
- input: 一个 HTML 文件路径, output: 页面渲染后的截图 + 页面上所有按钮、输入框、链接的清单, 方便你确认页面显示正常
- input: 一个已在本机运行的网址 (如 http://localhost:5173) + 指令: "提交空表单看看会怎样", output: 操作前后的对比截图 + 该场景是否正常 (如是否有报错提示) 的判定, 有异常时附浏览器控制台的报错信息
