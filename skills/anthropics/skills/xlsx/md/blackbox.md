# xlsx (`anthropics/skills/xlsx`)

## blackbox

**function**: 我专门伺候 Excel 表格：你给一个表格文件（或描述想要的表），我帮你读取、修改、计算、修错、美化或从零新建，最后交回一个能直接打开使用的表格文件。

- input: 一份乱糟糟的销售记录 CSV（列名错位、混着空行），要求「按产品汇总销售额」, output: 一个整理好的 .xlsx 文件：数据清洗干净，按产品分好类，销售额用公式汇总，改动原始数据总数会自动跟着变
- input: 「这个 xlsx 打开到处是 #REF! 报错，帮我修一下」+ 文件本身, output: 修复后的 xlsx 文件：报错全部消除，公式重新核算正确，原有格式保持不变
- input: 「帮我做一个年度预算模板，我要填收入的格子标黄」这样一句话, output: 一个全新的 .xlsx 预算表：黄色格子等你填数，其余自动计算，附一句使用说明和一行示例告诉你格式怎么填
