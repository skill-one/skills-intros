# algorithmic-art (`anthropics/skills/algorithmic-art`)

## blackbox

**function**: 把一句主题、情绪或灵感描述, 变成一个在浏览器里打开就能跑的互动生成艺术网页——画面会自己生长变化, 还能调参数、换编号刷出无数变体、一键保存成图片。

- input: 一段主题描述, 如「用代码画一幅雨夜霓虹的感觉」, output: 一个自包含的 HTML 文件, 双击就能在浏览器打开: 动态生成的艺术画面 + 侧边栏滑块实时调节效果
- input: 一个种子编号, 如「给我 42 号变体」, output: 同一编号永远生成一模一样的画面; 换个编号就是一张新作品, 可以下载为 PNG 图片
- input: 「帮我出一套 100 张风格统一但每张不同的壁纸」, output: 在同一个网页里点按钮或输入编号 1~100, 逐张浏览并保存, 风格统一、构图各异
