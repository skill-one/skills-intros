# frontend-design (`anthropics/claude-code/frontend-design`)

## blackbox

**function**: 把你的产品或页面想法变成一个有独特视觉风格的完整网页设计——不套模板、不千篇一律, 打开浏览器就能看。

- input: 一句话需求, 如「给我做一个独立咖啡烘焙工作室的官网首页」, output: 一个可直接在浏览器打开的完整网页: 配色、字体、版式都围绕咖啡烘焙这门生意定制, 带真实可用的文案和有记忆点的首屏
- input: 现有页面的截图或代码, 附一句「太像模板了, 帮我重新设计」, output: 改版后的网页: 视觉风格明显区别于之前的通用感, 手机上也能正常浏览
- input: 一个模糊的点子, 如「想给孩子做个背古诗的小工具」, output: 先收到一版设计方案 (做给谁用、整体气质、页面长什么样) 供你确认, 确认后交付成品页面
