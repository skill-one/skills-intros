# anysearch (`anysearch-ai/anysearch-skill/anysearch`)

## blackbox

**function**: 我是你的实时搜索助手: 你给我一个问题、网址或代码(如股票号), 我从互联网上帮你找到最新信息、读出网页内容、查回专业数据。

- input: 一个问题, 如「2025年新能源汽车销量排名」, output: 一份带来源链接的最新搜索结果汇总, 可直接看到各家说法和出处
- input: 一个网页链接, 如某篇新闻或博客的 URL, output: 该页面的正文内容, 已提取成干净的文本, 不用你自己去翻网页
- input: 一个代码或编号, 如股票「AAPL」、论文 DOI 号、航班号, output: 对应的专业数据: 股票实时行情、论文信息、航班动态等
