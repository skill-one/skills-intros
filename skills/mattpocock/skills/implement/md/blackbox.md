# implement (`mattpocock/skills/implement`)

## blackbox

**function**: 把你的需求文档或任务清单直接变成能用的代码，改完就提交，你只管验收。

- input: 一份功能需求文档（如 spec.md 的文件路径）, output: 按文档实现好的代码改动，已提交到当前代码分支，可直接验收
- input: 几条任务工单（如「给用户列表加搜索」「修复登录报错」）, output: 每条工单对应的成品代码，全部做完并提交
- input: 一段改需求的话（如「导出功能改成支持 Excel」）, output: 改好的代码，检查无误后提交
