# grilling (`mattpocock/skills/grilling`)

## whitebox

- 触发: 用户要求拷问 (grill) 自己的计划/决策/想法, 或使用 'grill' 类触发词
- 建模: 把话题映射成设计树 (design tree) —— 每个决策分叉出挂在它下面的子决策
- 每轮提问: 计算 frontier (前置条件已确定、现在就能问的问题), 一轮内全部抛出, 每题编号并附上我的推荐答案
- 等待与推进: 用户作答后答案重塑树结构, 已定的决策推开 frontier, 重新计算并进入下一轮
- 终止: frontier 清空 (所有分支已走完, 无沉默假设), 经用户确认达成共识后, 才开始行动

- frontier 机制: 每轮只问前置已定的问题; 一个问题的答案若依赖本轮另一个未决问题, 就推迟到后续轮次, 保证无猜测提问
- 事实/决策分离: 事实 (环境里的信息, 如文件系统、工具) 我自己查, 必要时派 sub-agent 去找且不阻塞本轮其他问题; 决策永远交还用户
- 固定轮次格式: 每轮按模板输出 '❓ Q 编号 - 标题: 问题正文' + '➡️ 推荐答案', 不引入额外外部工具/库/模型依赖
