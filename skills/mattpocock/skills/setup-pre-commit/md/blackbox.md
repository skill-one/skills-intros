# setup-pre-commit (`mattpocock/skills/setup-pre-commit`)

## blackbox

**function**: 给代码仓库装上"提交前质检": 以后每次 git commit 前自动整理代码格式、做类型检查、跑测试, 有任何一项不过关就拦下提交并报错。

- input: 在仓库根目录说一句: "给我的项目加上提交前检查", output: 仓库配置完成并完成一次验证性提交; 之后每次 git commit 自动做三件事: 修正格式 → 类型检查 → 跑测试, 全过才让提交成功
- input: git commit 时改动了几个代码文件, 但其中一处有类型错误或测试挂了, output: 这次提交被拦下, 终端里看到具体报错位置, 修好后才能提交成功
- input: 一个没有配置类型检查或测试命令的项目, output: 只保留提交前自动格式化, 并明确告诉你"测试/类型检查脚本不存在, 已跳过", 不硬塞、不报错卡死
