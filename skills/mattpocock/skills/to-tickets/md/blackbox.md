# to-tickets (`mattpocock/skills/to-tickets`)

## blackbox

**function**: 把一份计划、需求或规格说明, 拆成一串能直接开工的开发任务卡, 每张卡标清「先完成哪些才能做这张」, 并发布到你的任务看板。

- input: 一段产品构想, 如: 「给博客加评论功能, 支持回复和审核」, output: 一份带编号的任务清单草稿, 每条含标题、前置依赖、做完能演示什么; 你确认粒度后才正式发布
- input: 一个 GitHub issue 链接 (或本地 .md 需求文档路径), output: 在同一追踪器上新建的一组任务, 每张卡用平台原生链接标明「被谁阻塞」; 选本地文件的话, 则在 .scratch 目录下一张卡一个 md 文件
- input: 一段含大型改动的计划, 如「把全项目的 user_id 字段改名」, output: 拆成「先加新、再分批换、最后删旧」的三阶段任务序列, 保证每一步做完项目都还能正常跑
