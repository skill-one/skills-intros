# tdd (`mattpocock/skills/tdd`)

## blackbox

**function**: 带你用「测试先行」的方式开发功能或修 bug：先写一个能验证行为的测试，看着它失败，再写刚好让它通过的代码，交付时功能和测试一起到手。

- input: 一句话需求，如「给购物车加个结算功能」, output: 能跑通的结算代码 + 一套读起来像规格说明的测试（如「有效购物车可结算」），每一步都是测试先红、代码让它变绿
- input: 一条 bug 描述，如「用折扣码后金额算错了」, output: 先给一个能复现这个 bug 的失败测试，再给修复后的代码，测试由红转绿，证明 bug 真的修好了
- input: 现有代码 + 「这段逻辑之后要常改，帮我加个保险」, output: 写在对外接口上的测试文件：之后怎么重构内部实现，只要行为没变，测试就不会误报
