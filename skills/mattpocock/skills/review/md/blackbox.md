# review (`mattpocock/skills/review`)

## blackbox

**function**: 给一段代码改动 (从某个节点到现在的全部变更) 出一份"体检报告":一边检查代码写法是否守规矩,一边检查是否真的做对了需求方要的事。

- input: 一句「帮我 review 这个分支,从 main 开始」, output: 一份评审报告,分两栏:①写法问题 (如重复代码、命名含糊、违反项目规范的具体位置);②需求问题 (哪些要求没做、哪些是没让做的、哪些疑似做错了),每条附代码位置
- input: 一个 commit 编号或标签,如 abc1234 或 v1.2.0, output: 该节点之后所有改动 (含提交列表) 的评审报告,同样分「写法」与「需求」两部分
- input: 一个分支名 + 需求文档/issue 路径 (如 docs/spec.md 或 issue #45), output: 逐条对照该文档的核对结果:缺了什么、多做了什么、哪里看起来做了但实现有误,并引用原文对应条目
