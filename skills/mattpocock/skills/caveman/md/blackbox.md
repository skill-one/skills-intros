# caveman (`mattpocock/skills/caveman`)

## blackbox

**function**: 把你给的任何问题或文本压缩成 ~25% 长度的极简回答——废话全砍,技术内容一个字不少。说 "caveman" 即开启,全程生效。

- input: 「为什么这个 React 组件一直在重渲染?」, output: 「Inline obj prop → 新引用 → 重渲染。用 useMemo。」(两行,原因和修法都有)
- input: 500 字的会议记录或长文档, output: ~100 字的压缩版,要点、数字、结论全部保留,只删套话
- input: 粘贴一段报错信息,问「这怎么修?」, output: 一句话指出出错位置 + 一行修复代码,无寒暄
