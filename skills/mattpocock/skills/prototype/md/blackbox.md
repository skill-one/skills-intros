# prototype (`mattpocock/skills/prototype`)

## blackbox

**function**: 把"这么设计到底行不行"的口头争论, 变成一个你能亲手点着玩的临时演示, 玩完直接给出结论。

- input: 一段规则描述 + 疑问, 例: "会员等级按这样升级/降级, 逻辑对吗?", output: 一个双击就能打开的演示网页: 有"付费/到期/申诉"等按钮, 每点一下立刻显示等级和状态的变化, 试几步就知道逻辑顺不顺
- input: 一个页面想法 + 犹豫, 例: "首页横幅区到底该做成什么样?", output: 同一个网址下好几版长相完全不同的页面, 点底部的切换条挨个对比, 直到选出顺眼的那版
- input: 一个二选一的取舍问题, 例: "弹窗确认和行内确认, 哪个更不容易误删?", output: 能左右对比操作的演示 + 一句明确的结论, 如: "行内确认更容易误触, 用弹窗"
