# loop-me (`mattpocock/skills/loop-me`)

## blackbox

**function**: 陪你把一件反复要做的事(周报、回邮件、晨间规划……)盘问成一份可交给 AI 或助手执行的流程说明书——每轮提问都附建议答案,问到没有任何模糊处才算完。

- input: "每周一我要花一小时整理上周进度、排本周任务,想把这事交出去。", output: 几轮关键追问(每题带建议答案),最后一份定稿的流程说明书:什么时候自动运行、用什么数据、产出什么、哪一步留给你过目
- input: "客户来邮件时,希望先起草回复,我看过再发。", output: 一份完整的流程说明:新邮件触发 → 回复稿备好 → 你确认一次要点 → 发送,模糊处全在提问环节被补齐
- input: (只有一句)"帮我看看我生活里有什么值得交出去的事。", output: 从你的工作与日常里挑出的重复模式清单,按值得交出去的程度排序,你挑一个开始盘
