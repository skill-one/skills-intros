# design-an-interface (`mattpocock/skills/design-an-interface`)

## blackbox

**function**: 给任何软件模块或接口设计需求, 一次性给出几套截然不同的方案, 并告诉你每套的用法示例和利弊对比。

- input: 「帮我设计一个购物车模块的接口」, output: 3~4 套完全不同的接口方案: 每套含方法签名、实际调用代码示例、各隐藏了什么复杂度、优缺点
- input: 「我们要做一个消息通知模块, 调用方有手机 App 和后台定时任务, 有什么设计思路」, output: 几套可选的接口形状 (从极简 1~2 个方法到高度灵活的多用途版), 附各场景下的使用示例和取舍分析
- input: 一段现有模块的功能描述 + 「多想几个方案对比一下」, output: 一份对比分析: 哪套最贴合你的主要使用场景、哪套最容易用错、哪几套的优点可以组合
