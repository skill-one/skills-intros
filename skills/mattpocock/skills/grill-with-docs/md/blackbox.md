# grill-with-docs (`mattpocock/skills/grill-with-docs`)

## blackbox

**function**: 把你的方案或设计盘问到没有含糊之处:用连环追问逼你补齐漏洞和模糊点,边问边替你留下文档——关键决策记录(每个重要选择"为什么这么定")和术语表(统一大家的用词)。

- input: 一段粗糙的想法:「想给团队做个周报机器人」, output: 一连串追问:谁来填?催谁?漏交怎么办?你逐条答完后,拿到一份漏洞补齐、可以直接开工的定稿方案
- input: 一份技术设计文档(.md 文件), output: 指出文档里所有说不清、自相矛盾的地方;每敲定一个关键选择(比如「为什么选这个数据库」),就多出一条「为什么这么定」的决策记录,事后可查
- input: 评审会前丢过来的新功能提案, output: 会前收到一份提案里没人想清楚的问题清单 + 一份团队共用的术语表,开会不再为「同一个词各自理解」吵半天
