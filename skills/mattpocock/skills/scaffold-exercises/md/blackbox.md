# scaffold-exercises (`mattpocock/skills/scaffold-exercises`)

## blackbox

**function**: 拿到一份课程大纲或一句话需求, 帮你把编程课程的练习骨架 (章节文件夹 + 练习文件夹 + 说明文件) 一次性建好, 保证通过课程项目的规范检查。

- input: 一段课程计划文本, 如: 「05 章 记忆技能: 05.01 记忆入门; 05.02 短期记忆 (含题目+答案+讲解); 05.03 长期记忆」, output: 一套按编号排好的练习文件夹, 每个文件夹里带写好标题的 readme 说明文件, 运行课程自带的检查命令一次通过
- input: 一句话, 如: 「给 05 章新增一个练习 05.04 检索增强」, output: 新建好的对应文件夹和 readme 存根 (含标题和一句描述), 可直接开始填内容
- input: 一条调整指令, 如: 「把 01.03-embeddings 顺序改到 01.04」, output: 目录被重命名并保留 git 历史记录, 重跑检查依然通过
