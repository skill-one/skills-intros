# zoom-out (`mattpocock/skills/zoom-out`)

## blackbox

**function**: 看不懂某段代码时, 帮你"拉远镜头": 不抠细节, 而是画一张它所在项目的大地图——它属于哪个模块、谁在调用它、和哪些部分相连, 用项目自己的术语讲明白。

- input: 贴出一段看不懂的代码 + 一句「这玩意是干嘛的?」, output: 一段高层解释: 这段代码在整个系统里处于哪一层、上游是谁、下游是谁, 配上相关模块和调用方的清单
- input: 「接手了同事的支付模块, 完全没头绪, 先看哪里?」, output: 该模块的整体地图: 相关模块一览、调用关系、阅读顺序建议 (先看入口、再看核心流程)
- input: 「我想改这个函数, 但怕牵一发动全身」, output: 影响范围说明: 哪些模块、哪些调用方依赖它, 改动大概会波及到哪几处
