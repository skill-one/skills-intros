# write-a-skill (`mattpocock/skills/write-a-skill`)

## blackbox

**function**: 把你想让 AI 掌握的一项任务, 打包成一份 AI 装上就会照做的「任务说明书」(即 skill 技能包), 让 AI 下次遇到这类活儿时自动按你的规矩干。

- input: 一句话需求, 如:「我要一个技能: 以后丢给它 PDF, 它就自动提取内容并出中文摘要」, output: 一份可直接安装的技能说明书, AI 装上后见到 PDF 就会自动提取内容、按你的格式出摘要
- input: 只说清领域和场景, 如:「做个写周报的技能, 要能从 Git 提交记录汇总成本周进展」, output: 先向你追问关键细节, 再给出技能草稿; 你确认或提出修改后, 拿到定稿
- input: 一段你现有的工作流程描述, 如「我们审代码的规矩是: 先跑测试, 再查安全漏洞, 最后按模板写报告」, output: 按这套流程整理成的技能文件: 写明什么情况下触发、每步怎么做, 复杂细节会拆成配套的参考文档或小脚本
