# research (`mattpocock/skills/research`)

## whitebox

- 触发条件: 用户想调研某个主题、收集文档/API 事实、或把阅读查证工作外包出去
- 派出一个后台代理 (background agent) 去做调研, 主对话不被阻塞、继续工作
- 代理只采信一手来源 (官方文档、源代码、规范、第一方 API), 每条论断都追回到拥有它的那个源头
- 代理把发现写成单个 Markdown 文件, 每条论断附上来源引用
- 按仓库已有笔记惯例选存放位置; 若无惯例则放到合理位置, 并明确告知用户放在哪

- 后台代理机制: 调研整体委托给后台代理异步执行, 保证主对话同时继续工作 —— 这是技能的核心运转方式; 技能未指定任何具体外部工具/库/模型 API, 唯一依赖是平台提供的后台代理能力
- 一手来源回溯: 明确排除二手转述类材料, 只采信官方文档、源代码、规范、第一方 API 等一手来源, 论断必须能追到归属源头
- 带引用的归档: 结果落成单个 Markdown 文件并逐条标注来源, 存放位置匹配仓库既有的笔记惯例, 没有惯例时自行选合理位置并说明
