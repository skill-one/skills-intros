# improve-codebase-architecture (`mattpocock/skills/improve-codebase-architecture`)

## blackbox

**function**: 扫一遍你的代码库, 找出「结构越改越乱」的地方, 生成一份可视化的 HTML 报告告诉你哪里值得重构、为什么、怎么改, 然后陪你把选中的那一条聊成可落地的重构方案。

- input: 一个项目路径 + 一句「帮我看看这个项目的架构」, 或指定某个你头疼的模块 (如「支付这块每次改动都出事」), output: 浏览器里自动打开一份 HTML 报告: 列出 3~5 个可深挖的重构机会, 每条含涉及文件、问题所在、改法、收益、改造前后对比图, 并给出「先做哪个」的首选建议
- input: 从报告里挑一条, 如「就聊第 2 个候选」, output: 一轮针对性的追问对话 (依赖、约束、改成什么样、测试怎么办), 最终敲定具体方案: 哪些文件合并、新接口长什么样、哪些测试保留; 过程中顺手把新术语和关键决策记进项目文档
- input: 一段痛点描述, 如「这块代码谁都不敢碰, 测试也写不了」, output: 聚焦该区域的分析结论: 为什么难改难测、复杂度该往哪收、收完之后哪些原本写不了的测试变得能写了
