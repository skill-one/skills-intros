# wayfinder (`mattpocock/skills/wayfinder`)

## blackbox

**function**: 把一个大到没法一口气做完的模糊想法, 变成挂在你们任务追踪器 (如 GitHub Issues) 上的一张「待决策路线图」🧭, 再逐个帮你敲定上面的问题, 直到整条路线清晰到可以直接动手。

- input: 一句大而模糊的目标, 如「我想把博客系统重构成支持多人协作」, output: 追踪器上的一张地图条目: 写明「做完长什么样」、已定的结论一行一条, 外加一叠待定问题卡——每张卡是一个需要拍板的问题
- input: 地图的链接或编号, 如「继续推进多人协作那张图」, output: 一张问题卡的答案: 该卡下多出一条结论评论并被关闭, 地图的「已定结论」同步多一行; 若答案牵出新问题, 地图上会相应出现新的问题卡
- input: 一张需要「先看到东西再拍板」的问题卡, 如「导航栏的交互到底怎么定」, output: 一份粗糙但能直接点评的草稿——内容大纲、界面草图或示意代码——供你拍板或提修改意见, 最终结论记回这张卡
