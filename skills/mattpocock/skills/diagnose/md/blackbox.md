# diagnose (`mattpocock/skills/diagnose`)

## blackbox

**function**: 接手「反复修不好的 bug」和「突然变慢的性能问题」: 你给我出问题的代码和现象描述, 我还你真正的原因、修好的代码, 以及一个防止它复发的测试。

- input: bug 描述 + 代码仓库 (如: "下单按钮时好时坏, 十次里挂一次, 代码在 ./shop"), output: 修好的代码 + 一个能稳定触发这个 bug 的测试 (修复后它通过, 防止以后再犯) + 一段人话根因说明: 哪一行错了、为什么错
- input: 性能问题 + 相关代码 (如: "上周起首页接口从 200ms 变成 3 秒, 代码在 ./api"), output: 定位报告: 具体是哪一步在拖时间、慢了多少、从哪次改动引入的 + 优化后的代码 + 修复前后的耗时对比数据
- input: 一段报错信息/日志 + 项目路径 (如: 贴上一段堆栈跟踪), output: 指出报错真正来源的代码位置 (往往不是日志指向的那个文件) + 修复改动 + 说明为什么会走到这条错误路径
