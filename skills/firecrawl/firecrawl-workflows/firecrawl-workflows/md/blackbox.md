# firecrawl-workflows (`firecrawl/firecrawl-workflows/firecrawl-workflows`)

## blackbox

**function**: 把网上的公开信息直接变成你能用的成品——调研报告、竞品分析、SEO 体检、客户名单等, 不只是抓网页, 而是交付结论。

- input: 一个网址, 如 https://example.com, output: 一份该网站的 SEO 体检报告: 问题页面清单、关键词表现、逐条改进建议
- input: 一句话主题, 如「2025 年东南亚电动车市场」, output: 一份带来源引用的市场调研报告: 摘要 + 数据分析 + 建议
- input: 5 个竞品官网的网址, output: 一份竞品对比报告: 各家定价、功能差异、近期产品更新
- input: 一个在线文档站的地址, output: 整理好的结构化知识库文件, 可直接用于 AI 问答或内部搜索
- input: 一家公司名称 + 你要见面的场合, output: 一份会前简报: 对方业务、团队、近期动态、可切入的话点
