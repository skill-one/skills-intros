# firecrawl-qa (`firecrawl/firecrawl-workflows/firecrawl-qa`)

## blackbox

**function**: 给我一个网址, 我像真实用户一样去点、去填、去试, 最后给你一份「哪里有问题、怎么修」的网站测试报告。

- input: 一个网址 + 「上线前帮我全站检查一遍」, output: 一份完整测试报告: 网站健康评分 (如 7/10)、测过的页面清单、按严重程度分级的问题列表 (致命/重要/小问题), 每个问题附截图证据和复现步骤
- input: 一个网址 + 「重点测注册和登录表单」, output: 表单测试报告: 正常流程能不能走通、乱填/留空/超长输入会怎样、错误提示是否清晰, 逐条列出发现的 bug
- input: 一个网址 + 「看看手机上用起来正不正常」, output: 手机/平板/电脑三端检查报告: 指出哪一页布局错乱、按钮点不到、文字被截断, 附具体页面位置和现象描述
