# design (`nextlevelbuilder/ui-ux-pro-max-skill/design`)

## blackbox

**function**: 一个设计成品生成器: 你说出想要什么 (Logo、品牌视觉、社交媒体图片、图标、演示文稿), 它直接给你能用的成品文件。

- input: 一句话品牌描述, 如「品牌叫 TechFlow, 做企业软件的, 想要简洁专业的 Logo」, output: 几张不同风格的白底 Logo 图片, 挑中意的拿去用
- input: 一张 Logo 图片 + 需求, 如「用这个 Logo 做名片、信纸和手机壳效果图」, output: 印着你 Logo 的名片、信纸、周边实拍风格效果图 (图片文件)
- input: 平台和主题, 如「给 Instagram 做一张咖啡新品的宣传图」, 或「购物车图标, 线条风格」, output: 对应平台尺寸的宣传图文件 / 可任意缩放的 SVG 图标文件
