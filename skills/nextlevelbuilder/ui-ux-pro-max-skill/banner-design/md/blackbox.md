# banner-design (`nextlevelbuilder/ui-ux-pro-max-skill/banner-design`)

## blackbox

**function**: 帮你设计各类横幅/封面图,交给我平台、尺寸和文案,我给你直接能用的成图 PNG。

- input: 「Twitter 头图,极简风,文案:AI 建站工具,一句话上线」, output: 3 张 1500×500 的不同设计稿 PNG,风格各异,挑一张直接上传
- input: 「Instagram 发帖图 1080×1080,照片背景,写上『限时五折』」, output: 促销横幅 PNG,已按平台尺寸裁好,文字清晰可读
- input: 「网站首页大图,科技感,标题『云端数据平台』+ 按钮『免费试用』」, output: 1920×600 的 Hero 横幅 PNG,含标题、按钮排版,附每种方案的设计说明
