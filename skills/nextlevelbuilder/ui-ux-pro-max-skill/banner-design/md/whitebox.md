# banner-design (`nextlevelbuilder/ui-ux-pro-max-skill/banner-design`)

## whitebox

- AskUserQuestion 收集需求: 用途、平台/尺寸、文案、品牌素材、风格、数量 (默认 3 版)。
- 读取打包的 references/banner-sizes-and-styles.md, 确定精确尺寸、安全区和 2~3 个互补艺术方向。
- 按目标平台精确像素尺寸逐个方向编写 HTML/CSS 横幅, 文案/logo 用 CSS 叠加, 视觉取自用户素材或纯 CSS 构建 (有授权图像生成能力时可选)。
- 浏览器按精确目标视口预览并截取横幅元素为 PNG, 校验像素尺寸、安全区裁切、字体加载与画质。
- 并排展示各选项的风格名、预览、设计理由与文件路径, 按用户反馈迭代直至定稿。

- 规格单一数据源 + 硬校验: 尺寸/安全区/风格全部由打包的 references/banner-sizes-and-styles.md 推导; 校验规则固定为关键内容居中 70~80% 安全区、单一 CTA 右下且高 ≥44px、字体 ≤2 款、正文 ≥16px、标题 ≥32px、文字对比度 ≥4.5:1、广告文字占比 <20% (Meta 惩罚重文字)。
- HTML/CSS 作为中间产物保证可编辑性: 文案始终留在 HTML 层, 生成图像的 prompt 强制排除任何文字字母; 视觉源优先级为用户/合规授权素材 > 渐变与几何等纯 CSS 构建 (零依赖) > 可选授权图像生成。
- 导出与降级机制: 依赖运行时标准浏览器/截图能力在目标视口截图导出 PNG; 截图能力不可用时交付 HTML/CSS 源码并明确标记 PNG 待导出; 文件超平台体积上限则用可用图像优化器降质或缩尺寸。
