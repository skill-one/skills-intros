# ckm:design (`nextlevelbuilder/ui-ux-pro-max-skill/ckm:design`)

## blackbox

**function**: 我是设计师: 告诉我品牌或需求, 我直接交付能用的成品 — logo、名片信纸等企业用品、宣传图、演示幻灯片、图标。

- input: 「我的奶茶店叫茶语, 想要一个清新、手写感的 logo」, output: 若干款 logo 图片供挑选, 白底、可直接使用
- input: 一个 logo 图片 + 「帮我配一套名片和信纸」, output: 名片、信纸等设计效果图, 和你的 logo 风格统一, 可拿去印制
- input: 「周五要向投资人讲方案, 这是产品数据」, output: 一份演示幻灯片, 打开即可放映, 数据自动变成图表
- input: 「新品上市, 给 Instagram 和朋友圈各做一张宣传图」, output: 每个平台一张尺寸正确的成品图, 直接发布即可
- input: 「给 App 做一组图标: 首页、搜索、购物车、我的」, output: 风格统一的矢量图标文件, 放大到任意大小都不糊
