# ckm:ui-styling (`nextlevelbuilder/ui-ux-pro-max-skill/ckm:ui-styling`)

## blackbox

**function**: 帮你把网页和应用界面做得好看又好用——给一个需求或一段现有代码, 你拿到能直接运行的界面代码或成品设计图。

- input: 一句话需求, 如「做一个带邮箱格式校验的登录页」, output: 能直接运行使用的网页代码: 输入框、报错提示、按钮样式齐全, 手机和电脑上看都正常
- input: 现有的页面代码文件 + 「加上夜间模式」, output: 改好的代码, 页面可跟随系统或按钮一键切换明暗, 各页面风格保持统一
- input: 代码文件 + 「手机上按钮挤成一团」, output: 修复后的代码, 界面在小屏手机和大屏电脑上都排版整齐
- input: 一段描述, 如「给我的咖啡店做一张开业宣传海报」, output: 一张排版、配色、字体都处理好的成品海报图
