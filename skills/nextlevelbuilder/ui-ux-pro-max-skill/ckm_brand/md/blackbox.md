# ckm:brand (`nextlevelbuilder/ui-ux-pro-max-skill/ckm:brand`)

## blackbox

**function**: 帮你建立并守住品牌的「统一形象」:定语调、定配色定字体、写品牌手册,并检查所有文案和素材是否与品牌规范一致。

- input: 你的品牌基本信息(名称、定位、目标用户、想要的风格), output: 一份完整的品牌指南文档:语气规范、配色方案、字体规格、信息框架
- input: 一段营销文案,如「限时钜惠,错过再等一年!!」, output: 按品牌语气改写后的文案,并附不符点说明(如语气过于促销腔)
- input: 一张素材文件的路径,如 logo-v2_最终版.png, output: 合规检查结果:命名、尺寸、格式是否符合规范,不合规处列出整改项
