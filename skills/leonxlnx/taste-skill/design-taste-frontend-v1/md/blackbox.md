# design-taste-frontend-v1 (`leonxlnx/taste-skill/design-taste-frontend-v1`)

## blackbox

**function**: 你用一句话描述想要的网页界面, 我直接产出能运行的前端代码——打开就是一个设计感在线、会动、不像模板货的现代页面。

- input: 「帮我做一个咖啡品牌的官网首页, 要有质感」, output: 完整可运行的网页代码: 不对称排版、大字标题、滚动时元素渐次浮现, 浏览器打开即是成品首页
- input: 一个 React 组件文件 (如登录页), output: 重做后的组件代码: 换掉烂大街的字体配色, 补上加载骨架、空状态、报错提示等交互细节, 并附上需要安装的依赖命令
- input: 「做一个 SaaS 产品的功能介绍区块」, output: 一整块「苹果控制中心」式的非对称格子界面代码, 每张卡片自带循环动画 (如自动排序的列表、会打字的搜索框)
