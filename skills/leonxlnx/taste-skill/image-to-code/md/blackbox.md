# image-to-code (`leonxlnx/taste-skill/image-to-code`)

## blackbox

**function**: 把你的网站点子变成一个真正能打开的高级感网页：先画出页面效果图给你看，再照着图把代码写出来。

- input: 一句话需求："帮我做一个咖啡品牌落地页，要简洁有质感", output: 几张清晰的页面设计效果图（首页长什么样、配色、字体、布局），外加一个双击就能在浏览器里打开的成品网页
- input: 已知的页面结构，如："5 个板块：头图、产品介绍、用户评价、价格、页脚", output: 每个板块一张大而清晰的效果图 + 完整实现好的网页，视觉与效果图高度一致
- input: 改版需求："我的个人作品集网站太普通了，重做得更有设计感", output: 新版设计效果图 + 重写后的网页文件，直接替换原来的用
