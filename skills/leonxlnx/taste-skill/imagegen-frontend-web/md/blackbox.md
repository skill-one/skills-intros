# imagegen-frontend-web (`leonxlnx/taste-skill/imagegen-frontend-web`)

## blackbox

**function**: 你说一个网站想要什么, 我给你一套可以照着做的高质量网页设计参考图——每个区块一张横向大图, 像设计总监交出的整页方案。

- input: 「帮一个精品咖啡品牌做落地页, 8 个区块」, output: 8 张横向设计参考图, 每张对应一个区块 (首屏、品牌故事、产品菜单、门店信息、评价、底部 CTA 等), 整套配色、字体、风格统一, 开发可直接照图还原
- input: 「一个 SaaS 数据分析产品的官网首页」, output: 6 张横版区块图: 首屏、信任栏、功能展示、核心指标、用户评价、行动号召, 每张清晰呈现布局、文字层级和按钮位置
- input: 「只要一个极简风的 hero 首屏」, output: 1 张横版极简首屏设计图: 大量留白 + 一句短标语 + 细线条按钮, 干净到可以直接抄
