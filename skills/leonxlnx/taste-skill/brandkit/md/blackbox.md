# brandkit (`leonxlnx/taste-skill/brandkit`)

## blackbox

**function**: 你给我一个品牌名或一段产品描述, 我直接产出一张像专业设计公司交付的品牌手册大图——logo、配色、字体、应用样机、氛围影像都在一张版面里。

- input: 「帮我给一个叫 Nomad 的远程协作工具做品牌视觉」, output: 一张 3×3 品牌手册风格大图: 主 logo、logo 构图拆解、浏览器/终端界面应用、标语、色板、字体样张、名片/徽章物料、氛围影像、系统细节九个版块, 可直接当提案展示
- input: 「Vaultline, 网络安全公司, 深色科技风」, output: 一张完整品牌形象板图片: 围绕「守护/警戒」设计的原创 logo、深色盘配色、一句短标语、UI 与徽章应用, 整体像安全公司的高级视觉提案
- input: 「参考这张手册的排版质感, 给我的咖啡品牌做一套, 用 2×2 版式」(附一张参考图), output: 一张 2×2 紧凑概念板: 学习参考图的节奏与质感但不抄袭其内容, 含 logo、一句品牌主张、色卡与实物应用样机
