# industrial-brutalist-ui (`leonxlnx/taste-skill/industrial-brutalist-ui`)

## blackbox

**function**: 把普通网页做成「工业蓝图 + 军用终端」风格的硬核界面——粗黑大字、外露网格线、扫描线噪点,适合数据仪表盘、作品集、编辑类网站。

- input: 一句话需求:「给我的个人作品集做一个暗色终端风首页」, output: 一个能直接双击打开的网页文件:黑底白字、等宽字体、扫描线效果、网格分栏,内容就是你提供的作品信息
- input: 一个现有的 HTML 页面(或页面截图描述), output: 同一页面但换成工业硬核风格:超大加粗标题、可见的分隔线、纸张白/警报红配色,内容不变
- input: 产品名 + 一组数据(如服务器监控指标、销量数字), output: 一页数据密集的仪表盘网页:巨型数字标题、表格化数据排列、关键项用红色标出
