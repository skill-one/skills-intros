# redesign-existing-projects (`leonxlnx/taste-skill/redesign-existing-projects`)

## blackbox

**function**: 把你已经能用的网站或应用变得看起来更高级、更有质感——功能不动, 只升级观感。

- input: 一个已经能正常运行、但界面普通的网站项目, output: 同一个项目的升级版: 打开后字体更有气质、配色统一顺眼、按钮悬停和点击都有反馈——功能一切照旧, 不用改任何业务代码
- input: 你的网站链接或页面截图 + 一句「这页面看起来像 AI 做的/显得廉价」, output: 一份逐条的问题诊断: 具体指出哪里露馅 (如默认字体、扎眼的渐变、三栏等宽卡片、写死的假数据), 以及每条该怎么改
- input: 一段现有的页面代码 (如 index.html 或样式文件), output: 改好的同款代码文件, 直接替换回去就能跑: 排版更有层次、间距更舒展、缺的状态 (如加载中、报错提示) 补齐
