# smart-search (`jackwener/opencli/smart-search`)

## blackbox

**function**: 你给我一个想查的问题或线索，我从合适的网站和内容源帮你找到信息，最后给你一份带来源的结果汇总。

- input: 一段自然语言提问，如「最近中文互联网上关于新能源汽车价格战大家在讨论什么？」, output: 一份要点式回答：各方观点摘录 + 每条信息标注了出处（哪个网站/帖子）
- input: 指定平台的查找请求，如「在 GitHub 上找近一个月 star 增长最快的 AI Agent 项目」, output: 来自该平台的项目清单：项目名、简介、链接、热度数据
- input: 一个带场景条件的查询，如「帮我对比 3 月东京 vs 大阪 4 晚酒店的大致价格」，或「找北京月薪 2 万以上的 Python 岗位」, output: 满足条件的具体结果列表：价格区间/职位链接等，末尾附一段「搜索摘要」说明查了哪些网站、用了什么关键词、各查了几次
