# remotion (`google-labs-code/stitch-skills/remotion`)

## blackbox

**function**: 把你的 Stitch (Google 的 AI 界面设计工具) 项目里的一组设计稿, 变成一段自动播放的讲解视频: 界面按顺序出现, 带平滑切换、放大特写和文字说明, 最终交付一个可直接播放的 MP4 文件。

- input: 一句话指令: 「把我的 Stitch 项目『Calculator App』做成一个界面走查视频」, output: 一个 MP4 视频文件: 按顺序播放各界面截图, 界面间淡入淡出切换, 每屏底部带标题文字 (如「首页 - 计算器主界面」), 顶部有进度条
- input: 同一项目 + 一句要求: 「重点展示历史记录按钮在哪」, output: 视频里在对应位置出现放大的镜头特写, 并带一个动画脉冲圈指向该按钮, 配文字标注「点这里查看历史记录」
- input: 项目 + 节奏要求: 「每屏停 5 秒, 用左右滑动切换」, output: 按你的节奏重新生成的成片: 每个界面停留 5 秒, 界面间以左右滑动方式过渡
