# show-me (`humanlayer/skills/show-me`)

## blackbox

**function**: 把你在聊的话题变成一张直观的图——调用流程、结构关系、改动对比或一个能点开的网页演示——让你一眼看懂, 而不是读大段文字。

- input: 一句提问, 如「HTTP 请求从发出到收到响应中间发生了什么?」, output: 一张时序图: 浏览器 → DNS → 服务器 → 返回数据, 每步谁先谁后一目了然
- input: 一段现有代码 + 一句改动想法, 如「我想在这里加个缓存」, output: 一张改动对比图 (diff 样式): 左右标出改前/改后的逻辑差异, 红绿高亮哪几行变了
- input: 一个项目文件夹路径, output: 一张目录树状图: 每个文件夹/文件旁标注它负责什么, 整个项目分工一眼看清
- input: 一个抽象概念, 如「事件循环是怎么转的」, output: 一个浏览器打开的交互式 HTML 演示页: 动画展示任务队列进出, 可以自己点着看
