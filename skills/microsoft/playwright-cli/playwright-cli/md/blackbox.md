# playwright-cli (`microsoft/playwright-cli/playwright-cli`)

## blackbox

**function**: 我能替你操控一个真实浏览器：打开网页、点击、填表、登录、截图、抓内容，像真人一样完成网页上的各种操作。

- input: 一个网址 + 一句指令，如「打开这个页面帮我提交报名表」, output: 浏览器自动填完表单并提交，附上操作前后的页面截图确认
- input: 网站账号密码 + 「帮我登录并导出后台的订单列表」, output: 登录成功后的订单数据（文本/文件），全程无需你动手
- input: 「这个网页为什么打不开/报错？」+ 出问题的网址, output: 页面的报错信息和网络请求记录，告诉你卡在哪一步
