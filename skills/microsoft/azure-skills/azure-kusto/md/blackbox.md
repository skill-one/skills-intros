# azure-kusto (`microsoft/azure-skills/azure-kusto`)

## blackbox

**function**: 你存放在 Azure Data Explorer (微软云上的大数据分析服务) 里的日志和监控数据, 我帮你查出来、算清楚、画出趋势——你用大白话提需求, 我给数据和结论。

- input: 给出集群和库名, 问:「我的数据库里有哪些表?」, output: 表名清单, 以及每张表有哪些字段、字段是什么类型 (时间、数字、文本等)
- input: 「查一下最近 1 小时的错误日志」, output: 一张错误记录表: 每条错误的时间、级别、报错内容, 按时间倒序排好, 直接可读
- input: 「过去 24 小时接口响应时间表现如何?」, output: 按 5 分钟分段汇总的统计表/趋势图 (平均值、95 分位耗时等), 并标出明显变慢的异常时段
