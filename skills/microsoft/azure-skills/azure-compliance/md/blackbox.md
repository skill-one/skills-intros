# azure-compliance (`microsoft/azure-skills/azure-compliance`)

## blackbox

**function**: 给你的 Azure 云资源做"安全体检":扫描哪些配置不符合最佳实践、哪些资源闲置浪费钱,并检查密钥保管库 (Key Vault, 存放密码/证书的保险箱) 里有哪些证书或密码已过期、快过期。

- input: 一句指令 + 订阅 ID 或资源组名, 如「帮我扫描订阅 xxx-123 的合规情况」, output: 一份体检报告: 列出哪些资源配置有问题、哪些资源闲置没在用, 按严重程度 (紧急/高/中/低) 分级, 每条附修复建议
- input: 「看看我的密钥保管库 kv-prod 里未来 30 天内有什么要过期」, output: 一张清单: 已过期的和 30 天内到期的证书、密钥、密码, 逐条标明到期日期, 避免证书过期导致业务中断
- input: 「查一下哪些密码没有设置过期时间」, output: 没设到期日期的密码列表, 逐条标注这是一项合规风险, 建议补充过期策略
