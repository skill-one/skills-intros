# appinsights-instrumentation (`microsoft/azure-skills/appinsights-instrumentation`)

## blackbox

**function**: 教你如何给托管在 Azure 上的网站应用接入监控 (Application Insights, 微软的应用监控服务): 回答"怎么接、改哪里、怎么配", 给出具体方案和代码示例。注意: 只提供指导, 不直接改动你的代码。

- input: 我的 ASP.NET Core 应用部署在 Azure App Service 上, 怎么开启 Application Insights?, output: 一份接入方案说明: 推荐的接入方式、具体步骤要点和注意事项
- input: 我的 Node.js 应用想手动接入监控, 需要改哪些代码?, output: 手动接入指导: 先在 Azure 上创建什么资源、代码里加什么, 附可参考的示例代码片段
- input: 监控数据里的 Trace、Dependency 都指什么? 如何设置采样比例?, output: 概念解释 + 对应配置项的参考说明
