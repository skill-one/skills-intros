# azure-ai (`microsoft/azure-skills/azure-ai`)

## blackbox

**function**: 我能帮你在自己的资料库里做智能搜索, 以及声音和文字的互相转换: 把录音转成文字稿、把文字念成语音、把图片/扫描件里的文字抠出来。

- input: 一句搜索请求, 如「帮我找和报销流程相关的文档」, output: 从你的文档库里检索出的最相关内容清单 (支持按意思搜, 不只是按关键词匹配)
- input: 一段会议录音音频文件, output: 对应的文字稿, 可标注谁在什么时候说了什么
- input: 一段文本, 如产品介绍或文章, output: 对应的语音音频文件, 可选不同音色朗读
- input: 一张扫描件或含文字的照片, output: 提取出来的可编辑文字文本
