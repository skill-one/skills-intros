# azure-kubernetes (`microsoft/azure-skills/azure-kubernetes`)

## blackbox

**function**: 帮你在 Azure 上规划并创建一个安全、稳定且省钱的容器集群 (Kubernetes, 管理大量容器化应用的系统), 并标清哪些决定在建好后很难改。

- input: 一段需求描述, 如「要在 Azure 上建个跑生产业务的集群, 20 个节点左右, 预算有限」, output: 一套推荐配置方案 (集群类型、机型、网络、安全、成本各选什么+为什么), 以及可直接执行的创建命令或建好的集群
- input: 一条网络/安全要求, 如「API 只允许公司内网访问, Pod 对外出口要固定 IP」, output: 对应的网络配置方案与设置步骤, 并标注哪些属于「建完就难改」的关键项
- input: 一句痛点, 如「节点经常空闲, 云账单太贵」, output: 一份省钱改造方案 (自动缩容、低优先级便宜节点等) 和具体落地操作
- input: 一句运维需求, 如「集群要升级到新版本, 业务不能中断」, output: 一份分阶段升级计划 (升级时间窗口、先后顺序、安全检查清单)
