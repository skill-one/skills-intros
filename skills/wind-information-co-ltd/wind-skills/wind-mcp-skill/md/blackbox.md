# wind-mcp-skill (`wind-information-co-ltd/wind-skills/wind-mcp-skill`)

## blackbox

**function**: 查询、筛选和验证金融市场数据（股票、基金、指数、债券、宏观指标等），基于权威数据源的真实返回结果回答，不靠记忆编数字。

- input: 「贵州茅台今天最新价多少？」, output: 茅台实时行情：最新价、涨跌幅、成交量等具体数值
- input: 「筛选沪深市场市值超500亿且连续5日上涨的股票」, output: 符合条件的股票名单：代码、名称、市值、累计涨幅，一张可直接用的清单
- input: 「中证500指数现在的PE处在历史什么分位？」, output: 当前PE/PB数值及其历史分位（如「处于近10年35%分位」）
- input: 「中国近10年新能源汽车产销量是多少？」, output: 逐年产量与销量的数据序列，注明单位和统计口径
