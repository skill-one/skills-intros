# vueuse-functions (`antfu/skills/vueuse-functions`)

## blackbox

**function**: 我帮你开发 Vue.js / Nuxt 页面功能：你说想要什么效果（比如深色模式、拖拽、记住登录状态），我直接给你能跑的代码，而且通常比你手写的更短、更少出错。

- input: 一句需求描述：『给我的 Nuxt 博客加个夜间模式切换，用户上次选的模式刷新后还在』, output: 一个完整的切换按钮组件代码，贴进项目就能用，刷新页面后模式保持不变
- input: 粘贴一段臃肿的 Vue 组件代码（里面有你手写的窗口监听、定时器、滚动判断等）, output: 重构后的更精简版本：功能不变，行数明显减少，且不会出现切走页面后监听还在偷偷跑的问题
- input: 一个交互需求：『做一个能被鼠标拖着到处走的悬浮卡片，还能限制在屏幕内』, output: 几行可直接运行的组件代码，卡片即可拖拽且不会拖出屏幕边界
