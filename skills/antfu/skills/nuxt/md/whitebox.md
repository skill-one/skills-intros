# nuxt (`antfu/skills/nuxt`)

## whitebox

- 用户提出 Nuxt 相关任务 (服务端路由、useFetch、middleware、SSR/混合渲染、部署等)
- 将任务匹配到 skill.md 的知识索引 (Core / Features / Rendering / Best Practices / Advanced 五大类)
- 按索引定位并查阅对应的 references/*.md 详细参考文档
- 遵循 Nuxt 4.x 约定 (如 srcDir 默认为 app/、~ 指向 app/) 输出方案与代码

- 两级知识结构: skill.md 只作主题索引, 细节在各 reference 文档中按需取用, 不臆造索引外内容
- 官方来源锚定: 知识生成自 github.com/nuxt/nuxt 官方仓库, Nuxt 4.x @ 2026-06-22, 内含 Nuxt 4 目录结构变更说明
- 全栈覆盖: 前端 (文件路由、自动导入、组件、状态) + 后端 (Nitro 服务器引擎、server routes) + 部署 (Vercel/Netlify/Cloudflare) 均有对应参考文档
