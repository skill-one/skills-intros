# improve (`shadcn/improve/improve`)

## blackbox

**function**: 给任何代码项目做「体检 + 开药方」: 找出 bug、安全隐患、性能问题和技术债, 按优先级排好, 并写好可直接照着干的整改计划文档 —— 只诊断不动刀, 绝不改你的代码。

- input: 一个代码项目的文件夹路径, 如 ./my-app, output: 一份体检报告: 问题按优先级排序, 每条注明在哪个文件哪一行、影响多大、修复要花多少功夫; 外加一个 plans/ 文件夹, 里面是几份写好的整改计划文档
- input: 同上, 但指定只要安全: 「审计一下, security」, output: 只聚焦安全的报告: 漏洞清单 (如密钥泄露位置、注入风险), 代码原封不动
- input: 一句需求描述, 如「我想给网站加登录功能」, output: 一份完整施工图: 改哪些文件、分几步、每步怎么验证、什么算做完 —— 交给任何人或 AI 都能照着实现
- input: 一份已生成的计划文件 + 一句「execute 001-xxx.md」(执行它), output: 代码在一个隔离副本里被改好, 随后我逐行检查改动, 给出「通过 / 驳回」的验收结论
