# fastify-best-practices (`mcollina/skills/fastify-best-practices`)

## blackbox

**function**: 帮你从零写出、修好或优化网站/App 后台服务（负责处理请求和数据的服务器程序），写完就能直接运行。

- input: 一句话需求：「帮我做一个用户注册登录的接口」（接口 = App 和服务器之间传数据的通道）, output: 一套可直接运行的 Node.js 服务器代码，包含注册、登录、校验规则，跑起来就能被前端调用
- input: 一段报错的服务器代码，或粘贴的错误日志, output: 修好的代码 + 一句话说明哪里出了问题
- input: 「我想给现有接口加上登录校验，不能让陌生人随便调」, output: 改好的代码：未登录的请求会被拦截，登录后才能访问
- input: 「我的接口响应太慢，帮我提速」, output: 优化后的代码，接口响应明显变快
