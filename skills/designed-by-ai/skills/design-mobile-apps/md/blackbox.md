# design-mobile-apps (`designed-by-ai/skills/design-mobile-apps`)

## blackbox

**function**: 你用大白话描述想要的手机 App 界面, 我帮你设计出成型的界面图, 还能按你要求反复修改, 最后可以变成能直接打开预览的代码。

- input: 一句话需求, 如「帮我设计一个健身打卡 App, 风格清新, 有首页和打卡页」, output: 几张设计好的手机界面图 (可在网页里实时观看设计过程), 风格统一、细节完整
- input: 修改意见, 如「首页顶部加一个搜索栏, 按钮都改成绿色」, output: 更新后的界面图, 你能看到改动前后的效果
- input: 一句「帮我把这些设计变成代码」, output: 每个页面的 HTML 文件, 双击就能在浏览器里打开预览, 也可交给程序员继续开发成真 App
