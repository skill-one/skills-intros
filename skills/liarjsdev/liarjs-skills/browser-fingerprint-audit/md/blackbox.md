# browser-fingerprint-audit (`liarjsdev/liarjs-skills/browser-fingerprint-audit`)

## blackbox

**function**: 给你的浏览器做一次「指纹体检」——测它在网站眼里看起来像不像一个真人的浏览器,给出 0–100 分和具体扣分点清单(指纹 = 网站能看到的设备印象:字体、时区、IP、自动化痕迹等)。

- input: 一句话:「帮我测测我这台电脑的浏览器在网站眼里长什么样」, output: 一份文字报告:总分和评级(85+ 可信 / 60+ 可疑 / 更低 大概率是假浏览器),默认只列失分项和每项一句话的原因,如「自动化标记开启 -40 分」;也可以要求把通过项一并列出
- input: 「只测浏览器本身,别向外发请求」, output: 仅浏览器层面的体检报告;必须联网才能比对的项(如时区和 IP 是否一致)会标注「本次未检查」
- input: 「我有个正在跑的自动化/防关联浏览器,地址是 127.0.0.1:9222,帮我查它露不露馅」, output: 该浏览器的一致性报告:总分、每一处自相矛盾点(如「IP 在洛杉矶,浏览器时区却是上海 -12 分」),以及网络侧看到的形象(IP、运营商、TLS 版本)
