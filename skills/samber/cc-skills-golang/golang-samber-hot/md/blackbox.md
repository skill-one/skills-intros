# golang-samber-hot (`samber/cc-skills-golang/golang-samber-hot`)

## blackbox

**function**: 为 Go 代码接入内存缓存——让高频重复的查询不再每次都打到数据库, 响应变快、数据库压力变小。

- input: 一个 Go 项目路径, 某个接口每次请求都查数据库, 高峰期很慢, output: 修改后的 .go 文件: 查询结果存入内存缓存 (含过期时间), 重复请求直接命中缓存; 并附一段说明: 缓存该存多少条、存多久、为什么这么定
- input: 现有缓存代码 + 一句提问: "命中率只有 40%, 怎么调?", output: 调整后的代码 (更匹配你数据访问规律的淘汰策略和容量), 以及命中率低的可能原因清单
- input: 一段代码: 缓存一过期, 成千上万个并发请求同时砸向数据库, output: 改造后的代码: 缓存未命中时自动回源查询、并发请求合并成一次查询、过期时间随机错开, 避免"缓存失效瞬间打爆数据库"; 高峰期数据库压力指标会随之下降
