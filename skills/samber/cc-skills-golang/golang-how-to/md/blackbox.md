# golang-how-to (`samber/cc-skills-golang/golang-how-to`)

## blackbox

**function**: Go 语言开发全能助手: 给我一个需求、一段代码或一个问题, 交付符合 Go 语言习惯的代码、修复或报告。

- input: 「用 Go 写一个处理用户注册的 gRPC 服务, 要能连数据库」, output: 可直接运行的完整服务代码, 附带测试文件和使用说明
- input: 一个 Go 文件路径 + 「运行到这里就 panic 了, 帮我看看」, output: 问题原因分析 + 修好的代码
- input: 项目目录 + 「帮我做一次安全审查」, output: 安全审查报告: 漏洞清单、风险等级、逐条修复建议
- input: 「A 库和 B 库选哪个? 有没有已知漏洞?」, output: 两者对比结论 + 明确的选型建议, 附各版本已知漏洞情况
