# golang-lint (`samber/cc-skills-golang/golang-lint`)

## blackbox

**function**: 检查你的 Go 代码里的问题(潜在 bug、遗漏的错误处理、风格不统一、安全隐患),自动修好能修的,并帮你定好项目的检查规则。

- input: 一个 Go 项目文件夹 + 一句「帮我检查一下代码质量」, output: 一份问题清单:哪个文件、第几行、什么问题、严重程度;能自动修的直接修好,你拿到的是改完的代码
- input: 一条警告原文,如「utils.go:88:5: lostcancel (govet)」, output: 白话解释这条警告在说什么、要不要紧,并给出修好的代码;若是误报,给一行带理由的忽略标注
- input: 一个还没配检查规则的新 Go 项目, output: 一份项目专属的检查规则文件(.golangci.yml),写明开启哪些检查、忽略哪些,拿去就能用
- input: 一个老项目,一跑检查爆出几百条警告, output: 分类分批清理后的代码(自动修复、错误处理、风格、安全各归各类),附一份每类修了多少条的汇总
