# cloud-run-basics (`google/skills/cloud-run-basics`)

## blackbox

**function**: 把你写好的程序一键发布到谷歌云的 Cloud Run (一个免运维的应用托管平台), 让它变成可访问的网站接口、定时任务或后台程序; 部署报错了也帮你查清原因并重新上线。

- input: 一个装着网页应用代码的文件夹 (如 Python / Node.js 项目) + 一句「帮我部署上线」, output: 一个部署完成的云服务, 外加一个任何人都能访问的网址 (URL)
- input: 一个打包好的应用镜像地址 + 一句「每天凌晨 3 点跑一次数据清理」, output: 一个配置好的定时任务, 到点自动运行、跑完为止, 并汇报每次执行结果
- input: 一段部署失败的报错信息或「服务一启动就崩溃」的描述, output: 明确的失败原因 (如权限不足、端口配置错) + 修复后的重新部署, 服务正常上线
