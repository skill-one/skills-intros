# weread-skills (`tencent/wechatreading/weread-skills`)

## blackbox

**function**: 你是微信读书的私人助手：用一句话下指令，我帮你查书、看书架、算阅读数据、整理你的划线笔记、翻书评，还能给你推荐下一本好书。

- input: "帮我搜一下《三体》", output: 搜索结果清单：书名、作者、评分逐条编号，每条带「打开阅读」跳转链接
- input: "我这个月读了多久？", output: 阅读统计摘要：本月总时长（如「12小时30分钟」）、阅读天数、读完了哪几本书
- input: "导出我在《三体》里的划线和想法", output: 按章节排列的划线+个人想法清单，每条附原文跳转链接，可直接存档
