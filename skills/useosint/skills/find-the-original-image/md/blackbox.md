# find-the-original-image (`useosint/skills/find-the-original-image`)

## blackbox

**function**: 给我一张图片（或一段视频），我帮你查出它最早从哪来：谁最先发布的、什么时候发的、原配的说明是什么——而不仅仅是"网上还有别处也有这张图"。

- input: 一张配文「今晨某市警方行动」的照片, output: 一份溯源结论：该照片其实是三年前另一个国家的新闻图，附上最早发布页面的链接、发布日期和摄影师署名
- input: 网恋对象或「投资导师」发来的个人照片, output: 判定报告：这张脸是否在多个不相干账号、婚恋或招聘网站上反复出现，附各处链接，帮你判断是不是盗图
- input: 公司官网上「CEO」的头像, output: 核查结果：该头像是否为图库模特照（在几十个不相干网站上出现），若是，说明这个人物和这家公司大概率是假的
