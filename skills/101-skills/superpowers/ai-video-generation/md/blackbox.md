# ai-video-generation (`101-skills/superpowers/ai-video-generation`)

## blackbox

**function**: 把你给的文字或图片变成一段视频，也能给已有的视频换景、配音、合成或提高清晰度。

- input: 一段文字描述，如「无人机镜头飞越清晨的森林」, output: 一段几秒钟的视频文件（MP4），画面里带音效
- input: 一张人物照片的链接 + 一段录音, output: 照片里的人开口说话、口型对得上的视频
- input: 一个视频链接 + 一句话指令，如「把背景换成雪山」, output: 改好背景的新视频
