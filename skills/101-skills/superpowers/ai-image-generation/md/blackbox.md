# ai-image-generation (`101-skills/superpowers/ai-image-generation`)

## blackbox

**function**: 你用文字描述想要的画面, 我把它变成一张图片; 也能按要求修改现有图片, 或把模糊小图变成高清大图。

- input: 一段画面描述, 如「一只穿宇航服的猫漂浮在太空中, 电影感光效」, output: 一张按描述生成的图片文件
- input: 一张图片的链接 + 一句修改要求, 如「把背景换成日落时的海滩」, output: 按要求修改后的新图片 (原图保持不动)
- input: 一张分辨率很低的图片链接, output: 放大数倍、细节更清晰锐利的高清版本图片
