# ai-avatar-video (`101-skills/superpowers/ai-avatar-video`)

## blackbox

**function**: 把一张人像照片变成会说话、口型对得上的视频, 台词、声音、语气都由你指定。

- input: 一张正面人像照片 + 一段想说的话(文字), 比如 "欢迎了解我们的新品" → output: 照片里的人开口说这句话的视频, 发音、口型自然同步, output: 
- input: 一张人像照片 + 一段已有的录音(如 MP3) → output: 照片中人对着这段录音开口说话的视频, output: 
- input: 一段人物描述, 如 "25 岁女讲师, 微笑, 看向镜头, 竖屏" → output: 一张可用的虚拟人像照片, 可直接让她开口讲你的稿子, output: 
- input: 一个英文讲解视频 + 翻译好的中文文稿 → output: 同一个视频, 人物口型对上中文配音的中文版, output:
