# receiving-code-review (`obra/superpowers/receiving-code-review`)

## blackbox

**function**: 帮你处理别人对代码的评审意见: 对的直接改好, 错的用事实反驳, 含糊的先问清——不盲从、不客套。

- input: PR 上的一条评审意见 + 代码库, 如"把这段旧代码删掉", output: 要么已修好并测试过的代码, 要么一条有据的反驳, 如"项目要兼容老系统, 这段不能删, 只修错的部分"
- input: 一条指令: "修复评审第 1-6 条"(其中两条描述含糊), output: 先发来针对含糊项的追问, 你答复后, 再逐条修完并附每条的测试结果
- input: 外部评审建议: "补一套完整的指标统计功能(数据库+筛选+导出)", output: 核实后的结论及追问, 如"全代码库没人用这功能, 建议直接砍掉, 确认?"; 若确实有用则给出实现好的功能
