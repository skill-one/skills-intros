# brainstorming (`obra/superpowers/brainstorming`)

## blackbox

**function**: 在你动手做任何东西之前,通过一问一答把模糊的想法聊成一份明确、双方都点头确认的方案——先定清楚"做什么、不做什么",再开工。

- input: 一句模糊的想法,如「我想给我的记账 App 加个预算提醒功能」, output: 先收到几个关键问题(什么时候提醒?超预算怎么算?),你答完后在对话里看到一段简短的改动方案:改哪里、怎么改、怎么验证——你明确点头后才会开始动代码
- input: 「我想做一个全新的 XX 网站/工具」这类从零开始的新项目, output: 一份写好的设计文档(.md 文件):明确做什么、砍掉了什么、分几步走;你审完这份文档后,还会得到一份按顺序排列的实施计划
- input: 一个可行性问题,如「能不能在 3 天内做出 XX 的原型?」, output: 一个明确的结论 + 推荐做法(可行/不可行、最省力的试法是什么),外加动手验证后的发现报告;过程中产生的东西会标明只是临时试验品,不是正式成果
