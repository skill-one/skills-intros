# dispatching-parallel-agents (`obra/superpowers/dispatching-parallel-agents`)

## whitebox

- 识别问题域: 判断是否有 2+ 个互相独立、无共享状态的故障/任务; 若失败互相关联则不启用本模式
- 为每个域构造一个聚焦且自包含的 agent 任务: 明确范围、贴入上下文 (如错误信息)、写明约束 ('不要改动其他代码') 和期望输出 ('返回根因与修复总结')
- 在同一响应中发出全部 subagent 派发调用, 它们并发运行
- 逐一审阅各 agent 返回的总结, 确认修复之间没有冲突
- 运行完整测试套件验证整体, 并抽查后整合所有改动

- 上下文隔离: agent 永不继承主会话历史, 每个任务的提示词由我按'聚焦范围 + 具体上下文 + 约束 + 期望输出'四要素精确构造
- 并行语义: 同一响应中多个派发调用 = 并行执行, 每个响应一个 = 串行, 调度方式直接决定执行方式
- 外部依赖: subagent 派发机制 (类型 general-purpose) 负责实际执行; 最终验证依赖项目的完整测试套件, 因 agent 可能出现系统性错误需人工抽查
