# executing-plans (`obra/superpowers/executing-plans`)

## blackbox

**function**: 把你写好的开发计划逐条落地成真正能用的代码, 卡住了会先来问你, 而不是硬着头皮瞎做。

- input: 一份写好的开发计划文件 (如 plan.md, 列着每一步要做什么), output: 计划里所有任务都实现完的项目代码, 外加一份「做了什么、每步验证结果如何」的完工汇报
- input: 一份有漏洞或步骤说不清的计划, output: 开工前的一份疑问清单——哪里有坑、哪里看不懂, 等你拍板后才动手, 不会带着问题硬上
- input: 执行到一半卡住 (如测试反复失败、缺少某个东西), output: 一封「暂停通知」: 具体卡在哪、需要你提供什么, 而不是交付一堆猜测出来的烂代码
