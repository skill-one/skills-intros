# using-git-worktrees (`obra/superpowers/using-git-worktrees`)

## blackbox

**function**: 为要开发新功能的项目开出一个隔离的独立工作区, 让你手头的代码和分支完全不受影响, 开完随时干净合并。

- input: 一个项目文件夹 + 一句话需求 (如「我要开始做购物车功能, 但别动我现在的分支」), output: 一条就绪报告: 新的独立工作区已建好、依赖已装好、原有测试全部通过, 可以直接开工写新功能
- input: 一个其实已经处于隔离环境中的项目, output: 一条提示: 「当前已在隔离工作区」, 不会重复再建一个, 直接沿用现有环境开工
- input: 「不用隔离, 直接在这个目录改就行」, output: 在原目录原地开工, 不创建任何新工作区
