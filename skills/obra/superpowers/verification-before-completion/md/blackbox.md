# verification-before-completion (`obra/superpowers/verification-before-completion`)

## blackbox

**function**: 在任何人宣布「搞定了/修好了/测试通过了」之前，我会亲手重新验证一遍并拿出实际证据——只认亲眼看到的验证结果，不认「应该没问题」。

- input: 一句话宣称：「测试应该都能过，可以提交了」, output: 一条实际跑出来的验证结果，例如「34/34 全部通过 ✅」或「仍有 2 个失败 ❌，还不能说完成」
- input: 「bug 已修复」+ 修改后的代码, output: 用当初出问题的场景重新跑一遍的结果：复现不了问题才确认修好；问题还在就直接告诉你「没修好，症状依旧」
- input: 一个准备发布/合并的成果（如 PR、打包结果、一份完成的任务）, output: 一份逐条核对过的验收清单：每一项要求都标注「已验证通过（附证据）」或「未验证」，没有凭空写的「已完成」
