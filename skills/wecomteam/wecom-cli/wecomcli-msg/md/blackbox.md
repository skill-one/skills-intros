# wecomcli-msg (`wecomteam/wecom-cli/wecomcli-msg`)

## blackbox

**function**: 帮你查看和管理企业微信的聊天：看谁找过你、翻聊天记录、下载别人发的图片/文件，还能替你发消息。

- input: 「最近一周谁给我发过消息？」, output: 一份会话清单：谁、哪个群、最后一次消息的时间
- input: 「帮我看看和张三最近的聊天记录」, output: 按时间排列的对话内容（张三 3月17日 14:02: 明天记得交材料），含图片/文件/语音的位置标注
- input: 「聊天里那几张图片帮我下载下来」, output: 图片文件下载到你电脑，附带每个文件的完整存放路径，可随时帮你清理
- input: 「给项目群发一条：今天下午3点开会」, output: 你确认后，消息原样发送到项目群，并告知发送结果
