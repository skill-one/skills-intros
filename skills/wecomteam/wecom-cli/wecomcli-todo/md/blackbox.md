# wecomcli-todo (`wecomteam/wecom-cli/wecomcli-todo`)

## blackbox

**function**: 帮你管理企业微信里的待办事项：创建、查询、修改（标题/描述/参与人/截止时间）、完成或删除。

- input: 「明天下午3点提醒我给客户发合同」, output: 企业微信待办里新增一条「给客户发合同」，截止明天 15:00，到点提醒你
- input: 「我有哪些还没完成的待办？」, output: 一张清单：每条待办的标题、截止时间和完成状态，可按时间或关键词筛选
- input: 「把『交周报』那条的截止时间改到周五，加上张三一起做」, output: 原待办更新完成：截止时间变为周五，参与人多了一位张三
