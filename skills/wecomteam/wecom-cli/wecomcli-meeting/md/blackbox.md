# wecomcli-meeting (`wecomteam/wecom-cli/wecomcli-meeting`)

## blackbox

**function**: 帮你管好企业微信里的在线会议：开会、查会、改会、取消会，还能帮你拿会议纪要和发言原话。

- input: 「帮我约个产品评审会，明天下午 3 点，叫上张三和李四」, output: 创建好的会议，反馈包含：主题、时间（明天 3月X日 15:00-16:00）、参会人姓名；约之前会避开大家的忙碌时段
- input: 「最近有什么会？」, output: 一份按时间排序的会议清单，每条只有主题、时间、参会人姓名三项，一眼看清最近的安排
- input: 「总结一下上周的项目周会」或「把会上说的原话发我」, output: 该会议的纪要总结（讲了啥、有哪些待办），或逐字发言记录（谁在几点说了什么，原样保留）
