# browser-act (`browser-act/skills/browser-act`)

## blackbox

**function**: 代替你在浏览器里动手: 打开网页、点击、填表、截图、抓取内容, 把你要在网页上完成的事情做完并交付结果。

- input: 一个普通方式打不开的网页链接 (如需要等待加载、点击或滚动才出内容的页面), output: 页面完整显示后的文字内容, 保存成可阅读的文本/文件
- input: 一条指令: 「打开这个商品列表页, 把前 20 个商品的名称和价格记录下来」, output: 一份整理好的清单文件 (商品名 + 价格, 逐条列出)
- input: 一个网址 + 要提交的信息 (如注册表单的字段), output: 已填好并提交成功的确认页面截图
- input: 一个需要登录才能看的网站地址, output: 登录后看到的实际页面内容 (用你提前登录好的账号状态)
