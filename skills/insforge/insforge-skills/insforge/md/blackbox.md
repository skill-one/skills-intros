# insforge (`insforge/insforge-skills/insforge`)

## blackbox

**function**: 给你的应用接上真正能用的后端功能——注册登录、存数据、传文件、发邮件、收付款, 交付的是直接能跑的完整代码。

- input: 「给我的网页加一个邮箱注册和登录」, output: 能运行的登录代码: 用户可以真实注册账号、登录、退出, 关掉页面再回来还是登录状态
- input: 「做一个留言板, 数据要保存下来」, output: 留言板代码: 发出的留言存进云端, 刷新页面还在, 换台设备也能看到
- input: 「加上传头像的功能」, output: 上传代码: 用户选好的图片存到云端, 拿到能直接显示在页面上的头像链接
- input: 「让用户付钱升级会员」, output: 收银代码: 点购买跳到真实付款页, 付完自动开通会员, 每月自动续费
