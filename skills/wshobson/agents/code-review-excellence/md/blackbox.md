# code-review-excellence (`wshobson/agents/code-review-excellence`)

## blackbox

**function**: 帮你审查代码:找出其中的 bug、安全隐患和坏味道,并给出具体、可执行的修改建议,而不是空泛的批评。

- input: 贴一段你写的 Python/JS 代码, output: 一份审阅意见:逐条指出问题(如「列表为空时这里会报错」「这个查询在数据量大时会变慢」),每条标注严重程度 🔴必改/🟡建议/🟢可选,并附上修改后的代码示例
- input: 一个 PR (代码合并申请) 的改动内容,附上业务背景说明, output: 一份完整的审阅报告:先列做得好的地方,再列必须修复的问题和改进建议,最后给出明确结论——✅通过 / 💬有意见但可合并 / 🔄需修改后再合并
- input: 一段测试代码,问「这样写测试行不行」, output: 指出测试是否真的在验证功能(而非只检查内部细节),举出哪些边界情况没测到,并给出改写后的测试示例
- input: 一段涉及登录、数据库查询的代码,问「有没有安全问题」, output: 一份安全检查清单:逐项核对输入校验、密码存储、注入风险等,发现的问题会说明攻击场景和修法
- input: 一句描述,如「我们小团队想定一套代码审查规矩」, output: 一套可直接用的团队审查清单和评论规范(哪些必查、意见怎么写不伤和气、结论怎么给)
