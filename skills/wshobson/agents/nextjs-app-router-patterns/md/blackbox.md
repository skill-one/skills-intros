# nextjs-app-router-patterns (`wshobson/agents/nextjs-app-router-patterns`)

## blackbox

**function**: 帮你写好、修好 Next.js (App Router 版) 应用的页面和数据请求代码。

- input: 「我要一个商品列表页, 数据来自接口, 每小时自动刷新」这样的需求描述, output: 可直接放进项目运行的商品列表页代码
- input: 一段用旧版 Pages Router 写的页面代码, output: 迁移成新版 App Router 的等价代码
- input: 一个加载很慢或白屏报错的 Next.js 页面代码, output: 修好报错、补上加载状态、打开更快的修改后代码
- input: 「Server Component 和 Client Component 该怎么选?」这类问题, output: 结合你的场景给出答案 + 可直接抄的示例代码
