# data-storytelling (`wshobson/agents/data-storytelling`)

## blackbox

**function**: 把一堆枯燥的数据变成「有开头、有冲突、有结论」的数据故事——让你汇报、做报告、说服别人时, 数字自己会说话。📊

- input: 一份销售/运营数据表 (Excel、CSV 或粘贴的数字), output: 一份数据故事报告: 先给最关键的洞察结论, 再用图表和数据支撑, 结尾附明确的行动建议
- input: 几个季度经营指标 (如营收、用户数、留存率), output: 一版给老板/投资人看的汇报稿: 用「背景→问题→发现→建议」的结构讲清这季度的故事
- input: 一段夹杂很多数字的原始调研或分析结果, output: 一页面向非技术同事的洞察总结: 三条要点以内, 每条都有数据依据和「所以呢」的回答
