# git-advanced-workflows (`wshobson/agents/git-advanced-workflows`)

## blackbox

**function**: 帮你收拾 Git(代码版本记录)的各种烂摊子:整理凌乱的提交历史、精准搬运个别提交、揪出引入 bug 的那次改动、找回误删的分支和代码。

- input: 「我的功能分支上有 12 个乱糟糟的提交(改错字、临时调试混在一起),合并前想清理干净」, output: 整理后的分支:同样一处改动,浓缩成 3 个干净、有意义的提交,可以直接提 PR 给同事审查
- input: 「我把一个还没合并的分支删了,里面的代码找得回来吗?」, output: 完整找回的分支——代码和提交记录一条不少(删除后 90 天内都能救回)
- input: 「客户报了个 bug,但仓库里有两百多个提交,不知道是哪次改动引入的」, output: 精确定位到引入 bug 的那一次提交,并告诉你它具体改了什么,直接修那里就行
- input: 「main 分支上刚合了一个紧急修复,我只想把这一个改动搬到我的开发分支上」, output: 开发分支上多出这一个修复提交,分支上的其他改动完全不受影响
