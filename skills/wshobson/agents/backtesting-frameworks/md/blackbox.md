# backtesting-frameworks (`wshobson/agents/backtesting-frameworks`)

## blackbox

**function**: 把你的交易策略放到历史数据上做可信的回测, 输出真实的绩效报告 (收益、回撤、手续费后的净表现), 并帮你揪出「假赚钱」的回测陷阱。

- input: 一段策略描述 (如: 5日均线上穿20日均线时买入, 跌破时卖出) + 一份历史行情 CSV 文件, output: 一份绩效报告: 年化收益、最大回撤、夏普比率、扣除手续费后的资金曲线图, 附可直接运行的回测代码
- input: 一段回测代码, 结果好得离谱 (比如显示年化 200%), output: 一份「翻车诊断」清单: 指出哪里偷看了未来数据、哪里漏算了成本, 外加修正后重新回测的真实收益
- input: 一条疑问: 这个策略参数调出来的好成绩, 是真本事还是过拟合?, output: 一份滚动验证报告: 把历史切成多段时间窗, 展示每段样本外的真实表现, 一眼看穿策略是「稳」还是「蒙」
- input: 两套候选策略 (如: MACD 版 vs 布林带版), output: 一份同一标准下的对比报告: 净收益、回撤、稳定性打分, 告诉你该选哪个、为什么
