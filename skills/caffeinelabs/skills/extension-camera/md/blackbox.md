# extension-camera (`caffeinelabs/skills/extension-camera`)

## blackbox

**function**: 一句话: 我能给你的网页装上摄像头 —— 打开实时预览、拍照、前后摄像头切换, 出问题时显示明确提示。

- input: 「给我的网页加一个摄像头, 用户能拍照」, output: 带摄像头实时预览 + 「拍照」按钮的页面; 点拍照即得到一张照片 (可选 jpg / png / webp)
- input: 手机上打开页面, 点「切换摄像头」, output: 画面在前置 ↔ 后置摄像头之间切换, 预览立即更新
- input: 用户拒绝摄像头授权, 或设备没有摄像头, output: 页面上显示具体原因 (如「未获得权限」「浏览器不支持」), 并提供「重试」按钮
- input: 同一页面在电脑上打开, output: 「切换摄像头」按钮自动隐藏 (电脑不支持切换), 只保留拍照; 摄像头未就绪时按钮不可误触
