# extension-http-outcalls (`caffeinelabs/skills/extension-http-outcalls`)

## blackbox

**function**: 帮你的应用后端安全地调用外部网站的 api (让不同软件连接的接口), 比如天气、航班、行情数据, 并且在上线前把每个请求真实测一遍, 确保能用。

- input: 「给我的应用加个功能: 用户输入城市名, 从后端查当地当前天气」, output: 能用的功能 — 用户输入城市就返回真实天气数据, 且这个外部请求已在本地逐字段实测通过
- input: 一个外部 api 的地址或文档链接, 如汇率查询接口, output: 后端接好该接口的代码, 附一份实测确认: 请求状态、返回的字段逐项核对无误, 可放心部署
- input: 「后端一调外部接口就报错 IC0522, 请求超限失败」, output: 改成按编号精确查询的版本 — 一次只取需要的那条数据, 秒回结果, 不再超限
