# twitter-automation (`magentosh/superpowers/twitter-automation`)

## blackbox

**function**: 你说一声, 我就替你在 Twitter/X 上发推、带图发推、点赞、转发、删帖、发私信、关注人、查资料——把社交媒体的日常操作变成一句话的事。

- input: 一段文字, 如「新产品上线啦 🚀」, output: 这条推文已发出去, 拿到可分享的推文链接
- input: 一段文字 + 一张图片的网址, output: 带图推文已发布, 返回推文链接 (也支持发 AI 生成的图片/视频)
- input: 一条推文的链接或 ID, output: 已帮你点赞/转发, 或返回这条推文的内容、作者、发布时间
- input: 一个用户名, 如 elonmusk, output: 该用户的资料卡 (头像、简介、粉丝数); 说一声还能一键关注
- input: 对方的用户 + 一句想说的话, output: 这条私信已送到对方收件箱
