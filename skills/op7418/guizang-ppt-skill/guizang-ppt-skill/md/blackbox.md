# guizang-ppt-skill (`op7418/guizang-ppt-skill/guizang-ppt-skill`)

## blackbox

**function**: 把你的主题、大纲或素材变成一份双击就能在浏览器里全屏演讲的网页 PPT——左右翻页、自带演讲者提词视图和讲稿备注，有电子杂志风和瑞士极简风两种视觉可选。

- input: 一句话需求，如「帮我做一份 20 分钟的 AI 产品分享，杂志风」, output: 一个单文件 HTML 网页 PPT：浏览器打开即可用 ← → 键或手机滑动翻页，直接投屏演讲
- input: 一份大纲文档 + 几张图片/产品截图, output: 内容排好版、图片落位到对应页面的成品 PPT；按 P 键还能看到每页的讲稿备注、下一页预览和计时器
- input: 风格与配色偏好，如「瑞士风，克莱因蓝」, output: 一整套无衬线大字报式幻灯片：黑白主体 + 单一克莱因蓝高亮，大数字、对比图、时间线都按这套视觉出
