# convex-explain-app (`get-convex/agent-skills/convex-explain-app`)

## blackbox

**function**: 🗺️ 给我一个现成的 Convex 应用, 我还你一张看得懂的应用地图: 数据怎么存、表怎么关联、哪些功能对外可调用、登录权限怎么设计、一个请求从进门到落库的全过程 — 只讲解, 不改动。

- input: 一个 Convex 项目的文件夹路径, output: 一份应用地图: 有哪些数据表、表之间怎么关联、哪些函数对外开放、哪些只能内部调用、登录和归属权怎么设计的说明报告
- input: 「这个项目里, 客户端能直接调用的函数有哪些?」, output: 一份公开/内部函数清单, 每个函数配一句话: 它做什么、会读写哪些数据
- input: 「这个应用里, 用户 A 能看到用户 B 的数据吗?」, output: 对这个项目现有登录与权限机制的事实描述 — 它靠什么识别用户、靠什么字段判断归属; 只陈述现状, 不替你判断有没有漏洞
- input: 「一个用户点『新建任务』后, 数据是怎么流的?」, output: 一条端到端的流程讲述: 请求从哪个入口进来 → 经过哪些校验 → 写进哪张表 → 之后怎么被查出来
