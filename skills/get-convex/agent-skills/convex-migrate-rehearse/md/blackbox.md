# convex-migrate-rehearse (`get-convex/agent-skills/convex-migrate-rehearse`)

## blackbox

**function**: 帮您安全地改动线上数据库的表结构:先在一份数据副本上彩排到全部通过,再应用到真实数据库,且全程留有改动前的完整备份,出问题可回退。

- input: 一句需求:「给用户表加一个必填的『会员等级』字段」, output: 一份彩排报告(副本数据上哪些旧记录不合新格式、怎么修),改好的代码;您确认后,同样的改动应用到线上库并验证通过
- input: 一段报错:「部署失败:328 条旧数据不符合新格式」, output: 一份诊断:指出是哪批数据挡住了改动、长什么样,以及在副本上修到全部通过的证据,之后才敢动线上
- input: 一条确认:「把验证过的改动推到正式环境」, output: 改完并验证过的线上数据库,外加一份改动前的数据备份文件作为后悔药(可一键恢复,并会提醒您备份只覆盖到快照那一刻)
