# convex-cost (`get-convex/agent-skills/convex-cost`)

## blackbox

**function**: 我能预测你的 Convex 应用 (一种云后端服务) 会花多少钱: 找出最烧钱的接口, 告诉你花费随数据增长会怎么涨, 并指出最便宜的省钱改法.

- input: 一个 Convex 云端部署地址 (如 https://xxx.convex.cloud), output: 一份按「烧钱程度」排序的接口清单, 每条注明: 每次调用读多少数据 × 被调了多少次, 以及来自实际用量数据的证据
- input: 「我的消息列表接口, 以后用户多了会不会很贵?」, output: 一句话结论 (如: 现在每次都读全表, 数据涨到 100 万行时成本会翻百倍), 附增长趋势和最省钱的改法 (如: 改成只取前 20 条)
- input: 「帮我买个自定义域名」, output: 先明确报出价格和是否按月重复收费, 等你明确点头后才动手 — 绝不会让扣费悄悄发生
