# convex (`get-convex/agent-skills/convex`)

## blackbox

**function**: 你说出一个应用想法或一句「我要加个 XX 功能」, 我把它变成一个真正能跑、能存数据、多人实时同步的完整应用 (后端即应用的服务器部分, 负责存数据和处理请求)。

- input: 一句话想法, 例如「我要做一个团队待办清单, 大家看到的变化要实时刷新」, output: 一个几分钟内就能在浏览器里打开使用的完整应用 (前后端代码 + 运行地址), 待办数据存在服务器上, 多人打开页面时改动自动实时同步
- input: 一个已有的项目目录 + 一句需求, 例如「加上用户登录」「加上付费解锁」, output: 改好的代码: 用户能用微信/Google/邮箱登录, 或直接完成付款流程; 需要花钱的操作 (如购买域名) 会先向你确认
- input: 线上报错信息或一句「帮我检查这个后端有没有安全问题」, output: 一份说清问题在哪、为什么的修改方案: 报错会给你修好的代码变更等你确认合并, 体检会给出按优先级排序的问题清单 (谁能偷看数据、哪里会拖慢、哪里会多花钱)
