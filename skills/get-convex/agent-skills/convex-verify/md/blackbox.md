# convex-verify (`get-convex/agent-skills/convex-verify`)

## blackbox

**function**: 你给我一个刚写好或刚改过的后端功能，我实际把它当成不同身份的用户跑一遍，最后给你一份「验证报告」：哪些行为符合预期、哪些有漏洞（比如别人能看/改你的数据）——用真实运行结果证明它好用，而不是只看代码没问题。

- input: 一个后端功能（如 convex/messages.ts 里的删除消息函数）+ 一句预期：「只有消息主人能删」, output: 一份验证报告：✅ 主人删除成功；✅ 另一个用户删除被拒绝；若 ❌ 别人也能删成功，会标出是谁、怎么绕过的
- input: 一个「查我的订单列表」的查询功能, output: 报告：张三登录只看到张三的订单 ✅；若李四的订单混进了张三的结果 ❌，报告里明确指出泄露了哪条
- input: 一个要求登录才能用的功能（如「修改个人资料」）, output: 报告：✅ 已登录用户改成功；✅ 未登录者被拒绝；若 ❌ 不登录也能改，指出具体调用方式
