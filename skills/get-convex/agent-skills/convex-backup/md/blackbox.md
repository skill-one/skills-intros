# convex-backup (`get-convex/agent-skills/convex-backup`)

## blackbox

**function**: 给你的 Convex 数据库 (应用存数据的后台) 做备份, 并实际演练一次"把数据恢复回来", 用证据证明备份真的可用, 而不只是留一个从未验证过的文件。

- input: 「帮我备份数据库」 (说明一下你的 Convex 项目), output: 一个包含全部数据的备份文件 + 一份建议的定期备份计划 (多久备一次、保留多久)
- input: 「确认这份备份真的能恢复」, output: 一份恢复演练报告: 数据被实际恢复到一个用完即弃的临时环境, 逐表核对条数并抽查真实记录, 明确给出 通过 / 失败 的结论
- input: 「万一数据出了事, 怎么救回来?」, output: 一份应急恢复手册: 照着一步步执行就能把备份还原回正式环境, 附带注意事项 (如快照之后新写入的数据会丢失)
