# convex-design (`get-convex/agent-skills/convex-design`)

## blackbox

**function**: 把你用大白话描述的 App 想法, 直接变成能上线运行的后端 (负责账号登录、数据存储、实时消息同步这些用户看不见但缺一不可的部分)。

- input: 一句大白话, 比如「我想做个奶茶店点单小程序」, output: 能直接跑起来的后端: 订单能存、能查、扣款不出错, 前端一连就能点单
- input: 「给我的应用加个登录注册功能」, output: 加好登录的完整代码文件, 已验证编译通过并成功部署上线
- input: 「做个聊天功能, 别人发消息我要立刻看到」, output: 实时同步的聊天后端, 消息秒级出现在所有在线设备上, 无需刷新
