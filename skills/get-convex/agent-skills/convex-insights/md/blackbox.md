# convex-insights (`get-convex/agent-skills/convex-insights`)

## blackbox

**function**: 像一个懂行的运维助手:你用大白话问它线上后端服务 (Convex, 一种后端云平台) 的运营情况——哪里在报错、什么跑得慢或贵、是不是新版本上线搞出的问题——它给回结论 + 证据 (错误次数、日志片段) + 一条可点开核实的后台看板链接。全程只读,不会改动你的线上服务。

- input: 「最近上线后,哪些后端函数在报错?」, output: 一份简短结论:哪个函数失败最多、各类错误各出现多少次、附一条典型报错堆栈,外加一个直达该函数日志页的看板链接,可自己点开核对
- input: 「过去几天服务健康吗?有没有慢或费钱的操作?」, output: 一份 72 小时健康摘要:慢查询、费用异常、冲突重试等问题按严重程度排名,每项带发生次数和看板链接;如需修复方案会转交给专门的优化助手
- input: 「为什么这一笔请求失败了?」(附一个请求 ID 或函数名), output: 该请求的完整执行记录,标出具体死在哪一步,附原始日志行,而不是让你自己翻一堆日志
- input: 「是不是我上次部署把功能弄坏了?」, output: 一个相关性判断:报错开始时间 vs 部署时间的对照 (如『错误在部署后 5 分钟开始出现,相关性较高』),附时间证据,不下武断结论
