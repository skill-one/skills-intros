# gpt-image-2 (`gargantuax/openskills/gpt-image-2`)

## blackbox

**function**: 你说一句想要什么样的图、或给我几张参考图,我就能帮你生成新图、改图或把多张图合成一张。

- input: 一段文字描述,如「电影感的夜晚城市天际线,霓虹灯」, output: 一张对应的图片文件(如 skyline-1.png);要几张就出几张,自动按编号命名
- input: 两张参考图片 + 一句要求,如「把这两张融合成一张干净的产品宣传插画」, output: 一张合成/修改后的新图片文件
- input: 一张照片 + 一句指令,如「把这张产品照改成摄影棚风格的广告图」, output: 一张换风格后的图片文件,原照片内容保留
- input: 一句话,如「给 AI 开发者峰会做一张海报」, output: 一张海报图片;长图生成时还能先看到由模糊逐步变清晰的预览
