# langchain-rag (`langchain-ai/langchain-skills/langchain-rag`)

## blackbox

**function**: 帮你写好一套「让 AI 根据你自己的文档回答问题」的程序代码 (俗称 RAG 知识库问答系统)。

- input: 你的一批文档 (如 PDF 文件、网页链接、装满 .txt 的文件夹) + 一句话需求: 「想做个能自动回答这些文档问题的机器人」, output: 一份完整可运行的代码文件, 照着跑起来后, 机器人就能对着你的文档答问, 例如问「报销流程是什么」能从你的员工手册里找出答案
- input: 你已经有的问答程序代码 + 症状描述, 如「电脑一重启, 建好的知识库就空了」或「搜出来的内容总是不相关」, output: 修好的代码 + 一句原因说明, 例如知识库改为存到硬盘、检索内容量调大, 重启后数据还在、答案更对题
- input: 一条调整需求, 如「准备正式上线, 想把知识库放到云端」或「只想在 2024 年的文档里搜索」, output: 对应的改造后代码, 例如换用云上知识库存储、支持按年份/类别筛选检索结果
