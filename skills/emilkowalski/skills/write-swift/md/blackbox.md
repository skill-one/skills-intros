# write-swift (`emilkowalski/skills/write-swift`)

## blackbox

**function**: 帮你搞定 Swift (苹果 App 开发语言) 代码：写新功能、修报错卡顿、评审和升级旧代码。

- input: 一段报「数据竞争/并发错误」的 Swift 代码, output: 修好的代码，附一句话说明问题出在哪、为什么这样改
- input: 一段用旧版 Swift 写的代码, output: 改写成 Swift 6 新写法的代码，老写法逐处替换，可直接编译
- input: 一个需求描述，如「写一个能同时下载多张图片的函数」, output: 可直接粘贴使用的 Swift 代码
- input: 一份 Swift 源文件路径, output: 一份评审报告：列出隐患（内存泄漏、卡顿、坏味道）和具体修改建议
