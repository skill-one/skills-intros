# pick-ui-library (`emilkowalski/skills/pick-ui-library`)

## whitebox

- 仅在被显式调用时启动 (自动触发已被禁用), 接收一句任务描述如 "我要做 toast 通知"
- 提取任务语义而非用户点名的库名 — "我需要个下拉框" 归类为 UI 原语需求, 即使字面问的是别的东西
- 读取项目 package.json: 已装清单内库则直接沿用; 已装竞品只标记建议, 不擅自替换依赖
- 在精选清单中查表命中唯一答案, 输出一个库 + 一句话用途说明; 请求里包含安装/接线时一并完成
- 任务不在清单覆盖范围内时, 明确声明已脱离精选清单, 再用自身知识推荐

- 静态查找表: 核心是一张按五大类组织的固定映射表 (UI 原语/动效视觉/图表/交互性能/状态样式), 纯检索无生成 — 识别任务 → 匹配条目 → 单一推荐, 不给用户选项菜单
- package.json 依赖感知: 推荐前先检查项目已有依赖, 分三条路径 — 已装清单内库则沿用 / 已装竞品只提示不替换 / 未装才引入新库
- 反模式纠偏表: 内置常见错误方案映射 (手搓 toast → Sonner、裸 div 下拉框 → base-ui、千行列表直渲染 → Virtuoso 等), 用于把错误做法纠正回清单里的正确库; 本技能自身不依赖任何外部模型 API 或运行时工具, 清单条目均为外部 npm 库 (base-ui、motion、recharts、zustand、clsx、cva 等)
