# animate (`emilkowalski/skills/animate`)

## blackbox

**function**: 你说「这里要能动起来」,我给你一段能直接用的动画代码——并且会直接告诉你哪些地方根本不该加动画。

- input: 一段需求描述,如「下拉菜单展开太生硬,给它加个动画」, output: 可直接粘贴进项目的动画代码,包含缓动曲线、时长、以及打开/关闭两个方向的完整表现
- input: 你的组件代码文件(如一个 React 弹窗、Toast 组件), output: 原地改好的组件代码,动画已写入,触屏和「减少动态」用户也已一并适配,不用你事后补
- input: 「命令面板每天要按几十次,要不要加开关动画?」, output: 一个明确结论:不加动画,配一句理由和替代做法(瞬时切换),不会硬塞一段花哨代码给你
