# animate-expo (`emilkowalski/skills/animate-expo`)

## blackbox

**function**: 帮你在 Expo 手机应用里把动效和手势做出来——从「该不该动」的判断, 到可以直接粘贴运行的代码。

- input: Expo 项目里的一个组件代码 + 一句话需求, 如「这个列表要能滑动删除」, output: 可直接粘贴运行的组件代码, 滑动、回弹、删除的完整手势与动效都在里面
- input: 一段现有组件代码 + 「在我那台旧安卓机上很卡」, output: 修好的代码, 外加几行说明卡在哪、拿到真机上要试哪些手感 (快滑、中途打断、慢机验证)
- input: 「帮我给 Tab 切换加个滑动动画」, output: 一句「这个不该动」的理由 + 改成无动画的配置代码——该省的地方一个字动画都不写
