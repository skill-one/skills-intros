# vercel-optimize (`vercel-labs/agent-skills/vercel-optimize`)

## blackbox

**function**: 给已部署在 Vercel 上的网站做一次"线上体检": 用真实的访问和账单数据, 找出哪些页面/接口又慢又烧钱, 并给出按效果排序的具体改进方案。

- input: 已部署项目的本地代码目录 (已关联 Vercel) + 一句「帮我降低 Vercel 账单」, output: 一份审计报告: 列出最烧钱的几个路由 (如 /api/chat、/blog/[slug]), 说明贵在哪 (如重复请求、缺少缓存), 附上精确到文件和行号的改法, 按省钱效果排序
- input: 同一个项目 + 一句「我的首页加载很慢」, output: 报告指出慢的具体环节 (如服务端每次请求都重新拉数据、缓存策略缺失), 并给出具体的缓存配置或代码修改建议
- input: 「这个月函数调用次数涨了好几倍, 帮我查查为什么」, output: 报告定位到具体是哪几个路由调用量暴涨、原因是什么 (如图片/资源没缓存、被机器人刷接口), 附对应的修复方案
