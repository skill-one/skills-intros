# remotion-saas (`remotion-dev/skills/remotion-saas`)

## blackbox

**function**: 帮你搭一个「在网页里生成或编辑视频」的应用：访客填表、改文字，就能实时预览动画并导出成 MP4 视频。

- input: 「做一个网页：用户填入名字和照片，自动生成一段生日祝福视频」, output: 一个可运行的网站，访客填完表单点按钮，页面上直接预览祝福视频并可下载 MP4
- input: 一段产品文案 + 配色要求, output: 一个视频编辑器网页：左边改文字/颜色，右边实时刷新动画预览，满意后一键导出视频文件
- input: 一份客户名单表格（如 100 个名字）+ 你的视频模板, output: 100 条按名字定制的 MP4 视频，批量自动生成，不用逐条手工制作
