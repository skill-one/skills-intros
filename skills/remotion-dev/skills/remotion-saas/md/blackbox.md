# remotion-saas (`remotion-dev/skills/remotion-saas`)

## blackbox

**function**: 把"做视频"变成一个网站: 用户在网页上填内容、实时预览动画效果, 点一下就能导出成真正的视频文件 (mp4)——从简单的填表生成视频, 到像剪映一样的在线视频编辑器, 都能帮你搭出来。

- input: "做一个祝福视频生成器网页, 用户填名字和祝福语就能生成视频", output: 一个能直接运行的网站: 打开 → 填内容 → 网页里实时播放视频预览 → 点按钮下载 mp4
- input: 一段视频创意描述, 如"15 秒产品宣传视频, 换 logo 和三句文案就能用", output: 可复用的视频模板 + 带预览播放器的编辑页面, 每次改文字/图片, 画面即时刷新
- input: "做一个在线视频编辑器, 有时间轴, 能排多个画面和字幕", output: 带时间轴、多轨道的完整视频编辑器网页, 剪辑完可导出成片
