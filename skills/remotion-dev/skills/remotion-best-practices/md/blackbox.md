# remotion-best-practices (`remotion-dev/skills/remotion-best-practices`)

## blackbox

**function**: 用代码做视频:你描述想要的画面,我交付能直接渲染出 mp4 视频文件的项目(动画、字幕、地图路线、多视频剪辑拼合都可以)。

- input: 「做一个 30 秒的产品宣传片,附上 3 张产品图,结尾放 logo」, output: 一个可直接渲染的视频项目,渲染后得到 30 秒的 mp4 宣传片
- input: 一段 SRT 字幕文件 + 一个视频链接, output: 字幕与画面同步出现的成品视频
- input: 「做一个地图动画,展示这条骑行路线 GPX,沿途标注打卡点」, output: 地图上路线逐步绘制、打卡点依次弹出的动画视频
