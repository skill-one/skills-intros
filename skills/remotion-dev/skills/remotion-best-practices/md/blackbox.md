# remotion-best-practices (`remotion-dev/skills/remotion-best-practices`)

## blackbox

**function**: 把你的想法变成真正可播放的视频文件: 用代码写视频, 你说需求, 我产出成品 MP4。

- input: 一句话需求: 「帮我做一个 15 秒的产品宣传片, 用我们的 logo 和这三句文案」+ logo 图片文件, output: 一个可直接播放/发社交媒体的 MP4 视频文件
- input: 一个已有的视频项目 + 修改要求: 「把片头标题换成 XX, 配色改成蓝色」, output: 改好的项目, 重新播放/导出后画面即按你的要求更新, 文字和颜色都改到位
- input: 一条 SRT 字幕文件 + 你的视频项目, output: 字幕逐句同步出现在画面上的新视频
