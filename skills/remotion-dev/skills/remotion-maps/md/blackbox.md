# remotion-maps (`remotion-dev/skills/remotion-maps`)

## blackbox

**function**: 把地点、路线、行程做成「地图飞行动画」视频——就是纪录片和旅行视频里镜头在地图上俯冲、飞行、划路线的那种效果。

- input: 一句话需求: 「镜头从太空俯冲到曼哈顿, 拍出 3D 大楼」, output: 一段视频: 画面从地球全景一路拉近, 最后停在曼哈顿的 3D 楼群间
- input: 两个地名, 如「巴黎 → 东京」, output: 一段地图飞行视频: 镜头跨过大陆飞到目的地, 两端各有定位标记
- input: 一份旅行行程清单, 如「伦敦 → 巴黎 → 罗马」, output: 一段动画: 镜头按顺序依次飞过每一站, 站点逐个亮起标记
