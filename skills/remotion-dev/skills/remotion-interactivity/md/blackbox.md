# remotion-interactivity (`remotion-dev/skills/remotion-interactivity`)

## blackbox

**function**: 把你的 Remotion 视频代码改写成「能在编辑面板里直接操作」的形态——文字、图片、动画都能点选、拖动、即时改样式,不用每次回头改代码。

- input: 一段 Remotion 视频组件代码(.tsx 文件), output: 改写后的代码:在 Remotion Studio 里打开,标题卡片、图片等元素可以点选,字体、颜色、间距直接在界面上改,所见即所得
- input: 「这段入场动画太生硬,我想在面板里调」+ 对应代码, output: 调整后的代码:动画的关键帧和缓动曲线变成可视化控件,在时间轴上拖一拖就能调出手感,不用手写数值
- input: 若干视频、音频片段拼接成片的代码, output: 整理后的代码:每段片段在时间轴上有清晰名字,拖动即可调整顺序、时长和位置,像剪视频一样直观
