# remotion-markup (`remotion-dev/skills/remotion-markup`)

## blackbox

**function**: 你用大白话描述想要的视频效果、丢给我文案和素材,我给你做出能逐帧预览、一键导出成 MP4 的动画视频。

- input: 一句话需求:"做一个 10 秒的开场,产品名淡入,再加一行小字副标题", output: 一部动画视频:标题和副标题按你要求的时间点浮现、停留、消失,可直接预览并导出 MP4
- input: 几段视频/图片/音频素材 + 一段要配的字幕文案, output: 剪好的成片:素材按顺序拼接、裁掉不要的片段、配好音乐,字幕逐句带动画出现
- input: 一段产品介绍文字(约 50 字), output: 动态文字视频:关键词逐个弹出、高亮划线强调、最后整体淡出
- input: 已有的视频工程 + 一句修改意见:"标题放大一点,第 3 秒开始淡出", output: 调整后的视频,其余画面和节奏保持原样,只改了你指出的部分
