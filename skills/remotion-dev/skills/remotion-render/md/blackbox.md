# remotion-render (`remotion-dev/skills/remotion-render`)

## blackbox

**function**: 把用 Remotion 做好的动画/视频项目导出成真实可用的视频文件或图片,包括背景透明的视频。

- input: 一个用 Remotion 写好的视频项目 (比如一段产品介绍动画), 告诉我视频名字, output: 一个能直接播放和分享的 mp4 视频文件
- input: 项目里指定的某一个画面 (哪个视频 + 哪一帧), output: 一张高清静态图片 (如 png), 适合当封面或截图用
- input: 要求透明背景的动画项目 (比如一个会动的 logo), output: 背景透明的视频文件, 可以叠加到网页、PPT 或其他视频上
