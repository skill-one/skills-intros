# thermo-nuclear-code-quality-review (`cursor/plugins/thermo-nuclear-code-quality-review`)

## whitebox

- 接收当前分支的改动 (diff), 以 skill 内置的基线 prompt 发起深度代码质量审计
- 逐条应用 7 条硬性标准 (1000 行文件红线、禁止意面式 if 增生、倾向重构而非只认可工作的代码等)
- 对每个有实质的改动跑一遍固定的问题清单, 寻找 code judo (大幅简化且不改变行为的重构机会)
- 按优先级归并发现: 结构性回退 > 错过的简化机会 > 意面式分支 > 边界/抽象问题 > 文件膨胀, 刻意不罗列琐碎 nit
- 对照批准门槛逐项裁决, 输出少量高置信度、可执行的反馈或明确的阻塞项

- 纯规则驱动, 无外部依赖: 不调用任何工具/库/模型 API, 全部判断来自 skill 内嵌的检查清单、固定提问和示例话术
- 阈值化校验: 文件从 <1000 行被 PR 推过 1000 行视为默认强异味, 除非有强结构理由; 各类代码异味 (散落特例分支、any/unknown/强制转换、薄包装、复制粘贴等) 均为预设触发模式
- 门槛式输出: 只有当无结构回退、无文件爆炸、无意面增生等全部条件满足才批准; 否则给出'保留行为、重构实现'式的具体整改建议
