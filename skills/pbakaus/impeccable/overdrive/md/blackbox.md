# overdrive (`pbakaus/impeccable/overdrive`)

## blackbox

**function**: 把你已有的网页界面升级成让人"哇"出来的版本——更炫的视觉效果、更顺滑的动效、更跟手的响应,但功能和内容不变。

- input: 一个能正常用的官网落地页 (HTML 文件) + 一句「让它更惊艳」, output: 升级后的同款页面:滚动时内容逐段电影般浮现,背景随鼠标流动,动画全程顺滑不卡顿
- input: 「这个弹窗出现得太生硬了」+ 页面代码, output: 弹窗改为从你点击的那个按钮原地平滑展开、关闭时缩回原位,过渡自然得像原生应用
- input: 一份带几万行数据的表格页面 (一滚动就卡), output: 同样的表格:快速滚动依然流畅,搜索筛选即时出结果,全程不掉帧
