# audit (`pbakaus/impeccable/audit`)

## blackbox

**function**: 给你的网页/前端代码做一次体检, 输出一份打分报告: 哪里有问题、多严重、怎么修, 按优先级排好。

- input: 一个页面或组件的代码 (如 checkout 页面的文件路径), output: 一份打分报告 (满分 20 分): 无障碍、性能、主题、响应式、整体观感五个维度的得分表, 外加一份按 P0(致命)~P3(可缓) 排序的问题清单, 每条注明具体代码位置、对用户的影响和修复建议
- input: /audit 首页, output: 先给一句话判定「这页面看起来像不像 AI 批量生成的」, 再列出前 3~5 个最该先修的硬伤, 以及一份按优先级排好的修复顺序 (先修什么、后修什么)
- input: 整个项目 + 一句「帮我查查视障用户用起来卡在哪」, output: 一份无障碍问题清单: 对比度不达标的具体位置、键盘无法操作的按钮、缺失的图片描述、表单没有标签等, 每条都写清影响哪类用户、违反什么标准、怎么改
