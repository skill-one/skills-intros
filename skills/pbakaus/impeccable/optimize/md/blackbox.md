# optimize (`pbakaus/impeccable/optimize`)

## blackbox

**function**: 帮你的网页/前端应用「提速」: 找出慢的原因并改好, 让加载更快、滑动和动画更流畅。

- input: 一个网页的 URL (比如你的官网地址), output: 一份体检报告: 慢在哪 (图片太大? 代码太重?)、有多严重, 以及每一条对应的修复建议
- input: 你的前端项目代码路径 (如 React 项目), output: 优化后的代码: 图片压缩/懒加载、体积瘦身、卡顿动画修好, 并附前后速度对比数据
- input: 一段描述, 如「手机上首页要 8 秒才打得开」「列表滚动一卡一卡的」, output: 定位到具体原因 + 直接可用的修改后的代码
