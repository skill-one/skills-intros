# animate (`pbakaus/impeccable/animate`)

## blackbox

**function**: 给你的网页功能加上恰到好处的动效, 让界面「活」起来但不喧宾夺主。

- input: 一个做好的网页/功能的前端代码 (HTML、React 组件等), output: 修改后的同款代码: 页面加载时内容依次浮现、按钮悬停和点击有细腻反馈、弹窗平滑滑入——同时自动兼容偏好关闭动效的用户
- input: 一段具体抱怨, 如「提交表单后毫无反应, 像死机了一样」, output: 改好的代码: 提交时按钮显示加载状态, 成功弹出对勾动画, 输错时输入框轻晃并变色提示
- input: 一个交互问题, 如「下拉菜单是一瞬间跳出来的, 很生硬」, output: 修改后的代码: 菜单以自然的缓动展开收起, 箭头图标同步旋转, 不再突兀
