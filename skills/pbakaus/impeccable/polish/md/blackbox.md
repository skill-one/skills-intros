# polish (`pbakaus/impeccable/polish`)

## blackbox

**function**: 给「功能已经做完、细节还很糙」的网页或界面做最后一遍打磨: 对齐、间距、颜色字体统一、按钮各状态、文案错别字全修好, 让它从"能用"变成"能放心上线"。

- input: 一个功能已完成但细节粗糙的页面文件 (如 index.html 路径), output: 修改后的同一批文件: 元素对齐、间距统一、颜色不再乱、按钮补上悬停/加载/报错时的样子, 可直接上线
- input: 一个网址 + 一句话「这页面总觉得哪里不对, 你帮我看看」, output: 修好的页面 + 一份逐条对应的问题清单: 哪里没对齐、哪两处说法不一致、哪张表单缺了报错提示
- input: 一段已写好的注册表单页代码, output: 修好的代码: 报错提示更友好、手机上不再横向滚动、键盘填写顺序正常、删掉了调试残留 (如 console.log)
