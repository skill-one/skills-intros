# frontend-design (`pbakaus/impeccable/frontend-design`)

## blackbox

**function**: 识别前端/界面设计类请求, 并告诉你改用新技能 /impeccable 来完成 (旧技能已停用, 这个盒子只负责引路, 不直接做设计)。

- input: 「帮我设计一个产品落地页」, output: 一句提示: 本技能已改名, 请改用 /impeccable 完成设计
- input: 技能目录里残留的 frontend-design 文件夹, output: 告知这是废弃残留, 可以直接删除
- input: 「找不到 /impeccable 怎么办」, output: 给出具体指引: 在终端运行 npx impeccable skills update 更新技能 (终端即电脑上的命令行窗口)
