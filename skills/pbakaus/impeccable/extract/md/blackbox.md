# extract (`pbakaus/impeccable/extract`)

## blackbox

**function**: 把你的界面代码里重复出现的部件和散落的样式值, 收拢成一套可复用的"组件+规范", 并把原代码替换成引用它们。

- input: 一个前端项目的目录 (如 src/), output: 提取出的公共组件文件 (如 Button.tsx、Card.tsx) + 原页面代码已改为引用这些公共组件, 旧重复代码被清理
- input: "我项目里有好几种长得差不多的按钮, 帮我统一" — 一条需求描述, output: 一个支持不同大小/颜色变体的统一按钮组件 + 全项目所有按钮调用点已替换并保持外观不变
- input: 散落在各文件里的硬编码颜色/间距代码 (如 #3B82F6、margin: 16px 出现几十处), output: 一份命名清晰的样式规范文件 (如颜色叫「主色」「辅助色」) + 各处代码已替换为引用规范名, 以后改一处全局生效
