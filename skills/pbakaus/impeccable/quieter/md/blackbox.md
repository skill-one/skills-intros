# quieter (`pbakaus/impeccable/quieter`)

## blackbox

**function**: 把「太扎眼、太吵」的设计调得安静耐看——降低视觉刺激,但不丢质感和辨识度。

- input: 一个网页文件路径 + 一句「这配色太炸了,看着头晕」, output: 改好的文件:颜色变柔和不刺眼,粗重字体和满屏动效收敛了,页面照样清晰好用
- input: 一张过于花哨的 App 界面截图,附「帮我调安静点」, output: 新版界面:低饱和配色、去掉多余阴影闪光和弹跳动画,重点内容依然一眼可见
- input: 一句「我的官网像霓虹灯招牌,想要高级感」, output: 整体降噪后的官网:克制的配色和留白、更细的线条和边框,保留原有个性但不闹腾
