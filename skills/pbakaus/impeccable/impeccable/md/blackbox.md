# impeccable (`pbakaus/impeccable/impeccable`)

## blackbox

**function**: 我负责一切「界面」的活: 从零写出漂亮的网页/应用界面, 或把你已有的界面审查、打磨到好看又好用。

- input: 一句需求, 如「给我的咖啡店做一个落地页」, output: 一份可直接在浏览器打开的完整网页, 排版、配色、动效都已是成品级效果
- input: 你的网站 URL 或界面截图, output: 一份「设计体检报告」: 哪里不好用、哪里不好看, 每条都附带具体怎么改
- input: 现有页面代码 + 一句话方向, 如「首页太保守了, 放开一点」, output: 改好的代码文件, 刷新浏览器就能看到焕然一新的界面
