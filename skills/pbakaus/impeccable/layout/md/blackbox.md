# layout (`pbakaus/impeccable/layout`)

## blackbox

**function**: 看懂你的页面/界面哪里「排得难受」——间距乱、内容挤、重点不突出——并直接给你改好的版本, 让它看起来舒服、有层次。

- input: 一个网页的 HTML/CSS 代码 (或文件路径), output: 修改后的代码: 间距统一、内容分组清晰、重点突出的版本, 可直接替换使用
- input: 一张界面截图 (如「这个后台页面看起来很乱」), output: 一份诊断清单: 指出哪里太挤、哪里没对齐、哪些内容应该放大或缩小, 每条附具体改法
- input: 一句话描述 + 需求 (如「帮我做一个 3 个功能介绍的官网首页区块」), output: 写好的页面代码: 布局有呼吸感、层级分明, 桌面和手机上都不挤不散
