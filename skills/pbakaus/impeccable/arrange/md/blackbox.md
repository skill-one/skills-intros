# arrange (`pbakaus/impeccable/arrange`)

## blackbox

**function**: 帮你的网页/界面「排好版」: 修好乱七八糟的间距、单调的布局和分不清重点的层次, 让页面看起来舒服、有设计感。

- input: 一个「说不上哪里不对、但就是感觉乱」的网页文件 (HTML/CSS), output: 间距、对齐、层次修好的新版代码, 直接替换可用
- input: 页面 URL 或截图, 附一句话: 「这页太挤了, 重点看不出来」, output: 重排后的页面代码 + 改了哪些地方 (如间距统一、主次分区) 的简短说明
- input: 满屏长得一模一样卡片的后台页面代码, output: 打破单调网格、主次分明的重排版本, 各区块松紧有节奏
- input: 一段文字描述: 「落地页内容都是居中堆一起, 显得业余」, output: 调整后的布局代码 (如分区留白、左对齐、突出主按钮)
