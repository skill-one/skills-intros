# onboard (`pbakaus/impeccable/onboard`)

## blackbox

**function**: 帮你的产品设计"新用户第一次上手"的体验——让新人更快用明白、更快尝到甜头,而不是注册完就流失。

- input: 一句现状描述,如:「新用户注册完不知道该干嘛,大多当天就走了」, output: 一套新手上路方案:欢迎页该说什么、第一步让用户做什么、什么时候让他拿到第一个成果(aha 时刻),并附上让老手能直接跳过的选项
- input: 一个空白页的描述或截图,如:「用户的项目列表页是空的」, output: 一份完整的空状态文案与设计:这里以后会显示什么、对你有什么用、「创建第一个项目」按钮放哪,以及用现成模板一键开头的选项
- input: 一个功能说明,如:「我们的表格工具功能多,新手容易懵」, output: 一个分步引导的设计:3~7 步、每步指向哪个按钮、配什么提示文字,用户可随时跳过、点错不卡死、看过的不再重复弹
