# create-readme (`github/awesome-copilot/create-readme`)

## blackbox

**function**: 给你的项目写一份好看又好懂的 README (项目说明书) 文件, 让别人一眼看懂这是个啥、怎么用。

- input: 一个项目文件夹的路径 →, output: 一份完整的 README.md 文件: 含项目简介、功能列表、安装和运行步骤
- input: 一个 GitHub 仓库地址 →, output: 针对该仓库生成的 README.md, 可直接放进仓库首页
- input: 一份已有的 README.md (内容乱、缺安装说明) →, output: 重写后的 README.md: 结构清晰、补齐使用说明, 但不瞎编项目没有的功能
