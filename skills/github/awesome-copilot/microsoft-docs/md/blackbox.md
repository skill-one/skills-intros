# microsoft-docs (`github/awesome-copilot/microsoft-docs`)

## blackbox

**function**: 你问任何微软技术 (Azure、.NET、VS Code、GitHub 等) 的问题, 我帮你查官方文档, 给出准确的说法、教程入口和能直接用的代码示例。

- input: "Azure Functions 用 Python 写一个 HTTP 接口, 该从哪开始?", output: 官方入门教程链接 + 核心步骤要点摘要
- input: "给我一段 C# 上传文件到 Azure Blob 存储的代码", output: 一段来自官方文档、可直接运行的 C# 代码示例
- input: "GitHub Actions 怎么设置每天定时跑任务?", output: 官方文档中的定时触发配置写法和示例
