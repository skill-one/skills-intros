# gh-cli (`github/awesome-copilot/gh-cli`)

## blackbox

**function**: 你说要做什么, 我就替你在 GitHub 上完成——建仓库、提问题单、发合并请求、发版本, 全程不用你记任何命令。

- input: 一个仓库地址, 如 github.com/owner/repo, output: 整个仓库下载到你的电脑文件夹, 可直接开始改代码
- input: 一段 bug 或需求描述文字, output: GitHub 上新建好的 issue (问题单) 链接, 带标题和标签
- input: 「把我这个分支合并进 main」, output: 创建好的 PR (合并请求) 链接, 含标题、说明, 可继续帮你盯测试状态直到合并
