# gsap-timeline (`greensock/gsap-skills/gsap-timeline`)

## blackbox

**function**: 帮你把网页动画按时间顺序编排好：写动画代码、排先后顺序、控制播放/倒放/循环，只要说出"谁先动、谁后动、怎么动"就行。

- input: 一句动画需求，如：「标题先淡入，然后副标题上滑，最后按钮弹出」, output: 一段可直接放进网页的 GSAP 时间轴代码，三个动画按顺序自动衔接
- input: 一段用 delay 堆出来的混乱动画代码, output: 整理后的时间轴版本：动画像乐谱一样排列，想调时间只改一处数字即可
- input: 一个问题，如：「动画播完后想让它倒着放回原样，怎么做？」, output: 对应的播放控制代码（倒放、循环、跳到某一帧继续播等），并注明改哪里
