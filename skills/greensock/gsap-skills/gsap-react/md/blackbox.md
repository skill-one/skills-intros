# gsap-react (`greensock/gsap-skills/gsap-react`)

## blackbox

**function**: 给 React / Next.js 网页写动画:你给我组件代码和想要的效果,我还你一段能直接跑的动画代码——进场浮现、滚动触发、点击反馈都行,并且动画会随页面卸载自动清干净,不留内存隐患。✨

- input: 一段 React 组件代码 + 一句效果描述,如:「这是我的卡片列表,想让它们依次错落淡入」, output: 改好的组件代码:卡片们从下往上逐个浮现;关掉这个页面再打开,动画依旧正常,不报错、不卡顿
- input: 一个首页横幅组件 + 需求:「滚动到屏幕里时再出现,滚回去再滚回来要能重播」, output: 带滚动触发动画的代码:横幅进入视野时浮现,反复滚动都能正确重播,列表很长也不影响性能
- input: 一个 Next.js 页面 + 报错信息:「一启动就报 window 未定义」, output: 修复后的代码:页面构建、服务器端渲染 (先在服务器生成页面骨架) 都不再报错,动画只在浏览器里运行
