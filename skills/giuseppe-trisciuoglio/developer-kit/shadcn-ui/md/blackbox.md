# shadcn-ui (`giuseppe-trisciuoglio/developer-kit/shadcn-ui`)

## blackbox

**function**: 一句话: 你说要什么样的网页界面 (按钮、弹窗、表格、带校验的表单、图表等), 我直接给你能在 React 项目里跑起来的完整界面代码。

- input: 「帮我搭一个能做登录页的项目, 用 React」, output: 一个配好界面框架的新项目, 打开就是可以直接改的登录页底子
- input: 「做一个注册表单: 邮箱格式要检查, 密码至少 8 位」, output: 完整的注册表单代码: 用户填错时输入框下方会实时红字提示, 填对了才能提交
- input: 「加一个用户列表表格, 每行有勾选框和编辑按钮, 再加个删除前确认的弹窗」, output: 可直接放进项目的表格代码: 支持全选, 点编辑或删除会弹出对应弹窗, 手感精致
