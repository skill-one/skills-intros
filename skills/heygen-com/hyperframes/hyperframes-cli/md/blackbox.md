# hyperframes-cli (`heygen-com/hyperframes/hyperframes-cli`)

## blackbox

**function**: 把你的想法做成能直接发布的动态视频——你用文字描述想要的画面和动效, 我搭好场景、调好节奏, 最后交给你一条 MP4 成片。

- input: 一句话需求: 「做一个 30 秒新品发布动画, 标语逐行弹出, 结尾定格 logo」, output: 先给你一个能在浏览器里拖进度条预览的链接, 你点头确认后, 得到一个 30 秒的 1080p MP4 成片文件
- input: 一个网址, 如 https://example.com/launch, output: 把这个网页捕获并做成动态视频, 输出一个 MP4 文件
- input: 一个做好的视频项目 + 一份 100 行客户名单的表格, output: 批量渲染出 100 个换了名字的定制版 MP4 视频, 一人一条
- input: 「我的视频渲染出来是黑屏 / 第 3 秒画面闪了一下」, 附项目文件夹, output: 一份定位到具体原因的诊断报告, 加上修好的成品视频
