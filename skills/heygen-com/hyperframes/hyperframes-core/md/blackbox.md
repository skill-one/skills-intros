# hyperframes-core (`heygen-com/hyperframes/hyperframes-core`)

## blackbox

**function**: 把你的视频想法变成一部真正能播放的成片——你用文字说清要什么, 我交付渲染好的视频文件。

- input: 一段需求描述, 如「做一个 30 秒产品宣传动画: 黑底白字, 三句文案依次滑入, 配轻快音乐」, output: 一个可直接播放的 30 秒视频文件 (mp4), 画面、节奏、音乐都按描述呈现
- input: 一份分镜/脚本计划 (如 STORYBOARD.md: 每个镜头的时长、画面、字幕), output: 严格按分镜逐帧落实的成片视频, 镜头顺序和时长与计划一致
- input: 一个已有的 HTML 动效工程 (文件夹), output: 检查并修复后的工程 + 一个可在浏览器实时预览、可逐帧调整时间线的页面, 确认后再出片
