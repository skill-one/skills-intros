# hyperframes-core (`heygen-com/hyperframes/hyperframes-core`)

## blackbox

**function**: 你给我一份视频想法、脚本草稿或已有的视频工程, 我把它变成一个能在浏览器里逐帧预览、确认后渲染成成片文件的视频项目。

- input: 一句需求描述, 如「做一个 15 秒的新品发布短片: 开场 Logo 弹出, 中间 3 张产品图轮播, 结尾带slogan和背景音乐」, output: 一个可直接在浏览器打开预览的视频工程, 时间轴上各画面按你说的时机出现; 你点头后可渲染出成片视频文件
- input: 一份分镜脚本或口播文稿 (Markdown/文本), 如「分镜1: 黑底白字标题 2 秒; 分镜2: 数据图表从左滑入 4 秒……」, output: 严格按文稿节奏搭建好的视频工程: 每个分镜对应一段画面, 时长、字幕、转场都对得上, 逐帧检查无误后交付成片
- input: 一个已有的视频工程文件 + 一句修改要求, 如「把第 3 个镜头缩短 1 秒, 字幕晚 0.5 秒出现, 音乐结尾淡出」, output: 改好的工程文件: 只动你指定的部分, 其他镜头的时长、顺序、轨道都不变, 预览里能直接看到修改后的效果
