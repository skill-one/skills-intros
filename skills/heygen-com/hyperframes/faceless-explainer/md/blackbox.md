# faceless-explainer (`heygen-com/hyperframes/faceless-explainer`)

## blackbox

**function**: 把你给的文字——文章、笔记、口播稿或一个主题——做成一条无人出镜的讲解视频(mp4):有旁白、逐句字幕、背景音乐,画面全部用动画文字、图形和图表来把一件事讲清楚。

- input: 一篇公众号文章或一段课程笔记(直接贴文本), output: 一条 mp4 讲解视频:人声旁白 + 逐句字幕 + 背景音乐,画面是围绕内容设计的动画文字、示意图和数据图表
- input: 只给一个主题,比如「什么是复利」, output: 一支约 1~2 分钟的科普短片(mp4):从抓眼的开场,到一步步拆解概念,全程动画图形讲解
- input: 自己写好的一篇口播稿, output: 按你的原话逐句配音、逐句配画面的成片视频,不改动你的措辞
- input: 一份「3 个理由 / 5 个步骤」式的清单要点, output: 一条条目式盘点视频(mp4),每条要点一屏动画,旁白逐条讲解
