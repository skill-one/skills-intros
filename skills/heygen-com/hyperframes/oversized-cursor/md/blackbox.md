# oversized-cursor (`heygen-com/hyperframes/oversized-cursor`)

## blackbox

**function**: 给产品宣传视频里的界面场景编入一个超大号鼠标指针——它从屏幕外飞入、走到按钮上点一下、"点"出下一个动作、再离场,负责带动观众视线、让呆板画面动起来。🖱️

- input: 一段场景描述文字,如「落地页,点击『开始试用』按钮后弹出注册表单」, output: 可直接运行的场景动画代码:指针从屏幕下方滑入、稳稳停在按钮上,点击瞬间按钮被按下并触发表单弹出,随后指针滑出画面
- input: 已做好的 UI 场景动画代码,但画面偏静态、缺乏动感, output: 加入指针动线的修改版代码:观众视线被指针牵着走(入场→点击→触发下一个动作→离场),场景不再死气沉沉
- input: 一部产品发布视频的分镜脚本,含多个场景, output: 每个场景的指针调度方案:何时入场、指向哪个目标、每次点击触发什么、如何离场或跨场景衔接
