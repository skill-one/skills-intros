# media-use (`heygen-com/hyperframes/media-use`)

## blackbox

**function**: 你说一句需求, 我交付能直接用的媒体文件: 背景音乐、音效、图片、图标、官方 logo、人声配音、字幕、抠图去背景, 以及视频调色、剪裁这类画面处理。

- input: 一句需求:「配一段轻快的咖啡店背景音乐」, output: 一个本地音频文件, 拖进视频就能用
- input: 一段视频文件 + 一句话:「画面太暗太闷, 想要复古胶片感」, output: 调好色的同款视频: 画面更亮, 带胶片质感
- input: 一段约 200 字的产品文案, output: 一条自然的人声旁白音频 + 配套的字幕文件
