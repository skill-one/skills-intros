# hyperframes-creative (`heygen-com/hyperframes/hyperframes-creative`)

## blackbox

**function**: 给你的视频点子做整体视觉与内容设计——配色、字体、旁白文案、镜头节奏、画面构图、音乐联动一次定好, 让成片有统一的风格和叙事感。

- input: 一句主题描述, 如「帮我做一支 60 秒的咖啡新品预告视频, 主题是清晨第一口」, output: 一份完整视觉方案: 配色板 + 字体组合、带开头钩子的旁白文案、分镜节奏表 (每一拍出现什么画面、持续几秒、何时切换)
- input: 一个设计规范文件 (frame.md / design.md) + 一句「按规范做第 2 个场景」, output: 严格贴合该规范的场景设计稿: 颜色、字体、间距、圆角全部对齐规范, 附画面构图说明 (主视觉、前景细节、文字摆放位置)
- input: 一段背景音乐音频文件 (mp3 / wav), output: 音频节拍分析 + 画面联动方案: 鼓点、重音出现在第几秒, 对应画面里哪些元素跟着跳动、闪现或放大
