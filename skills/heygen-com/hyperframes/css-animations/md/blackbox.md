# css-animations (`heygen-com/hyperframes/css-animations`)

## blackbox

**function**: 给 HyperFrames 视频合成页面编写 CSS 关键帧动效（脉冲波纹、微光扫过、圆点依次弹入这类装饰动画），保证预览和最终渲染时动画时间精准、进度条任意拖动画面都稳定一致。

- input: 一个 HyperFrames 页面，需求是"加一个从中心扩散的脉冲圆环，播 3 次就停", output: 写好的页面代码：圆环由小放大、渐隐消失，共 3 轮，预览和渲染成片里每轮的时机完全一致
- input: 一句话需求："三个小圆点依次弹起入场，每个间隔 0.12 秒", output: 错峰入场的页面代码：三个圆点逐个弹起落定，一套规则控制全部，时间间隔精确到帧
- input: 一段现成的 CSS，动画是无限循环、靠鼠标悬停才触发, output: 修正后的版本：改成有限次数、无需鼠标操作，拖动预览进度条时每个时刻的画面都固定不变
- input: 需求："背景上加一层若隐若现的光扫过效果", output: 微光 (shimmer) 动画层代码：只在对应画面片段播放，片段开始前和结束后画面保持静止
