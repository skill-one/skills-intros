# hyperframes-audio (`heygen-com/hyperframes/hyperframes-audio`)

## blackbox

**function**: 给已经放进网页作品里的声音做混音: 让音乐和旁白不打架、加淡入淡出、修掉发闷发浑的音色, 改完直接拿回去就能播。

- input: 同一页面里「背景音乐 + 旁白」两条音轨的代码, output: 改好的代码 — 有人说话时音乐自动让开人声的音区, 话音一停音乐自然恢复, 两条轨都能听清
- input: 「片尾音乐要渐弱收尾, 现在戛然而止」+ 对应页面代码, output: 写好淡出的代码, 结尾音乐平滑收住, 不再突兀掐断
- input: 「这段人声发闷、字听不清」+ 音轨代码, output: 加好修音色设置的代码, 回放时人声明显清楚干净
