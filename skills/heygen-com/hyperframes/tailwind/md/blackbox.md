# tailwind (`heygen-com/hyperframes/tailwind`)

## blackbox

**function**: 给你的 HyperFrames 视频/动画合成页面 (HTML) 写样式、修样式, 让渲染出来的每一帧画面排版正确、不缺样式、不闪白。

- input: 一句需求, 如「做一个开场页: 深色背景, 白色大标题居中, 顶部一行小字」, output: 可直接放进合成里的 HTML 片段, 渲染出来就是你描述的画面
- input: 用 --tailwind 创建的项目里的 index.html, output: 修改后的 index.html: 布局、配色、字体到位, 渲染第 0 帧样式就完整
- input: 一段样式不生效的旧写法代码 (或「预览有样式、导出视频没样式」的描述), output: 改成新版可用写法的代码 + 简短说明改了哪里, 样式恢复正常
