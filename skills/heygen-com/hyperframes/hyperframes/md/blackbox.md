# hyperframes (`heygen-com/hyperframes/hyperframes`)

## blackbox

**function**: 把文字、网址、音乐或录好的视频片段, 做成一支能直接发布的成品视频 (mp4)——宣传片、解说片、配字幕的真人视频、卡点短视频都可以。

- input: 一个产品网站的网址, 例如 https://example.com, output: 一支自动展示网站页面和亮点的宣传视频文件 (mp4)
- input: 一首歌的音频文件, output: 画面跟着音乐节拍切换的短视频 (mp4)
- input: 一段录好的真人讲话视频, output: 同一支视频, 但加上了字幕或设计好的信息卡片
