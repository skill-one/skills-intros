# figma (`heygen-com/hyperframes/figma`)

## blackbox

**function**: 把你发来的 Figma 设计稿（链接）变成能直接放进视频里的素材：抠出 logo 和图片、提取品牌颜色、还原整个设计画面，甚至让静态设计稿"动起来"生成动画视频。

- input: 一个 Figma 图层链接（比如你的 logo 或某个图标）, output: 一张可直接插入视频的图片文件（SVG 或高清 PNG），附好说明文字
- input: 一个 Figma 设计文件链接, output: 该品牌的颜色规范清单（主色、辅色、变量），改一处颜色就能整体换肤
- input: 一个 Figma 画框链接（含动效或一组连续的分镜画面）, output: 一段按原设计运动效果还原的动画视频，画面元素会像在 Figma 里预览的那样移动、淡入、滑出
