# ai-video-generation (`qu-skills/superpowers/ai-video-generation`)

## blackbox

**function**: 你给一段文字描述或一张图片, 我帮你生成一段能直接用的视频 (还能让它说话、加音效、剪改、变清晰)。

- input: 一段画面描述文字, 如: 「无人机镜头飞越秋天清晨的森林, 阳光穿透薄雾」, output: 一条生成好的视频文件 (MP4), 画面即描述的场景, 可带环境音效, 直接下载使用
- input: 一张图片的链接 (URL), 如: 一张产品图或风景照, output: 这张图片「动起来」的视频: 镜头平移、风吹叶动等, 就像照片活了
- input: 一张人物照片 + 一段录音 (如一段配音 mp3), output: 照片里的人开口说话的视频, 口型和声音对得上 (可用于数字人口播、讲解视频)
