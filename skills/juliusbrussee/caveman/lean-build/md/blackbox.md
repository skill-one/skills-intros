# lean-build (`juliusbrussee/caveman/lean-build`)

## blackbox

**function**: 把你的功能需求做成能直接用、能跑通的完整改动, 只做你要的, 多余的一概不加, 达到验收标准就停手。

- input: 一句话需求: 「给网站加一个忘记密码功能」, output: 改好的代码: 从点击「忘记密码」到收邮件、重置成功的完整流程都能走通, 不附带任何用不上的选项或扩展
- input: 现有项目 + 新需求: 「订单列表要能按状态筛选」, output: 在现有代码上完成的最小改动, 筛选功能打开页面就能用, 并附一句说明哪些是刻意没做的
- input: 一段模糊想法: 「想让用户能导出自己的数据」, output: 先给你明确的验收标准和「不做清单」, 再交付刚好满足验收的改动, 不多写一行
