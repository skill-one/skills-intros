# migration (`juliusbrussee/caveman/migration`)

## blackbox

**function**: 帮你把系统从旧状态安全搬到新状态（如数据库、接口、配置升级）——数据不丢、随时能退回原样、新旧版本可同时在线不互相打架。

- input: 现在的数据库表结构 + 你想要的新表结构, output: 一套搬迁方案：先扩新、再搬数据、核对无误后才动旧的；附每步「数据一根不少」的核对记录，出问题一键退回原样
- input: 旧版接口说明 + 新版接口设计（比如 App 要改接口，老版本用户还没升级）, output: 过渡方案：老版本用户照常用、新版本正常上，附切换顺序清单和回退步骤，切换当天业务不断
- input: 项目的依赖清单文件 + 一句「帮我升级到新版本」, output: 升级后的清单文件 + 一份变更报告：改了哪些地方、每处怎么验证没坏、哪一步出问题怎么退回去
