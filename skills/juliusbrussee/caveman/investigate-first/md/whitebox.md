# investigate-first (`juliusbrussee/caveman/investigate-first`)

## whitebox

- 收集证据: 追踪输入、状态变化、所有权边界、失败输出, 只把观察到的症状当事实
- 从证据生成候选假设, 按证据支持度 × 证伪成本排序
- 从最便宜的证伪入手逐个检验假设
- 证据足以指名原因 (或确切阻塞点) 时, 停止探索
- 输出'原因 + 证明'; 任务未授权实施, 则不改任何代码

- 症状/原因强制分离: 每条信息标注'观察到'还是'推断出', 推断只作待验假设, 不当事实使用
- 证据排序 + 廉价证伪: 不穷举验证, 优先检验最易被推翻的假设, 快速收敛到唯一可信机制
- 编辑门禁 (双重校验): ① 没有单一可信机制解释全部证据前, 禁改产品代码; ② 即使找到原因, 任务未授权实现也不修。全程无外部工具/库/模型 API 依赖
