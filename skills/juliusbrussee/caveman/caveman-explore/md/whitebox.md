# caveman-explore (`juliusbrussee/caveman/caveman-explore`)

## whitebox

- 接收 solver (主求解 agent) 委派的定位问题 — 只负责找"相关代码在哪里", 不改文件、不跑命令、不提方案
- 第一轮就并行发出多个工具调用撒大网: Glob (按路径模式猜位置) + Grep (按符号/字符串搜) + Read (直接读最有希望的文件), 互补假设一次覆盖
- 如有必要再跟进 1~2 轮验证; 一旦能说出相关位置就立刻收工, 为 solver 的 token 预算省时间
- 只回传一个证据块: 每行一条 `路径:起止行  相关原因`, 无前言、无解释、无总结

- 并行扇出 (fan-out) 搜索: 不逐个文件试探, 第一轮同时验证多条互补假设 — Glob 锁定候选文件, Grep 定位符号与字符串, Read 确认内容
- 严格引用纪律: 只引用实际读过的行区间, 绝不编造/估算行号, 绝不引用超出文件末尾的范围; 宁可小而精确, 不给大而模糊
- 依赖与隔离: 仅用 Read / Glob / Grep 三个只读工具, 运行在 haiku 模型 (Anthropic 的快速低价模型); 读取过程不进入 solver 主上下文, 只回传引用列表
