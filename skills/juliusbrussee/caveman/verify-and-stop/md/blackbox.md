# verify-and-stop (`juliusbrussee/caveman/verify-and-stop`)

## blackbox

**function**: 给一份已有的工作成果(如代码、任务)和验收标准,我只做一件事:验证它是否达标,然后交给你一份"过/不过"的判定报告——不改代码、不加功能、不画蛇添足。

- input: 一段验收标准(如「用户能登录、能退出」)+ 代码所在的仓库地址, output: 一份验证报告:逐条标注每条标准是「通过 / 不通过 / 无法验证 / 被卡住」,并附上验证时实际执行的检查和真实结果
- input: 「帮我确认这个功能是不是真的做完了」+ 项目路径, output: 一个明确的完成结论(达标 ✅ 或 未达标 ❌),列出不达标的具体证据;绝不顺手改代码或加优化
- input: 「只检查登录相关的部分,别跑全套」, output: 只针对登录部分的快速检查结果;如果已检查的部分全部达标,就到此为止,主动结束并汇报,不多做一步
