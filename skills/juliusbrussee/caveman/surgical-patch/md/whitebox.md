# surgical-patch (`juliusbrussee/caveman/surgical-patch`)

## whitebox

- 先复现故障（划算时）；复现不了就抓最硬的现有证据（报错、日志、复现路径）。
- 从症状向上追溯，找到真正「拥有」错误行为的那个代码位置。
- 只改这一层最窄的代码，其余一律不动。
- 补一条仅与本任务相关的回归证明（通常就是针对该 bug 的一个测试）。
- 跑回归测试 + 离改动最近的验证门（gate），失败已修复且回归通过即收工。

- 定位机制：先把症状追到「负责出错行为」的具体机制，改动落在持有该行为的最窄一层，不跨层打补丁。
- 最小 diff 约束：修复范围外不做清理、重命名、抽象，用户已有改动全部保留——diff 里只允许出现与 bug 相关的内容。
- 局部验证：只跑聚焦回归测试 + 最近的验证门（gate：项目里已有的检查，如相关测试/lint），不跑全量；本技能不依赖任何外部工具、库或模型 API，验证全靠项目自带的测试与检查。
