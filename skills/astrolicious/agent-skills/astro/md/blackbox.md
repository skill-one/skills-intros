# astro (`astrolicious/agent-skills/astro`)

## blackbox

**function**: 帮你从零搭建或修改 Astro 网站 (一种做内容型网站的主流框架), 从页面代码到部署成品一步到位。

- input: 一句需求: 「帮我建一个博客网站, 能发文章、有首页列表」, output: 一个可运行的网站项目: 浏览器打开本地预览地址就能看到首页和文章页
- input: 一段描述: 「做一个带导航栏、三张产品卡片的官网首页」, output: 写好的首页代码文件, 放进项目里刷新即可看到效果
- input: 一条指令: 「把网站部署到 Vercel」, output: 配置好的项目 + 打包完成的 dist 文件夹 (可直接上传上线的成品)
- input: 一个出错的 Astro 项目路径 + 报错信息, output: 定位到问题的修复方案或修正后的代码文件
