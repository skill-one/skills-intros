# browser-use (`browser-use/browser-use/browser-use`)

## blackbox

**function**: 替你操作网页浏览器：像真人一样打开网页、点击、填表、翻页、截图、下载，把你交代的事在网站上办完。

- input: 一个商品列表页的网址 + "把前 20 个商品的名字和价格整理出来" → output: 一份整齐的名称/价格对照表（可直接复制或存成文件）, output: 一份整齐的名称/价格对照表（可直接复制或存成文件）
- input: "用我已登录的浏览器，把这个后台里上个月的 30 张发票全部下载下来" → output: 30 个发票 PDF 文件保存到电脑上，附一份下载清单, output: 30 个发票 PDF 文件保存到电脑上，附一份下载清单
- input: 你自己网站的网址 + "测一下注册流程能不能走通" → output: 实际走完一遍注册的结论报告：哪一步卡住、页面长什么样（附截图）, output: 实际走完一遍注册的结论报告：哪一步卡住、页面长什么样（附截图）
