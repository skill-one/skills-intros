# brandalf (`warpdotdev/common-skills/brandalf`)

## blackbox

**function**: 给 Warp / Oz 出品的东西做品牌把关：你给我需求或草稿，我交付看起来、读起来都是「正宗 Warp 味道」的成品。

- input: 「帮我做一个 Warp 新功能的发布页（HTML）」, output: 一个可直接打开的发布页文件：配色、字体、文案都符合 Warp 品牌规范，并附一句用了哪些品牌规则的说明
- input: 一段已写好的产品介绍文案, output: 按 Warp 品牌口吻改写后的文案，并标出原文里不符合品牌语气的地方
- input: 一份现成的 Warp 宣传 PPT / 网页组件, output: 品牌审查意见清单 + 修正后的文件，指出哪里不像 Warp、该怎么改
