# saga (`warpdotdev/common-skills/saga`)

## blackbox

**function**: 你用一句话说出想要的中大型功能, 我先跟你确认几个关键决定, 然后自动把它开发、验证到完成, 你只需在开头点头和最后验收。

- input: 一段粗略需求, 如「给我的博客后台加草稿自动保存」, output: 实现完毕、每项要求都验证过的完整代码 (以代码分支或补丁交付), 附一份完成报告和手动检查步骤
- input: 对我发来的几道选择题的回答 (如功能范围、验收标准怎么定), output: 一份明确到可以直接开工的开发方案, 等你批准后我才动工
- input: 一句「继续上次没做完的那个功能」, output: 接着上次中断的进度自动往下推进, 直到功能交付并请你最终验收
