# council (`warpdotdev/common-skills/council`)

## blackbox

**function**: 给一个悬而未决的问题,你会拿到多位独立"评审专家"各自分析后的汇总结论:一份明确告诉你该选哪个方案、风险在哪的决策建议。

- input: "这个 PR 的修复能不能直接合并?" + PR 链接, output: 一份简短结论:可合/暂缓、关键风险点、合并前建议跑的测试
- input: "单体要不要拆成微服务?" + 代码仓库路径, output: 一份决策备忘录:推荐方案、各方共识与分歧、成本和下一步动作
- input: 两个候选技术方案 A 和 B 的描述(或链接), output: 一页对比结论:哪个胜出、为什么、落选方案输在哪
- input: 一段线上事故的日志和现象描述, output: 事故分析报告:最可能的原因排序 + 修复与预防建议
