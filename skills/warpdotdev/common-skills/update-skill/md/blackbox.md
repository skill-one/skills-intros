# update-skill (`warpdotdev/common-skills/update-skill`)

## blackbox

**function**: 把你的想法或已有的技能说明, 直接产出或改写成一份规范好用的 SKILL.md 文件 (描述某项技能该怎么做、什么时候用的说明文档)。

- input: 一句话需求, 如「帮我做一个整理会议纪要的技能」, output: 一份完整可用的 SKILL.md 文件, 含名称、描述和使用步骤
- input: 一个已有技能的文件夹路径, output: 修改后的 SKILL.md, 结构更清晰、描述更准确规范
- input: 一份写得太啰嗦、重点不清的 SKILL.md, output: 精简重写后的 SKILL.md, 关键内容突出、容易被找到
