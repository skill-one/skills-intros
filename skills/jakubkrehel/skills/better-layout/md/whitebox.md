# better-layout (`jakubkrehel/skills/better-layout`)

## whitebox

- 接收界面代码/设计稿, 按布局原则清单逐条审查: 空间分组、控件与内容区分、共享对齐边缘、重要度排序、隐藏内容提示、控件呼吸间距
- 修复写进项目现有样式系统; 仅当项目无既定密度体系时才用 skill 默认值 (如组间距 ≥ 2× 组内间距)
- 压力测试: 多视口宽度缩放、伪本地化模拟翻译变长、RTL 镜像、按内容实际断裂点而非设备预设设断点
- 按「严重度/位置/修改前/修改后/原因」表格输出报告, 未检查项标 Not verified
- 存在 HIGH 问题则以 Block 收尾, 否则 Approve

- 解析: 原则驱动清单, 8 条主规则 (空间优先于线条分组、控件需视觉可辨识、内容贴边/控件留边、断点由内容决定等) + 收尾错误对照表兜底; 数值 (8/12/16/24px) 仅为无体系项目的起步默认值
- 转换: 方向相关布局一律用逻辑属性 (margin-inline-start 替代 margin-left), 保证 RTL 可镜像; 关键操作不放易被裁切的窗格底部, 用 sticky 或安全区稳定层
- 校验: 双模式——无浏览器时做静态检查 (逻辑属性、container/media query、DOM 顺序 vs 阅读顺序); 有浏览器时逐视口宽度 + 200% 缩放 + RTL 镜像实测; 无法验证的项如实标 Not verified
