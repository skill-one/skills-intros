# better-colors (`jakubkrehel/skills/better-colors`)

## blackbox

**function**: 帮你搞定界面配色: 从零生成一整套色板、检查文字放在背景上是否看得清、统一或转换颜色格式, 并回答项目里的任何用色问题。

- input: 「我要做一个健康类 App, 给我一套从浅到深的完整色板」, output: 一组可直接复制的色值 (如 #F0FDF9 → #0F766E), 每个色号都标注了用途: 页面底色、边框、按钮填充、正文文字……拿来即用, 不用自己猜哪个色号该放哪
- input: 「白色文字放在 #4A90D9 的按钮上, 看得清吗?」, output: 实测的对比度数值和结论, 例如「3.2 : 1, 不达标, 距离 4.5 : 1 还差多少」; 只报告事实, 不擅自替你改颜色
- input: 项目的配色文件路径 (CSS 变量 / Tailwind 配置), output: 一份按严重程度排序的问题清单表格: 哪个色值对比度不够、哪两个颜色放在一起容易混淆、哪个颜色命名不合规, 每条都写明具体位置和原因
