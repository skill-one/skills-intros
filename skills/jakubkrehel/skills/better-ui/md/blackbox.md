# better-ui (`jakubkrehel/skills/better-ui`)

## blackbox

**function**: 给你的网页/应用界面做"精装修": 找出那些让界面看着不对劲的细节 (圆角不齐、按钮按压没反馈、图标偏了、动画太闹), 直接改代码或给出一份问题清单。

- input: 一个前端项目的代码 (如 React / Vue 项目), output: 一份按严重程度排序的 UI 体检表: 哪个文件哪一行、现在什么样、改成什么样、为什么, 最后给出「必须修 / 可以慢慢修」的结论
- input: 一个组件的代码文件, 比如登录按钮或卡片组件, output: 改好的代码: 按下时按钮有恰到好处的缩放反馈、内外圆角同心、图标和文字粗细匹配, 拿来就能用
- input: 一句描述, 如「点主题切换按钮时整个页面闪一下」, output: 修复后的代码, 主题切换变成干脆利落的一瞬间, 不再颜色渐变拖泥带水
