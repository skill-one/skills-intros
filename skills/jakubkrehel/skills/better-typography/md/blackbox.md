# better-typography (`jakubkrehel/skills/better-typography`)

## blackbox

**function**: 给你的网页或产品界面做「文字排版体检」——哪里字太大太小、行距挤不挤、标题换行丑、数字跳动、内容被截断, 逐条指出并给出能直接照抄的修改写法。

- input: 一个正在开发的网页项目(代码仓库, 或线上页面地址/截图), output: 一份排版问题报告: 表格形式, 按严重程度排列, 每条写清位置、现状是什么、改成什么、为什么改; 全部没问题则明确说「无排版问题」, 不硬找茬
- input: 「我们首页大标题在手机上换行特别难看, 第二行只孤零零挂一个字」, output: 针对这个问题的具体修复方案(改哪处、换成什么写法), 附一句白话原因, 直接照抄即可生效
- input: 「界面上价格和倒计时每秒刷新时整个版面都在抖」, output: 指出原因并给出对应的排版写法, 让数字更新时不再带动布局晃动
