# attribution (`coreyhaines31/marketingskills/attribution`)

## blackbox

**function**: 帮你回答「客户到底是被哪个渠道带来的」: 当广告平台、网站统计、销售系统给的数字互相打架时, 帮你理清谁在多报功劳、每个渠道对收入的真实贡献、以及下一笔预算该往哪投; 也可以帮你从零搭一套自己的来源追踪。

- input: 导出的三份对不上的数字: 广告平台说带来 50 单, 网站统计说 60 单, 客户系统里只有 35 单, output: 一份对账报告: 该以哪个数字为准、为什么每个工具都会多报、哪些渠道是真涨真跌, 以及下次投放该按哪个数字花钱
- input: 一段业务描述: 「我们是 B2B 软件, 客户从看到广告到签约要两三个月, 渠道有付费搜索、内容、线下活动, 每季度预算 50 万」, output: 一套测量方案: 该用哪种归因模型 (即『一单功劳算给谁』的记账规则)、哪些渠道值得单独做小实验验证真实效果、你现在的数据里哪些渠道根本看不见
- input: 「我的转化报表里 60% 来源写的是『直接访问』, 不知道这些人哪来的」, output: 一份诊断: 说明这通常是追踪盲区而非真实渠道 (老客户口碑、播客、私信转发都躲在里面), 并给出补救办法——比如在转化时加一道『你怎么知道我们的?』小调查
- input: 「我想自己搞清楚: 每个注册付费的客户, 最初是从哪个渠道进来的」, output: 一份从零搭建的追踪方案: 怎么把客户的首次访问来源一路带到注册/付款那一刻并写进客户系统, 先查什么、改哪里、最后能看到哪张报表
