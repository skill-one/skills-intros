# popup-cro (`coreyhaines31/marketingskills/popup-cro`)

## whitebox

- 读取上下文文件 .agents/product-marketing-context.md（旧版在 .claude/ 下），有则直接复用，减少向用户提问
- 评估三件事：弹窗目的（订阅/引流/折扣/挽留等）、现状（已有弹窗表现）、流量来源
- 根据目的匹配触发策略（时间/滚动/退出意图/点击触发）和弹窗类型（邮件收集/线索磁铁/公告条等）
- 按固定输出格式产出设计方案：类型、触发、定向、频次、文案（标题/副标/CTA/拒绝选项）、设计要点
- 可选：给出 A/B 测试假设，进入迭代

- 纯规则库驱动，无外部工具/库/模型 API 依赖：核心是内置决策表（触发策略×弹窗类型×文案公式×行业策略模板），输出全由查表+组合生成
- 意图关键词路由：用户提到 "exit intent"、"lead capture popup"、"sticky bar" 等词即命中本技能；表单类转 form-cro，页面转化转 page-cro（Related Skills 边界分发）
- 数值校验来自内置基准：邮件弹窗转化 2-5%、退出意图 3-10%、点击触发 10%+，用于设定预期与评估方案；合规约束（GDPR、可访问性、Google 插页式广告规则）作为硬性检查项附在输出中
