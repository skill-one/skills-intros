# public-relations (`coreyhaines31/marketingskills/public-relations`)

## blackbox

**function**: 帮你的产品获得媒体报道:找对记者、写出他们会愿意回的 pitch、蹭上热点新闻、准备播客采访。

- input: 一条正在发酵的热点新闻(如「AI 创业公司裁员潮上热搜了,我们怎么看」), output: 2~3 个借势切入的角度 + 一封 150 词以内、可直接发给记者的 pitch 邮件
- input: 「帮我找报道过竞品/我所在行业的记者」, output: 一份打分排序的记者名单,含每人近期写过什么、为什么适合、该用哪个角度去 pitch
- input: 「下周我要上 XX 播客当嘉宾,帮我准备一下」, output: 一份嘉宾简报:这档节目反复聊的话题、主持人风格、你该讲的 3 个故事和避开的雷区
- input: 「我们没什么大新闻,但也想被报道,该讲什么故事?」, output: 给你的公司找出 1~3 个可传播的故事角度(创业故事/以小博大/向坏制度开战),并说明各自适合投给谁
