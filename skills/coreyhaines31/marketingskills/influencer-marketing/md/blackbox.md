# influencer-marketing (`coreyhaines31/marketingskills/influencer-marketing`)

## blackbox

**function**: 帮品牌方完成从找达人、谈价、定合同条款、写合作简报到追踪投放效果的达人营销全流程, 并确保广告披露合规。

- input: 「我想做 YouTube 达人推广, 预算 5000 美元」, output: 一份投放方案: 该找哪些量级的达人、预算怎么分配、怎么开口谈价、上线前怎么装好效果追踪
- input: 某个达人的账号主页和粉丝数 (如: 3 万粉的 TikTok 博主), output: 一份投前评估: 受众是否匹配你的买家、互动和评论质量如何、真假粉丝疑点、大致报价区间和谈判切入点
- input: 一份准备发给达人的合作简报草稿, output: 修改后的简报: 一句话讲清卖点、2-3 个必讲要点、明确的行动号召、必须标注的「广告」声明、不能乱承诺的禁区
- input: 一份达人合作协议草稿 (或一条合同问题, 如「要加内容授权条款吗」), output: 标注出缺失的关键条款: 内容二次使用授权、竞品排他期、广告披露义务、付款与终止条款, 并给出建议写法
- input: 一次投放结束后拿到的数据 (优惠码使用数、链接点击数等), output: 一份效果复盘: 按实际成交算的获客成本、哪些达人值得加投、下一步是复投还是转长期合作
