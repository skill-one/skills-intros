# copy-editing (`coreyhaines31/marketingskills/copy-editing`)

## whitebox

- 先读品牌上下文: 若工作区存在 .agents/product-marketing.md 等文件, 先读取以获取品牌语调和用户语言
- 按序跑七轮清扫 (Seven Sweeps): 清晰 → 语调 → '所以呢' → 证据 → 具体化 → 情绪 → 零风险, 每轮只查一个维度
- 每轮结束后回查之前各轮, 防止新改动引入新问题; 高风险文案 (落地页/发布邮件) 额外跑专家团打分 (3~5 个专家人格各打 1~10 分, 修订至全部 ≥7、均分 ≥8)
- 输出「发现的问题 + 具体修改建议」, 与作者迭代, 直到完整清扫一遍不再发现新问题

- 单维度清扫 + 回查链条: 不一次性修所有问题, 每轮只盯一类毛病 (如: 每条主张是否答了「所以呢」、有无证据支撑); 每轮收尾回查前序轮次, Zero Risk 轮收尾时从情绪一路回放到清晰
- 分层快查规则: 词级/句级/段落级规则表 (砍掉 very/really 类弱化词、弱词强词替换表、每句一个观点等); 交付形式是「指问题 + 给具体改法」, 不直接替作者定稿, 保留其最终决定权
- 无外部工具/模型依赖: 仅用技能包内 3 份参考文档 — checklist.md (完整 QA 清单)、plain-english-alternatives.md (难词替换表)、content-refresh.md (旧文案刷新清单), 加上可选读取用户工作区的 .agents/product-marketing.md
