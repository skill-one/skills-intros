# referral-program (`coreyhaines31/marketingskills/referral-program`)

## blackbox

**function**: 帮你设计、优化「老用户带新用户」的推荐奖励机制, 从方案到落地文案都能给。

- input: 「我有个 SaaS 产品, 想让老客户介绍新客户, 该怎么设计奖励?」, output: 一份完整推荐方案: 推荐人和新用户各得什么奖、在什么时机弹出邀请、用什么话术、怎么防刷单
- input: 「推荐计划上线 2 个月, 只有 3% 的用户用过, 问题在哪?」, output: 一份问题诊断报告: 定位卡在哪个环节 (不知道、不想分享、分享了没转化), 以及对应的改进动作清单
- input: 「帮我写一封向老用户宣布推荐计划的邮件」, output: 可直接发送的邮件文案, 含标题、正文和行动按钮文案
