# paid-ads (`coreyhaines31/marketingskills/paid-ads`)

## blackbox

**function**: 帮你规划并优化付费广告投放: 从选平台、搭结构、分配预算、写广告文案, 到根据投放数据给出改进动作, 目标是花更少的钱带来更多客户。

- input: 一句产品/服务描述 + 月预算 + 想要的结果 (如「B2B 客户管理软件, 月预算 3 万, 想拿试用注册」), output: 一份可直接执行的投放方案: 投哪个平台、广告系列怎么搭建、预算怎么分、每阶段盯什么指标
- input: 现有广告的表现情况 (如「Facebook 广告点击率只有 0.5%, 获客成本一路上涨」), output: 一条问题诊断 + 一份按优先级排好的优化清单 (换什么素材角度、缩放哪部分定向、该排除哪些人)
- input: 产品卖点和目标人群的描述 (如「帮小餐饮店做会员系统的 App, 客户是 30-45 岁的店主」), output: 一组可直接上线测试的广告文案: 多个不同角度的标题、正文、行动号召, 并注明每个角度适合放在哪
