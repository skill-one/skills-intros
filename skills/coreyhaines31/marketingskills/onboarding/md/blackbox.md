# onboarding (`coreyhaines31/marketingskills/onboarding`)

## blackbox

**function**: 帮你优化产品注册后的新手引导:让新用户更快体验到产品的核心价值,而不是注册完就走人。

- input: 一段产品描述 + 问题现状, 如:「我们是 B2B 项目管理工具, 用户注册后 60% 再也没打开过第二次」, output: 一份新手引导优化方案: 定义「激活时刻」、设计最短价值路径、首日流程分步说明、需要跟踪的指标
- input: 各步骤的漏斗数据, 如:「注册 100% → 完善资料 80% → 邀请同事 35% → 创建首个项目 12%」, output: 一份流失诊断报告: 指出最该先修的环节, 每个问题按「现象 → 影响 → 建议 → 优先级」给出改进排序
- input: 首次使用流程的截图或文字描述, 如「注册后先看 5 页教程, 再填 8 项资料, 然后进入空白首页」, output: 一份逐项审核清单: 具体到每一屏的问题 (如步骤太长、空页面没有引导), 附可直接抄用的界面文案和改进示例
