# page-cro (`coreyhaines31/marketingskills/page-cro`)

## blackbox

**function**: 帮你的营销页面(首页、落地页、定价页等)找出访客看完就走、不注册不下单的原因, 并给出能直接照着改的具体方案。

- input: 一个落地页的 URL + 一句话说明目标(如「想让访客免费注册」), output: 一份转化诊断报告: 按「现在就能改的速赢项 → 高影响改动 → 值得测试的假设」分级列出, 附每条的改动理由
- input: 首页首屏的标题和按钮文案 + 页面类型, output: 2~3 组可直接替换的主标题 / 按钮文案备选, 每组附带为什么这样写能更容易打动访客的说明
- input: 定价页内容 + 疑惑(如「用户总问不知道选哪个套餐」), output: 针对选择困难的具体改法: 如标注推荐套餐、简化套餐对比、在犹豫点旁边补充答疑内容的建议
