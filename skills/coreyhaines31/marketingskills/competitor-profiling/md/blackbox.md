# competitor-profiling (`coreyhaines31/marketingskills/competitor-profiling`)

## blackbox

**function**: 给我竞争对手的网站地址, 我帮你摸清每家的底细——卖什么、怎么定价、功能强弱、线上口碑、网站流量——最后给你一份能横向对比的调研报告。

- input: 3 个竞争对手网站的网址 (如 https://competitor-a.com), output: 每家一份调研档案文件: 它的定位口号、定价表、核心功能、客户评价和评分、网站流量水平, 一目了然
- input: 竞争对手网址 + 一句话说明你自己的产品是什么, output: 档案里多出一节「对我方的启示」: 对方哪里比我们强、我们哪里占优、哪里有可乘之机、哪里需要警惕
- input: 多个竞争对手网址 (5 家以上), output: 在逐家档案之外, 额外得到一份横向对比总结: 关键指标对照表、各家定位分布、市场空白点分析
- input: 「快速看一下这两家」, 不要求深入, output: 精简版快照报告: 只保留关键事实 (主打卖点、价格、大致流量), 几分钟出结果
