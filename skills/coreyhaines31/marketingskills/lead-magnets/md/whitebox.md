# lead-magnets (`coreyhaines31/marketingskills/lead-magnets`)

## whitebox

- 先查上下文: 查找并读取项目内的产品营销档案 (.agents/product-marketing.md 等路径), 已有的信息不重复问
- 收集缺口: 只追问缺失的四类上下文 — 业务/理想客户、现有获客方式、可复用内容资产、目标 (邮箱增长还是线索质量/买家阶段/时间资源)
- 匹配方案: 按买家阶段 (认知/对比/决策) 从内置格式表 (清单/模板/电子书/测验/webinar 等) 选出钩子类型与选题
- 规划捕获: 定门槛策略 (全门槛/部分门槛/内容升级)、表单字段 (字段越多转化越低, 每加一个降 5-10%)、落地页结构与交付方式
- 按固定五段产出策略: 推荐方案 → 内容大纲 → 门槛与捕获 → 分发计划 → 衡量计划 (KPI + 首个 A/B 测试); 超范围任务转交关联 skill

- 上下文预载: 启动时优先读 .agents/product-marketing.md (兼容 .claude/ 变体和旧文件名 product-marketing-context.md), 用它填充业务背景, 只追问未覆盖项 — 依赖文件系统读取, 不依赖外部库或模型 API
- 查表驱动决策: 格式选择、门槛权衡、交付方式、指标基准 (如落地页转化率热流量 20-40% / 冷流量 5-15%) 全部来自 skill 内置的查找表, 属纯知识推理, 无外部计算
- 技能路由分发: 本 skill 只做'规划', 写实际文案转 copywriting, 互动工具转 free-tools, 捕获后的邮件序列转 emails, 落地页/表单优化转 cro, 弹窗实现转 popups — 通过引用兄弟 skill 完成闭环
