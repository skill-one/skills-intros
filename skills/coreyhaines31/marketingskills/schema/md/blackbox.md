# schema (`coreyhaines31/marketingskills/schema`)

## blackbox

**function**: 给你的网页生成一段"结构化数据"代码——贴上去后, Google 搜索结果里你的链接会多出星级评分、价格、常见问答等额外信息 (俗称富摘要), 更显眼、更容易被点开。

- input: 商品页信息: 商品名、图片链接、价格 ¥299、库存状态, output: 一段可直接粘贴到网页里的代码; 贴好后, Google 搜索结果中你的商品会显示价格、有货状态和星级评分
- input: FAQ 页面上的 5 组「问题 + 回答」文本, output: 对应的 FAQ 代码; 搜索结果里你的链接下方会直接展开显示这些问答
- input: 网页里已存在的一段结构化数据代码 (或页面 URL), output: 一份错误清单 (缺了哪个必填字段、哪里的日期/链接格式不对) + 修正后的完整代码
