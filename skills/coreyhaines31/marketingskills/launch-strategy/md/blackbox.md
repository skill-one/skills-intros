# launch-strategy (`coreyhaines31/marketingskills/launch-strategy`)

## blackbox

**function**: 帮你规划产品或新功能的发布——从预热、上线当天到发布后跟进, 给出一份能直接照着做的发布方案。

- input: 「我们刚做完 MVP, 想找第一批用户」+ 一句话产品描述, output: 一份分阶段发布路线图: 先小范围内测收集反馈 → 上线等待名单页造势 → 逐步放量开放, 每阶段附具体动作和目标
- input: 「下周三要在 Product Hunt 发布, 要准备什么?」, output: 一份发布日作战清单: 发布前要打磨的页面和素材、当天全天的互动节奏 (逐条回复评论、引导注册)、发布后的转化跟进事项
- input: 「新功能『自动备份』下周上线, 需要多大声张?」, output: 按功能体量定宣传力度: 这种小更新只需发更新日志 + 站内横幅即可, 不必全渠道造势; 并给出每个渠道该发什么
