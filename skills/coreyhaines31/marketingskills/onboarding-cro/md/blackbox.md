# onboarding-cro (`coreyhaines31/marketingskills/onboarding-cro`)

## blackbox

**function**: 帮你的产品优化新用户上手流程:让注册用户更快体验到价值、留下来,而不是注册完就流失。

- input: 一段现状描述,如:「我们是 B2B 协作工具,用户注册后 7 天只有 8% 会再回来」,再加上产品简介, output: 一份上手流程诊断报告:逐条列出问题点 → 影响 → 改法建议 → 优先级排序
- input: 产品类型 + 你期望用户完成的关键动作,如:「希望新用户创建第一个看板」,以及注册后现状, output: 一套完整的新手引导设计:首次登录每一步做什么、任务清单条目、空状态文案、提醒邮件触发时机、要盯的指标
- input: 各环节流失数据,如:注册 100% → 完成设置 60% → 达成关键动作 40%, output: 指出流失最严重的环节,并给出针对性的改进方案和可验证的实验建议
