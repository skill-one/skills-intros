# cro (`coreyhaines31/marketingskills/cro`)

## blackbox

**function**: 帮你诊断营销页面 (首页、落地页、定价页、报名表单) 为什么访客不转化, 并给出能直接上手的修改建议和替代文案。

- input: 你的落地页 URL + 一句「这页没人注册」, output: 一份诊断报告: 按见效快慢排好序的改进清单 (先列立刻能改的小改动, 再列影响大的结构性改动), 每条写清改什么、为什么改
- input: 粘贴你现在的主标题和按钮文字, 如「立即了解更多」, output: 2~3 个更有吸引力的替代版本 (聚焦用户能得到什么, 而不是动作本身), 每个附一句改动理由
- input: 描述定价页的问题, 如「摆了三个套餐, 用户不知道选哪个就不买了」, output: 针对定价页的具体整改建议 (如标出推荐套餐、怎么消除「选错」的顾虑), 外加几个值得做对照测试的点
