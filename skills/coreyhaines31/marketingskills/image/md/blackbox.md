# image (`coreyhaines31/marketingskills/image`)

## blackbox

**function**: 帮你做出营销用的成品图片——从一张文字描述生成博客头图、社交配图、产品展示图, 到把现有图片压缩到网站加载飞快, 拿到就能直接用。

- input: 一句话描述, 如「帮我做一张博客头图, 主题是远程办公, 用在公众号和网页上」, output: 一张 1200x630 的成品图片, 博客顶部和分享卡片都能直接用
- input: 一张几 MB 的大 PNG 图片, output: 压缩好的 WebP 图片, 体积缩小大半、肉眼几乎看不出画质差别, 网页打开更快
- input: 产品页面的真实截图 (或网址), output: 套上浏览器/手机外框、带功能标注的展示图, 适配 Product Hunt、朋友圈等平台的指定尺寸
- input: 你的 Logo + 品牌色 + 一句口号, output: LinkedIn、X 等平台尺寸的封面横幅图, 关键内容居中、手机上缩小也能看清
