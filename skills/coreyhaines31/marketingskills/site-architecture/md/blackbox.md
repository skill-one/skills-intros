# site-architecture (`coreyhaines31/marketingskills/site-architecture`)

## blackbox

**function**: 我帮你规划网站该有哪些页面、怎么分层、怎么互相链接，并给出可直接照着做的完整站点结构方案。

- input: 「我要做一个瑜伽工作室官网，有课程、教练、价格、在线预约」, output: 一套完整结构方案：页面层级树（首页→课程→团课/私教…）＋可视化站点地图＋每页的网址清单（如 /classes/vinyasa）＋顶部导航栏和底部链接的具体设计
- input: 现有网站的页面清单 ＋ 「导航太乱、用户找不到东西、30 个旧网址不能失效」, output: 重构方案：新旧页面对照表、哪些旧网址要跳转到哪里、精简后的导航栏（不超 7 项）、每页顶部的面包屑路径（如 首页 > 课程 > 瑜伽课）
- input: 「博客有 40 篇文章，互相之间没有链接」, output: 内链规划：按主题把文章分组、指定每组的中心页、每篇文章该链接到哪几篇相关文章、检查有没有孤立页面
