# competitor-alternatives (`coreyhaines31/marketingskills/competitor-alternatives`)

## blackbox

**function**: 帮你写「我们 vs 竞品」类的对比页面文案, 让正在搜索竞品名字的人找到你、看清差异、愿意切换过来。🔍

- input: 一段自我介绍: 你的产品是什么、主打卖点、以及想对标哪个竞品 (如「我们是协作笔记工具, 想针对 Evernote 做 SEO 抢流量」), output: 一篇完整可发布的「Evernote 替代品」页面文案: 痛点开场 → 快速定位 → 功能/价格逐项对比 → 什么人适合切换 (以及什么人不适合) → 迁移指引 → 行动按钮
- input: 一句话指令, 如「写一篇 我们的产品 vs 竞品 X」, output: 按网页结构组织好的整篇文案: 开头 2-3 句结论摘要、对比表格、按功能/价格/客服等维度的逐段分析、双方各自最适合谁 (包括诚实写出竞品的优势)、切换客户证言、迁移支持说明
- input: 一份竞品名单 + 你的产品定位 (如 5 个竞争对手), output: 一份页面建设计划: 每个竞品该做哪种页面、按搜索流量优先级排序; 外加每个竞品的信息档案 (定位、价格档位、优劣势、用户常见抱怨、迁移注意事项), 供所有页面反复调用
