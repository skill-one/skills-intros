# directory-submissions (`coreyhaines31/marketingskills/directory-submissions`)

## blackbox

**function**: 帮你把产品提交到各类目录网站 (Product Hunt、AI 工具站、G2 等), 换取高质量外链、搜索排名和买家曝光——从检查你够不够格提交, 到逐站文案, 再到发布日执行, 全程陪跑。

- input: 产品官网 URL + 一句话产品介绍, output: 一份就绪度体检报告 (标出哪些环节不过关, 比如缺定价页、缺真实截图), 附按优先级排好的一批目录站点清单
- input: 一段产品描述原文, output: 按目录类型改写好的多套文案 (AI 工具站版 / SaaS 评测站版 / 开发者站版), 每套含短标语、60 字简介、150 词长介绍, 避免全站复制粘贴被降权
- input: "我要上 Product Hunt, 还剩 3 周", output: 倒排到天的冲刺计划 + 发布日执行清单 (几点发帖、首条评论怎么写、评论回复节奏、什么话千万不能说)
