# programmatic-seo (`coreyhaines31/marketingskills/programmatic-seo`)

## blackbox

**function**: 帮你用「一个模板 + 一批数据」批量生成大量能被搜索引擎收录带来流量的网页,并保证每页有真实价值、不会被搜索判为垃圾页。

- input: 一句话产品介绍,例如「我做了个在线简历工具,想靠搜索带来用户」, output: 一份可直接执行的策略方案:锁定哪类关键词模式、一共能做多少页、每页的网址怎么定、标题怎么写
- input: 一份产品资料 + 一个数据表,例如 50 个城市的名单, output: 50 个可直接上线的落地页:每页针对一个城市,有各自的标题、简介和差异化内容,而不是换个城市名复制粘贴
- input: 一批已上线页面的网址,例如网站里 200 个「XX vs YY」对比页, output: 一份体检报告:哪些页没被谷歌收录、哪些内容太薄有被降权风险、页面之间链接怎么补
