# form-cro (`coreyhaines31/marketingskills/form-cro`)

## whitebox

- 读上下文: 若存在 .agents/product-marketing-context.md (旧版 .claude/ 路径) 先读取, 只追问其中未覆盖的信息
- 定位表单: 判定表单类型 (线索获取 / 联系 / 演示申请 / 申请 / 问卷 / 结账 / 报价) + 业务上下文 (提交数据去向、哪些字段真正被用于跟进、合规要求)
- 逐项审计: 按「每个字段都有成本 / 价值须大于投入 / 降低认知负担」三原则, 检查字段、布局、标签、错误处理、提交按钮、信任要素
- 套用类型化指南: 按表单类型应用专属建议 (如 demo 表单电话设为可选、问卷加进度条、移动端单列 + 44px 触控目标)
- 结构化输出: Form Audit (问题/影响/修复/优先级) + 推荐表单设计 (必填字段及理由、字段顺序、文案、错误消息) + A/B 测试假设

- 纯启发式规则库, 零外部依赖: 全部判断来自内置 CRO 知识与经验数据 (字段数与完成率映射: 3 字段为基线, 4-6 字段降 10-25%, 7+ 降 25-50%+), 不调用任何外部工具、库或模型 API
- 上下文去重 + 路由守卫: 启动先查产品营销上下文文件避免重复提问; 超范围场景自动转介相关技能 — 注册表单 → signup-flow-cro, 弹窗内表单 → popup-cro
- 结构化交付契约: 输出固定三段式, 每个问题必须标注 Impact (对转化的影响估算) 与 Priority (High/Medium/Low), 修复建议落到字段级 (标签/占位符/按钮文案/错误消息示例)
