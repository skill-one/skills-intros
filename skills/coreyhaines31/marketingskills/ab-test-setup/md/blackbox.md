# ab-test-setup (`coreyhaines31/marketingskills/ab-test-setup`)

## blackbox

**function**: 帮你不靠感觉、靠数据回答"哪个版本更好":把一个改动(文案、按钮、页面)设计成可信的 A/B 测试,并告诉你结果能不能信、能不能上线。

- input: 一句话描述你的想法,如:「落地页转化率3%,每天约2000访客,我想把按钮文案从『注册』改成『免费开始』试试」, output: 一份可直接执行的实验方案:假设陈述、看哪个指标定胜负、需要多少样本、预计跑多久
- input: 测试中途的疑问,如:「B 版高 8%,才跑了 10 天还没够样本量,能不能提前停?」, output: 明确的判断建议:能否停止、提前停的风险、继续跑的判断标准
- input: 一组跑完的结果,如:「B 版显著胜出,但客服咨询量涨了 20%」, output: 结果解读 + 上线或回滚的建议,以及值得复用的结论(哪个规律可以搬到其他页面)
