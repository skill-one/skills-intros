# baoyu-diagram (`jimliu/baoyu-skills/baoyu-diagram`)

## blackbox

**function**: 你用大白话描述一个系统、流程或想法, 我还你一张画好的图 (SVG 文件, 浏览器打开即看) — 架构图、流程图、时序图、脑图、时间线都能画。

- input: 一句话描述: "画个电商系统架构, 用户端 → API 网关 → 后端服务 → 数据库, 还有 Redis 缓存", output: 一张深色风格的架构图 .svg 文件: 各组件是带颜色的方块, 之间用箭头连好, 浏览器打开就能看, 也能直接贴进文档/PPT
- input: 一段流程描述: "用户登录, 验证密码, 对了就进入首页, 错了重试, 连续三次失败就锁号", output: 一张流程图 .svg 文件: 菱形代表判断 (密码对不对?), 箭头标着「是/否」走向, 全程一目了然
- input: 一份需求文档路径 + 吩咐: "照这个画时序图", output: 一张时序图 .svg 文件: 参与方纵向排列, 消息按时间从上往下往来, 请求实线、返回虚线
- input: "把『低碳生活』这个主题整理成脑图" + 一段要点文字, output: 一张中心发散的脑图 .svg 文件: 中心一个主题, 分支向四周自然展开, 每个分支一种颜色
- input: 一份 .svg 图的文件路径, output: 同一张图的 2 倍分辨率 PNG, 发微信、插 PPT 不糊
