# baoyu-cover-image (`jimliu/baoyu-skills/baoyu-cover-image`)

## blackbox

**function**: 根据你的文章或一句话描述，生成一张可直接使用的文章封面图片（PNG），支持指定尺寸、配色、画风和标题文字，生成前会先和你确认这些选项。

- input: 一篇文章的 .md 文件路径（或直接粘贴全文）, output: 一张带文章标题的封面 PNG（默认 16:9，也可选电影宽幅 2.35:1 或方形 1:1）
- input: 一句话需求，如「给一篇讲深度睡眠的文章做封面，冷色调、极简风、不要文字」, output: 按这些要求生成的封面 PNG + 一份简短报告（用了什么配色/画风、文件保存在哪）
- input: 一张已生成的封面 + 一句修改要求，如「配色换成暖色，标题改成 XXX」, output: 一张改好的新封面 PNG，旧版本保留备份方便对比
