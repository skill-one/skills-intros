# baoyu-post-to-x (`jimliu/baoyu-skills/baoyu-post-to-x`)

## blackbox

**function**: 把你的文字、图片、视频或长文章发到 X(推特)上——内容填好后你过目,点发布才真正发出。

- input: 一段文字 + 最多 4 张图片(如 "看看今天的晚霞" + photo.png)→, output: X 发帖框里文字和图片已就位,你确认后一键发布
- input: 一条推文链接 + 一句评论 →, output: 引用转发框已填好你的评论,确认后即可发出
- input: 一个 Markdown 文件路径(如 article.md,可带封面图)→, output: X 长文章草稿:标题、封面、正文插图全部排版到位,预览满意后发布
