# baoyu-slide-deck (`jimliu/baoyu-skills/baoyu-slide-deck`)

## blackbox

**function**: 把你给的任何内容（一篇文章、一份文档或一句话主题）变成一套设计统一、图文并茂的幻灯片图片，还能打包成 PPTX / PDF，直接拿去阅读、分享或汇报。

- input: 一篇 3000 字的 .md 技术文章文件路径, output: 10~18 张风格统一的幻灯片图片（PNG），外加合并好的 .pptx 和 .pdf 文件
- input: 一句话需求："帮我做一份介绍机器学习入门的演示文稿", output: 自动扩写成大纲并生成约 10 张带插图的幻灯片，逐张给你看，不满意可指定某一张重画
- input: 一份报告 + 一句指定："用手绘教育风，中文", output: 按手绘教育风、中文排版的整套幻灯片图片，可直接发朋友圈或投屏讲解
