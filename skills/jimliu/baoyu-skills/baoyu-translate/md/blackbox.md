# baoyu-translate (`jimliu/baoyu-skills/baoyu-translate`)

## blackbox

**function**: 把英文文章、网页或段落翻译成地道流畅的中文（也支持中译英），长文术语前后统一，还能按要求润色到可发布的水准。

- input: 一个英文文章的网页链接, output: 一份中文翻译文件 translation.md，保留原文的标题、图片、链接和排版
- input: 一段英文文本，附一句「快翻」, output: 对应的中文译文，直接给出，速度快
- input: 一个英文技术文档的文件路径，附一句「精翻」, output: 一份精修过的中文译文：全文术语统一，专业概念处附简要中文解释，达到可发表的质量
