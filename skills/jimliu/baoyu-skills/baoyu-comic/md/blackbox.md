# baoyu-comic (`jimliu/baoyu-skills/baoyu-comic`)

## blackbox

**function**: 把你给的一段文字或一个主题, 做成一本画风统一、带对白分格的原创知识漫画, 最终交付一个可翻阅的 PDF 文件。

- input: 一段文字或一个主题, 如: 「帮我画一本介绍图灵生平的知识漫画」, output: 一本多页漫画 PDF: 有封面、分格画页, 人物有台词, 前后画风一致, 可直接阅读或打印
- input: 同一主题 + 风格要求, 如: 「用日漫风格、温馨基调讲量子计算入门, 做成竖版」, output: 对应画风与氛围的漫画 PDF (可选横版/竖版、四格、条漫等版式), 换风格即换成品
- input: 一句修改指令, 如: 「第 3 页对白改一下, 重新生成」或「只重新画第 2、5 页」, output: 更新后的那几页漫画图, 以及重新合并好的整本 PDF, 其余页面保持不变
