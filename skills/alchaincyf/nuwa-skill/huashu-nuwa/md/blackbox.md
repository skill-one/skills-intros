# huashu-nuwa (`alchaincyf/nuwa-skill/huashu-nuwa`)

## blackbox

**function**: 把一个真实人物（或某个主题）的思维方式，做成一个可对话的「思维顾问」——你提问，它用那个人的视角、口吻和分析习惯来回答。

- input: 一句话：「蒸馏查理·芒格」（或任意人名：费曼、塔勒布、王阳明……）, output: 一个装好的思维顾问 skill：之后你问「这笔投资该不该做」，它会用芒格的多元思维模型和说话风格回答，并诚实标注哪些是推断、哪些有原文依据
- input: 一段模糊需求：「我总在商业决策上犹豫不决、选错方向」, output: 2-3 个最匹配你需求的候选人物推荐（各自的核心视角 + 适合你的理由 + 局限），你选定一个后，直接交付成品思维顾问
- input: 你手上的人物素材：书籍 PDF、访谈录音文字稿、演讲视频等，加一句「用这些做」, output: 基于你提供的原始素材生成的思维顾问，比纯网络搜索质量更高，且标注每条观点来自你的哪份素材
- input: 「更新芒格的 skill，他最近有新访谈」, output: 增量更新后的 skill：保留原有框架，补充最新动态和观点变化，并在文档里注明信息截止日期
