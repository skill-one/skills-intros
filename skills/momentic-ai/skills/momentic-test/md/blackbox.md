# momentic-test (`momentic-ai/skills/momentic-test`)

## blackbox

**function**: 我像一个替你点浏览器的测试员: 你用大白话告诉我要在网页上做什么, 我就能创建、修改和运行自动化的端到端测试, 并告诉你网站到底好不好使。

- input: 一句流程描述 + 网址, 如「打开 shop.example.com, 登录, 加一件商品进购物车, 结账成功后应显示订单号」, output: 一个可直接运行的自动化测试: 我会真的打开浏览器逐步操作并验证页面, 交付一个测试文件, 以后随时可重复跑
- input: 一个已有测试文件的路径 + 一句改动说明, 如「结账按钮改名叫『立即支付』了」, output: 更新后的测试文件: 失效的步骤指向新按钮, 其余内容保持原样
- input: 一个测试的路径或 ID + 「帮我跑一下」, output: 运行结果: 通过或失败、失败在第几步、当时的页面截图、失败原因分析, 以及修好的测试
