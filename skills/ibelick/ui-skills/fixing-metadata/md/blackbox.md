# fixing-metadata (`ibelick/ui-skills/fixing-metadata`)

## blackbox

**function**: 检查并修好网页的"门面信息"(页面标题、描述、分享卡片等), 让搜索引擎收录正确、链接分享到微信/推特时显示体面。

- input: 一个 .html 网页文件, output: 修好的同一份文件: 补齐或更正了页面标题、描述、分享卡片、收藏夹小图标等标签, 其他代码原样不动
- input: 一个已上线的网页链接, output: 一份问题清单: 指出哪些标签缺失或写错(如分享出去没配图、页面地址指向错误), 按严重程度排好序
- input: 一句话需求, 如"帮我给新上线的活动页加上标题和描述", output: 可直接粘贴进网页的标签代码
