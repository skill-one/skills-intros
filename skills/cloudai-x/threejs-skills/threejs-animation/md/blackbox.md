# threejs-animation (`cloudai-x/threejs-skills/threejs-animation`)

## blackbox

**function**: 给网页里的 3D 模型编写「会动」的代码——让物体旋转弹跳、让角色播放动作、在动作之间平滑切换、控制表情变化。

- input: 一个带动作的 3D 人物模型文件 (GLB 格式), 如走路动画, output: 可直接运行的代码, 在浏览器里加载模型并自动播放走路动作, 循环不停
- input: 一句需求: 「让这个立方体上下弹跳, 同时慢慢旋转」, output: 能跑的动画代码, 打开网页就能看到立方体按描述动起来
- input: 一个带多套动作的角色 (待机/走路/跑步) + 一句「按移动速度切换动作」, output: 平滑过渡的代码: 从走到跑动作自然衔接, 不会瞬间跳变
- input: 一个带表情的模型 + 「让角色慢慢露出微笑」, output: 控制表情的代码, 角色从面无表情平滑过渡到微笑
