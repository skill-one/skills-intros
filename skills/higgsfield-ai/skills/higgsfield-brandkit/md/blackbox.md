# higgsfield-brandkit (`higgsfield-ai/skills/higgsfield-brandkit`)

## blackbox

**function**: 根据你的品牌描述或现有 logo, 生成完整的品牌视觉物料: 配色、logo、包装、海报、社交媒体图、品牌手册等成品文件。

- input: 一句品牌描述, 如「新开的精品咖啡品牌, 名叫『山雾』, 想要简约自然的风格」, output: 3 套配色方案 + 3 个 logo 设计稿供你挑选, 选定后交付可用的 logo 文件(SVG/PNG)和字体搭配建议
- input: 你已有的 logo 图片文件 + 一句话需求, 如「用这个 logo 做一套咖啡杯包装和门店招牌」, output: 印上你 logo 的包装设计图和招牌效果图(图片文件), 不改动你原有的 logo
- input: 品牌的 logo、配色和基础信息, 如「帮我们整理成一本品牌手册」, output: 可编辑的 PPTX 和 PDF 品牌手册文件, 包含 logo 使用规范、色值、字体和应用示例
