# higgsfield-soul-id (`higgsfield-ai/skills/higgsfield-soul-id`)

## blackbox

**function**: 用你的照片训练一个专属「数字分身」，之后生成图片或视频时，画面里的人始终是你那张脸。

- input: 一个名字（如 Alice）+ 5~20 张不同角度、不同光线的面部照片, output: 训练完成的专属角色「Alice」，之后可随时用它生成带这张脸的内容
- input: 「用 Alice 生成：穿宇航服站在火星地表」, output: 一张 2K 高清图片，画面中的人物有着 Alice 那张真实的脸
- input: 「用 Alice 生成一段电影感场景」, output: 一段以 Alice 的面孔为主角的影像画面
