# higgsfield-video-explainer (`higgsfield-ai/skills/higgsfield-video-explainer`)

## blackbox

**function**: 你给我一个主题、一份文档或一段故事, 我交给你一条完整的带旁白动画解说视频 (1–10 分钟, 非实拍画风), 你中途只需挑一下画风和配音, 最后拿到一条可直接播放的成品 MP4。🎬

- input: 一句话主题: 「用 3 分钟讲清楚为什么天空是蓝色的, 中文旁白」, output: 一条约 3 分钟的 MP4 视频链接: 画风统一的插画动画 + 中文配音旁白, 附事实来源清单
- input: 一份产品白皮书 PDF + 「把它做成解说视频, 竖屏 9:16」, output: 一条忠于文档内容的竖屏动画解说视频, 适合手机端播放
- input: 一段个人故事文字: 「把我爷爷开茶馆的经历讲成 2 分钟动画短片」, output: 一条 2 分钟的动画叙事短片, 保留你提供的细节, 全程旁白讲述
