# firebase-hosting-basics (`firebase/agent-skills/firebase-hosting-basics`)

## blackbox

**function**: 把你的网站放上互联网: 给我一堆做好的网页文件, 帮你部署上线, 拿到一个全世界都能访问的网址。

- input: 一个装着做好的网页文件的文件夹 (HTML/CSS/JS), output: 一个 https 开头的正式网址, 世界各地访客打开就能看到你的网站
- input: 你买的域名, 例如 myshop.com, output: 访客输入 myshop.com 就能打开你的网站, 且带自动的 https 安全证书
- input: 「新版改好了, 但先别正式上线」这样的请求, output: 一个临时预览网址, 只有拿到链接的人能看, 确认没问题再一键切换为正式版
